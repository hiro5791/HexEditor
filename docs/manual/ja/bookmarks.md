# ブックマークと注釈

ブックマークは、ドキュメントの一部に付ける印です。名前、色、コメントを付けて、あとからすぐ戻れます。このページでは、ブックマークの使い方と、注釈、色付けルールによる色分けを説明します。

## ブックマークを付ける {#add-bookmarks}

次のどれかで付けます。

- <kbd>Ctrl</kbd>+<kbd>F2</kbd> を押す。
- **移動 > ブックマーク > ブックマークの設定 / 解除** を選ぶ。
- Hex ビューを右クリックして、**ブックマークを設定** を選ぶ。

選択範囲があるときは、その範囲に付きます。ないときは、カーソル位置の 1 バイトに付きます。名前は「ブックマーク 1」のように自動で付き、色は既定の色になります。名前などは聞かれません。あとで直せます。

カーソル位置から始まるブックマークがあるときに <kbd>Ctrl</kbd>+<kbd>F2</kbd> を押すと、そのブックマークが外れます。名前やコメントを付けたブックマークを外したときは、通知に **元に戻す** が出ます。

ブックマークの範囲は、Hex ビューで色付きの背景になります。開始位置のオフセット列には目印が付きます。範囲にマウスを重ねると、名前とコメントが出ます。

覚えておくことがあります。

- ブックマークを付けても、ドキュメントは「変更あり」になりません。ファイルの内容も変わりません。
- ドキュメントを編集すると、ブックマークの位置も追従します。ブックマークより前にバイトを挿入すると、位置が後ろにずれます。範囲の中に挿入すると、長さが伸びます。範囲がすべて削除されると、長さ 0 になり、パネルに「範囲が削除されました」と出ます。ブックマーク自体は消えません。元に戻すと、位置も戻ります。
- ブックマークはファイルの外に保存されます。ファイルを閉じて開き直しても残ります。ファイルが外で変わっていたときは、「位置が合わない可能性があります」と知らせ、**ブックマークを復元** か **破棄** を選べます。
- 1 つのドキュメントに付けられるのは、1,000,000 件までです。

### ブックマークを編集する {#edit-bookmarks}

1. ブックマークの上にカーソルを置きます。
2. **移動 > ブックマーク > ブックマークを編集** を選びます。Hex ビューの右クリックメニューの **ブックマークを編集** や、パネルの **編集** からも開けます。
3. 編集欄が開きます。

編集欄では、次の項目を変えられます。入力するとすぐ保存されます。保存ボタンはありません。閉じるときは <kbd>Esc</kbd> を押します。

- **名前**: 1〜256 文字。
- **開始オフセット** と **長さ**: 式で入力できます。**終了 (このバイトを含む)** で範囲を指定することもできます。
- **色**: 8 色から選びます。**任意の色** も使えます。
- **グループ**
- **番号**: なし、または 1〜9。
- **コメント (Markdown)**: 64 KB まで。**プレビュー** で表示を確かめられます。リンクの先を `#0x1F00` や `#bm.header` にすると、クリックでその位置に移動します。`http` と `https` のリンクはブラウザで開きます。

名前を `header` のような英数字と `_` だけにすると、入力式で `bm.header+8` のように位置の指定に使えます。同じ名前が複数あるときは、先に作ったものが使われます。

### 番号付きブックマーク {#numbered-bookmarks}

1〜9 の番号を付けたブックマークは、キー 1 つで設定と移動ができます。

1. <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>3</kbd> のように押して、カーソル位置に番号 3 を設定します。
2. 別の場所で <kbd>Ctrl</kbd>+<kbd>3</kbd> を押すと、番号 3 の位置に戻ります。

番号が別のブックマークに付いていたときは、番号が新しい位置に移ります。設定していない番号に移動しようとすると、ステータスバーに知らせが出ます。テンキーの数字も使えます。

メニューは **移動 > ブックマーク > 番号付きブックマークを設定** と **番号付きブックマークへ移動** です。

### 前後のブックマークへ移動する {#next-previous}

<kbd>F2</kbd> で次のブックマーク、<kbd>Shift</kbd>+<kbd>F2</kbd> で前のブックマークに移動します。範囲も選択されます。最後まで行くと先頭に戻り、ステータスバーに「先頭に戻りました」と出ます。

## ブックマークのパネル {#bookmarks-panel}

**表示 > パネルの表示切り替え > ブックマーク** でパネルを開きます。**移動 > ブックマーク > ブックマーク一覧** からも開けます。

パネルの一覧には、番号、色、名前、開始、長さ、グループ、コメントなどの列があります。列の見出しを選ぶと並べ替えます。初めは開始オフセット順です。列の表示と順番は変えられます。上の欄に語を入力すると、名前かコメントに含む行だけに絞り込めます。

操作は次のとおりです。

- 行を選ぶ (クリックか <kbd>Enter</kbd>): その位置に移動して、範囲を選びます。
- <kbd>↑</kbd> と <kbd>↓</kbd>: 行を移ります。エディタが一緒にスクロールします。
- <kbd>Delete</kbd>: 選んだブックマークを削除します。通知の **元に戻す** で戻せます。
- 複数の行を選ぶ (<kbd>Shift</kbd>+<kbd>↑</kbd>、<kbd>↓</kbd> や <kbd>Ctrl</kbd>+<kbd>A</kbd>): まとめて削除、色の変更、グループの移動ができます。
- 右クリック: **移動**、**名前を変更**、**編集...**、**色**、**削除**、**グループに移動**、**選択範囲にする**。

パネルの設定で、**すべてのドキュメント** にすると、開いているすべてのドキュメントのブックマークをまとめて表示できます。

スクロールバーにブックマークの印を出すには、設定の **スクロールバーにブックマークを表示** をオンにします。

## グループとタグ {#groups}

ブックマークをグループにまとめると、整理しやすくなります。グループは入れ子にでき、8 階層までです。

1. パネルの **グループの作成** で、グループを作ります。
2. ブックマークをグループにドラッグします。右クリックの **グループに移動** でも移せます。

グループには、名前と色、表示・非表示の状態があります。

- グループに色を付けると、色を決めていないブックマークはその色で表示されます。
- グループを非表示にすると、そのブックマークは Hex ビューに出ません。<kbd>F2</kbd> での移動でも飛ばされます。グループの行で <kbd>Space</kbd> を押すと、表示と非表示が切り替わります。
- グループを削除するときは、**中のブックマークも削除する** か **中のブックマークを親のグループに移す** を選びます。通知の **元に戻す** で戻せます。

## 型付きブックマークと位置の式 {#typed-bookmarks}

ブックマークに型を付けると、その位置の値が一覧の **値** の列に出ます。ブックマークの編集欄の **型** で選びます。[データインスペクタ](inspector.md)のすべての型と、適用しているテンプレートの型が使えます。**エンディアン** は、ブックマークごとに決められます。一覧の値の欄から、値を書き換えることもできます。

開始オフセットは、固定の数ではなく **位置の式** で決められます。たとえば、次のように書きます。

| 式 | 意味 |
| --- | --- |
| `u32le(0x3C)` | オフセット 0x3C にある 4 バイトの値 (PE ヘッダの位置) |
| `bm.pe + 0x18` | `pe` という名前のブックマークの 0x18 バイト後ろ |
| `align(bm.data + u16le(bm.data), 4)` | 4 バイト境界にそろえた位置 |

`u8(x)`、`u16le(x)`、`u32le(x)`、`s64be(x)` のように、ドキュメントの値を読む関数が使えます。`align(x, n)` は、x を n の倍数に切り上げます。

位置の式を持つブックマークは、ドキュメントを編集して少し待つと、式が計算し直されて位置が更新されます。一覧では「式」の印が付きます。式にエラー (書き方の誤り、循環する参照、範囲外) があるときは、その行に理由が出て、位置は最後に計算できた値のままです。`bm.名前` の参照は、32 段までです。

## 選択範囲とブックマークの変換 {#selection-conversion}

選択範囲とブックマークは、相互に変換できます。複数の範囲を選んだ状態も扱えます。

- **選択範囲をブックマークに**: **編集 > 選択範囲をブックマークに** を選びます。各範囲が 1 件のブックマーク (名前は「選択 1」など) になります。範囲が 2 つ以上のときは、「選択範囲 <日時>」というグループもできます。
- **ブックマークを選択範囲に**: パネルでブックマークを選んで、右クリックの **選択範囲にする** を選びます。**移動 > ブックマーク > ブックマークを選択範囲に** でも実行できます。2 件以上のときは、複数の範囲の選択になります。長さ 0 のブックマークは除かれます。

「すべて検索」の結果をブックマークにすることもできます。その場合は、グループが自動で作られます。

## ブックマークのインポートとエクスポート {#import-export-bookmarks}

ブックマークをファイルに書き出して、別のドキュメントに読み込めます。

1. **ファイル > ブックマークのインポート / エクスポート > ブックマークをエクスポート** を選びます。パネルの **ブックマークをエクスポート** でも書き出せます。
2. 読み込むときは、**ブックマークをインポート** を選び、ファイルを選びます。

使える形式は次のとおりです。

| 形式 | 内容 |
| --- | --- |
| HexEditor ブックマーク (`.hexbm.json`) | すべての情報 (グループ、番号、型、位置の式、コメント) |
| CSV | 開始オフセット、長さ、名前、色、グループ、コメント。Excel で編集できる |
| wxHexEditor のタグ (XML) | 範囲、タグの文字、色。対応しない情報は捨てられる |

インポートのときは、**追加する** か **置き換える** を選びます。**オフセットのずれ** に `+0x200` のような式を入力すると、すべてのブックマークがその分ずれて読み込まれます。ドキュメントの範囲外になるブックマークは読み込まれません。終わると、読み込んだ件数と飛ばした件数が通知されます。ファイルの形式が正しくないときは、場所と理由が出て、何も読み込まれません。

番号が重なるときは、読み込む方が優先されます。既存のブックマークからは番号が外れます。

## 注釈 {#annotations}

注釈は、機能が Hex ビューのバイト範囲に付ける、ラベルと色と説明です。ブックマークも注釈の 1 つです。

出どころは次のとおりです。

- ブックマーク
- すべて検索の結果
- 構造体テンプレート
- スクリプト・プラグイン
- 解析の結果 (暗号化・圧縮データの検出など)

**表示 > 注釈** で、表示を切り替えます。

- **注釈を表示**: 注釈全体のオンとオフ。
- **注釈の列**: テキスト列の右に、その行で始まる注釈のラベルを出します。1 行に複数あるときは、「header +2」のように件数が付きます。
- 出どころごとのチェック: 見たくない出どころを隠します。

注釈の描き方は、出どころごとに、設定の **注釈の描き方: ...** で、背景色、枠線、下線から選べます。

注釈のあるバイトにマウスを重ねると、そのバイトを含む注釈がすべて出ます。キーボードだけで読むときは、**移動 > ブックマーク > カーソル位置の説明を表示** を使います。

### 位置マネージャ {#position-manager}

長い説明を書き溜めたいときは、位置マネージャが便利です。**移動 > ブックマーク > 位置マネージャ** で開きます。ブックマークを開始オフセット順に並べた一覧と、選んだブックマークのコメントの編集欄とプレビューが並びます。一覧で選ぶとエディタが移動し、エディタでカーソルを動かすと一覧の選択も追従します。内容は Markdown か HTML のファイルに書き出せます。

## 色付けルール {#coloring-rules}

色付けルールは、条件に合うバイトに色を付ける機能です。見た目が変わるだけで、データは変わりません。たとえば、`00` を薄く表示したり、ファイルのヘッダを目立たせたりできます。

**表示 > 色付けルール > 色付けルール** でパネルを開きます。

ルールの作り方は次のとおりです。

1. パネルの **ルールを追加** を選びます。
2. **名前** と **条件** を決めます。
3. 条件の値を入力します。
4. **文字色**、**背景色**、**枠線** を選びます。**適用先** で、Hex 列とテキスト列のどちらに付けるかを決められます。

条件の種類は次のとおりです。

| 条件 | 入力する値の例 |
| --- | --- |
| **バイト値** | `00`、`20-7E`、`7F, 80-FF` |
| **オフセット範囲** | 開始と終了を式で入力 (例: `0x0`〜`0x3F`) |
| **周期** | 間隔、位置、長さ (512 バイトごとの先頭 2 バイトなど) |
| **Hex パターン** | `50 4B 03 04` (`??` は任意の 1 バイト) |
| **テキスト** | 文字列、文字コード、大文字・小文字の区別 |
| **正規表現** | 一致の最大長は 256 バイト |
| **数値** | 型、エンディアン、値または範囲 (例: uint32 で `0..0xFF`) |

条件の書き方が正しくないときは、入力欄に理由が出ます。

ほかに、次のことができます。

- **選択範囲の値で色付けルールを作成**: 1〜256 バイトを選んでから実行すると、その内容を Hex パターンにしたルールが作られます。
- プリセット: **ゼロを薄く表示**、**印字可能な ASCII**、**制御文字**、**FF**、**上位ビットが 1**。初めは無効です。必要なものを有効にします。
- ルールの集まりは 2 つあります。**全体** はすべてのドキュメントに、**このドキュメント** はそのドキュメントだけに効きます。
- 同じバイトに複数のルールが一致したときは、一覧で上のルールが優先されます。**上へ (優先する)** と **下へ** で順番を変えます。このドキュメントのルールは、全体のルールより優先です。
- ルールは 1 つの集まりで 256 件までです。

**表示 > 色付けルール > 凡例** で、凡例のパネルを開けます。有効なルールの色と、表示範囲での件数が並びます。**全体の件数を数える** でドキュメント全体の件数を数え、各ルールの **次の一致** と **前の一致** で、一致する場所に移動できます。

ハイコントラストのテーマでは、色の代わりに、枠線の形 (実線、破線、点線、二重線) でルールを区別します。
