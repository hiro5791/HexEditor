# 外部からの自動操作

PC のほかのプログラム (PowerShell、Python、テストツールなど) から、実行中の HexEditor を操作できます。スクリプトと同じ機能を、名前付きパイプの JSON-RPC 2.0 のメッセージで呼びます。

## オンにする {#turn-on}

外部からの自動操作は、既定ではオフです。

1. **ツール > 設定** を選び、**自動化** を選びます。
2. **外部からの自動操作を許可する (名前付きパイプの JSON-RPC)** をオンにします。

オンの間は、ステータスバーに「外部からの自動操作: 有効」という名前のアイコンが出ます。アイコンを選ぶと、この設定が開きます。**外部からの自動操作** の区画には、パイプの名前、PowerShell モジュールの場所、許可したプログラムが出ます。

接続できるのは、この PC のあなたのアカウントで動くプログラムだけです。ほかの利用者やネットワークからの接続は拒否します。

## プログラムを許可する {#allow-a-program}

プログラムが初めて接続すると、許可するかどうかの確認が出ます。確認には、プログラムのパスと、デジタル署名があればその署名者が出ます。

- **今回だけ許可する**: 接続を切るまで使えます。次の接続でまた確認します。
- **常に許可する**: プログラムを覚えます。プログラムのファイルが変わったら、また確認します。
- **許可しない**: 接続を切ります。

許可したプログラムは、開いているドキュメントの読み書き、ファイルを開く・保存するなど、自動化のほかの機能も使えます。ディスクやプロセスのメモリを開くときは、そのたびに確認します。HexEditor を管理者として実行しているときは、接続のたびに確認します。

許可を取り消すときは、**設定 > 自動化 > 外部からの自動操作** で、そのプログラムの **取り消す** を選びます。

## PowerShell モジュールを使う {#powershell}

HexEditor には PowerShell モジュール **HexEditor.Automation** が入っています。Windows PowerShell 5.1 と PowerShell 7 で使えます。フォルダの場所は **設定 > 自動化 > 外部からの自動操作** に出ます。

```powershell
Import-Module 'C:\Program Files\HexEditor\Automation\HexEditor.Automation'
Get-HexEditorDocument
$doc = Open-HexEditorFile -Path C:\data\sample.bin
Read-HexEditorBytes -Document $doc.id -Offset 0x10 -Length 16
Invoke-HexEditorMethod -Method 'document.goTo' -Params @($doc.id, 'end-0x10')
```

パスは、自分のインストール先に読み替えてください。コマンドは自動で接続します。どのメソッドも **Invoke-HexEditorMethod** で呼べます。

## 自分でクライアントを書く {#protocol}

- パイプは `\\.\pipe\HexEditor.<あなたの利用者の SID>.rpc` です。
- 1 行に 1 つの JSON-RPC 2.0 のメッセージを UTF-8 で送り、1 行ずつ読みます。1 つのメッセージは 64 MB までです。
- メソッドの名前はスクリプトの API の名前 (`オブジェクト.メンバー`) です。例: `app.open`、`app.documents`、`document.readBytes`。プロパティは同じ名前で読み、`value` を渡すと代入します。
- ドキュメントのメソッドには、ドキュメントの `id` を引数 `document` (配列で渡すときは先頭) で渡します。テンプレートのノードなど、ほかのオブジェクトは `handle` で渡します。
- バイト列は Base64 の文字列です。バイトのパターンを受け取るメソッドには `{"hex": "DE AD"}` も渡せます。
- オフセットと範囲には、スクリプトと同じ入力式を使えます (例: `"end-0x10"`、`"0x100:0x20"`)。
- イベントは `app.on` で購読します。イベントは `event` の通知で届きます。
- 時間のかかる処理は、進捗を `$/progress` の通知で知らせます。要求の `id` を付けて `$/cancel` の通知を送ると、キャンセルします。
- プログラムが加えた変更は、スクリプトの変更と同じく元に戻せます。プログラムが書き込んでいる間、そのドキュメントには「外部から操作されています」と **切断** ボタンが出ます。

例 (Python):

```python
import json
pipe = open(r"\\.\pipe\HexEditor.S-1-5-21-...-1001.rpc", "r+b", buffering=0)
pipe.write((json.dumps({"jsonrpc": "2.0", "id": 1, "method": "app.documents"}) + "\n").encode())
print(pipe.read(65536))
```

メソッドの一覧 (引数とエラーコードを含む) は、HexEditor のフォルダの `Automation\jsonrpc-methods.json` です。エラーは次のコードで返ります。

| コード | 意味 |
| --- | --- |
| -32001 | 許可がない |
| -32002 | 引数が正しくない |
| -32003 | 範囲外 |
| -32004 | ドキュメントが読み取り専用 |
| -32005 | 読み書きに失敗した |
| -32006 | キャンセルされた |
| -32007 | 上限を超えた (64 MB を超えるメッセージなど) |
| -32010 | 利用者が接続を許可しなかった |
| -32601 | メソッドがない、またはほかのプログラムからは使えない |
| -32602 | 引数が正しくない (形式) |
