# リモートのデータソース

GDB サーバーを通してメモリを編集する方法、SFTP でファイルを開く方法、受信した UDP のデータグラムをその場で見る方法を説明します。HexEditor は、利用者が操作したときだけ接続します。起動時やセッションの復元のときには接続しません。

## GDB サーバー {#gdb-server}

`gdbserver`、QEMU、OpenOCD、デバッグプローブなどの GDB サーバーを通して、対象のメモリを読み書きできます。

1. **ファイル > リモートに接続 > GDB サーバー** を選ぶか、コマンドパレットの **ファイル: GDB サーバーに接続** を実行します。
2. **ホスト** (既定 `localhost`) と **ポート** (既定 `1234`) を入力し、**アドレスの幅** (32 bit か 64 bit) を選びます。
3. **読み取り専用で開く** は既定でオンです。対象に書き込みたいときはオフにします。
4. **接続** を選びます。

オフセットは対象のアドレスで、ドキュメントはアドレス空間全体です。読み込むのは表示している範囲だけです。対象が拒否した範囲は、読めない範囲として表示します。HexEditor はメモリの読み書きだけを行います。対象の停止・再開やブレークポイントは使いません。

- 保存 (<kbd>Ctrl</kbd>+<kbd>S</kbd>) で、変更したバイトを対象に書き込みます。最初の書き込みの前に確認が出ます。コマンドパレットの **ファイル: 即時書き込みの切り替え** で、プロセスのメモリと同じく、編集するたびにすぐ書き込めます。
- ステータスバーに接続先と接続の状態が出ます。要求に対して上限の時間 (既定 5 秒。**設定 > ファイル** の **GDB サーバーの要求の待ち時間の上限 (秒)**) 内に応答がないときや、サーバーが止まったときは、ドキュメントが「切断」になります。未保存の変更は残ります。バーの **再接続** を選ぶか、ステータスバーの項目を選ぶか、**ファイル: 再接続** を実行します。
- **再読み込み** (<kbd>Ctrl</kbd>+<kbd>R</kbd>) で、メモリを読み直します。

## SFTP {#sftp}

ほかのコンピューターにあるファイルを、SSH (SFTP) で開いて編集し、保存できます。ダウンロードするのは表示している部分だけです。

1. **ファイル > リモートに接続 > SFTP** を選ぶか、コマンドパレットの **ファイル: SFTP で開く** を実行します。
2. **ホスト**、**ポート** (既定 `22`)、**ユーザー名** を入力します。
3. **認証方式** を選びます。**パスワード**、**鍵ファイル** (パスフレーズがあれば入力します)、**SSH エージェント (OpenSSH エージェント、Pageant)** のどれかです。
4. **接続** を選びます。
5. 一覧からファイルを選び、**開く** を選びます。フォルダーはダブルクリックで開きます。**上へ** で上のフォルダーに戻ります。

初めて接続するサーバーでは、ホスト鍵の種類と SHA-256 のフィンガープリントを表示します。サーバーのものと一致することを確かめてから、**信頼して接続** を選びます。以前に信頼した鍵と違うときは警告を出し、**鍵を置き換えて接続** を選ばない限り接続しません。

- パスワードやパスフレーズは、**パスワードを Windows の資格情報マネージャーに保存する** をオンにしたときだけ保存します。設定ファイルには書きません。
- 開いたファイルは、最近使ったファイルに `sftp://ユーザー@ホスト:ポート/パス` の形で記録します。パスワードは含めません。そこから開くと、接続の画面をもう一度出します。
- タブのツールチップにリモートのパスが、ステータスバーに接続の状態が出ます。
- 長さを変えずに保存するときは、変更した範囲だけを書き込みます。保存の途中で接続が切れると、リモートのファイルの一部だけが書き換わる可能性があることを確認します (**設定 > ファイル** の **SFTP で変更範囲だけを書き込む前に確認する** でオフにできます)。それ以外の保存では、同じフォルダーの一時ファイルに書き出してから、ファイルを置き換えます。
- 30 秒ごとと、ウィンドウに戻ったときに、ほかの人がリモートのファイルを変更していないかを確かめます。変更されていたら、バーに **再読み込み** が出ます。
- 接続が切れたときは、1 回だけ自動で再接続を試みます。失敗したら、バーの **再接続** を選びます。未保存の変更は残ります。
- セッションから戻したタブは接続していません。タブの **接続** を選びます。

## UDP を受信 {#udp}

UDP のポートで待ち受けて、受信したデータグラムを順に見られます。機器やネットワークのプログラムを調べるときに便利です。

1. **ファイル > リモートに接続 > UDP を受信** を選ぶか、コマンドパレットの **ファイル: UDP を受信** を実行します。
2. **待ち受けるアドレス** を選びます (既定 `127.0.0.1`。すべてのアドレスは `0.0.0.0` か `::`)。それ以外のアドレスでは、Windows ファイアウォールの確認が出ることがあります。
3. **ポート** (1〜65535) を入力します。
4. **保持する上限** (既定 64 MiB) を決めます。
5. **開始** を選びます。

受信したデータグラムは、受信した順に、読み取り専用のドキュメントの末尾に加わります。HexEditor は受信だけを行い、送信はしません。

- **パケット** のパネルに、データグラムごとの位置・長さ・時刻・送信元が並びます。行を選ぶと、その位置に移動します。**一時停止**、**再開**、**消去** もここにあります。**CSV でエクスポート**、**JSON でエクスポート** で一覧を保存できます。
- カーソルが末尾にあるときは、受信したデータまで表示が追従します (**設定 > ファイル** の **UDP の受信中に末尾に追従する** でオフにできます)。
- ステータスバーに、受信した数と量が出ます。
- 上限に達すると記録を止め、バーで知らせます。**古いデータを捨てて続ける** を選ぶと、古いデータから捨てて受信を続けます。アドレスは受信を始めてからの通算のままです。
- **ファイル > 名前を付けて保存** で、受信したデータを 1 つのファイルに保存できます。タブは受信を続けます。
- タブを閉じると受信を止めます。アプリを起動し直しても、受信は再開しません。
