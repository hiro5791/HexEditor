# フォルダの比較

フォルダの比較は、2 つのフォルダのファイルを相対パスで対応付けて、同じもの、違うもの、片方にしかないものを一覧にします。結果を見せるだけで、コピーや同期はしません。

## 2 つのフォルダを比べる {#compare}

1. **ツール > ファイルツール > フォルダの比較...** を選びます。コマンドパレットの **ファイルツール: フォルダを比較** でも開けます。
2. **左のフォルダ** と **右のフォルダ** を入力するか、**参照...** で選びます。
3. オプションを設定します。
   - **サブフォルダを含める** は、既定でオンです。
   - **対象のファイル名のパターン** で、対象を絞れます。例: `*.bin`。複数のパターンは `;` で区切ります。空欄なら、すべてのファイルです。
   - **ハッシュ (SHA-256) で比較して値を表示する** を選ぶと、バイトごとの比較の代わりにハッシュで比べ、ハッシュ値を表示します。
4. **比較する** を選びます。

## 結果の見方 {#results}

ファイルは、大文字・小文字を区別せずに相対パスで対応付けます。`SAME.BIN` と `same.bin` は同じファイルです。サイズが違うか、バイトが違えば **異なる** です。バイトは 1 つずつ比べ、違いが見つかった時点でそのファイルの比較を止めます。**最初の差分** にそのオフセットが出ます。

一覧には、**状態**・**相対パス**・**左のサイズ**・**右のサイズ**・**最初の差分** が出ます。状態は、**同じ**・**異なる**・**左だけ**・**右だけ**・**読み取りエラー** です。どの状態にも、アイコンと文字が付きます。既定では、同じファイルを隠します。絞り込みを変えると表示できます。

結果は、1 ファイルを比べるたびに出ます。処理センターから比較を取り消せます。読めないファイルやフォルダは **読み取りエラー** として一覧に出し、比較を続けます。

2 つのファイルの違いを見るには、**異なる** の行を選んで <kbd>Enter</kbd> を押すか、ダブルクリックします。2 つのファイルがファイルの比較の画面で開きます。[ファイルの比較](compare.md)も見てください。

見出しをクリックすると並べ替え、CSV / JSON への書き出しもできます。
