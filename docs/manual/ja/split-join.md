# ファイルの分割・結合・インターリーブ

大きなファイルを複数に切り分けたり、複数のファイルをつなぎ直したり、1 つのファイルのバイトを複数のファイルに交互に振り分けたりします。**ツール > ファイルツール** にあります。ストリームで読み書きするので、どんなサイズのファイルでも、使うメモリは一定です。

## ファイルを分割する {#split}

1. **ツール > ファイルツール > 分割** を選びます。コマンドパレットの **ファイルツール: 分割** でも開けます。
2. 入力を選びます。アクティブなドキュメント (未保存の変更を含む内容) か、ファイルです。
3. 分け方を選びます。
   - **サイズで分ける**: 1 ファイルのサイズを入力します (例: `4G`、`1.44M`、`0x10000`)。最後のファイルは残りの長さです。
   - **個数で分ける**: 2〜10,000。各ファイルのサイズは切り上げで均等にします。**サイズを N バイトの倍数にそろえる** に 512 などを入れると、その倍数に切り上げます。
   - **位置で分ける**: オフセットを 1 行に 1 つ入力するか、**ブックマークの位置を使う** にチェックを付けます。
4. **出力フォルダ** (空欄は入力と同じフォルダ) と **ファイル名の形式** を選びます。既定の `{name}.{index:000}` では `big.bin.001`、`big.bin.002` のようになります。`{base}` (拡張子なしの名前)、`{ext}` (点を含む拡張子)、`{index}`、`{index0}`、`{offset}` (開始オフセットの 16 進) も使えます。
5. 必要なら、`copy /b` で結合するコマンドファイルと、元のファイルと各ファイルのハッシュを書いたチェックサムファイルも作れます。
6. オプションの下の要約 (ファイルの数、最初と最後のファイル名、合計サイズ) を確かめて、**分割する** を選びます。

出力先に同名のファイルがあるときは、上書きの前に確認します。出力先の空き容量を先に確かめ、足りなければ始めません。

処理は処理センターに出て、キャンセルできます。キャンセルや失敗のときは、作りかけのファイルを削除します。完成したファイルを残すかどうかを確認します。

## ファイルを結合する {#join}

1. **ツール > ファイルツール > 結合** を選びます。
2. **追加** か、一覧へのドラッグ & ドロップでファイルを足します。`p.bin.001` のような連番のファイルを足すと、`.002`、`.003` ... もまとめて追加するか確認します。
3. **上へ**・**下へ**・ドラッグで順序を変えます。**名前順** と **自然順** (数字を数値として比べる。`file10` が `file9` の後) で並べ替えられます。
4. ファイルの間に何も入れないか、**各ファイルの開始を N バイトの倍数にそろえる** (詰める値の既定は `00`) かを選びます。
5. **結果を新しいドキュメントとして開く** (既定) か **結果をファイルに保存する** を選び、**結合する** を選びます。

新しいドキュメントは、データをコピーせず、元のファイルを指すだけで作ります。大きなファイルをいくつつなげてもすぐに開きます。データは保存したときに初めて書き出します。ファイルに保存する場合は、ストリームで書き出し、処理センターに出ます。読めないファイルがあると、そのファイルを示して、何も結合しません。

## デインターリーブとインターリーブ {#interleave}

インターリーブは、複数の入力から単位ずつ順に取り出してつなぐ処理です。たとえば、8 bit の ROM 2 個で 16 bit のバスを作る機器では、1 つのイメージの偶数番目と奇数番目のバイトを別々の ROM に入れます。

**デインターリーブ** (**ツール > ファイルツール > デインターリーブ**) は、1 つのファイルを N 個に分けます。出力の数 (2〜16) と単位 (1・2・4・8 バイトまたは任意) を選びます。出力 2 個、単位 1 では、`00 11 22 33` が `00 22` と `11 33` になります。出力の名前の既定は `名前.1.拡張子`、`名前.2.拡張子` で、0 から始めたいときは `{index0}` を使います。入力の長さが「個数 × 単位」の倍数でないときは、最後を指定の値 (既定 `FF`) で埋めるか、端数を最後の出力にそのまま入れます。

**インターリーブ** (**ツール > ファイルツール > インターリーブ**) は逆の処理です。ファイルを 2〜16 個、順番どおりに足し、単位を選び、長さが違うときの扱い (短いものを指定の値 (既定 `FF`) で埋める、またはエラーにする) を選びます。結果は新しいドキュメントとして開くか、ファイルに保存します。デインターリーブした結果を、同じ単位と順序でインターリーブすると、元のファイルに戻ります。
