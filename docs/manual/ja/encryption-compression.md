# 暗号化と圧縮

選択範囲を暗号化・復号・圧縮・展開できます。展開・復号したデータは別のタブで編集して、元に書き戻せます。選択していないときはドキュメント全体が対象です。これらのコマンドは 1 つの範囲に使います。マルチ選択・矩形選択には使えません。

## 暗号化と復号 {#encrypt}

1. バイトを選択します。
2. **データ > 暗号化** または **データ > 復号** を選びます。
3. **アルゴリズム** と **モード** を選びます。
4. 鍵、IV またはナンス、ほかの設定 (下で説明します) を入力します。
5. 結果の書き込み先を選び、**暗号化** または **復号** を選びます。

| アルゴリズム | モード | 説明 |
| --- | --- | --- |
| **AES-128**、**AES-192**、**AES-256** | ECB、CBC、CFB8、CFB128、CTR、GCM | GCM は認証付き |
| **ChaCha20-Poly1305** | — | 認証付き。古い Windows では使えません |
| **3DES (TripleDES)**、**DES** | ECB、CBC | 互換のためだけに使います。安全ではない方式である旨が表示されます |
| **RC4** | — | 互換のためだけに使います |

認証付き暗号 (GCM・ChaCha20-Poly1305) は 1 GiB までのデータに使えます。ほかのモードには大きさの上限がありません。大きな範囲はバックグラウンドで処理し、進捗を表示します。取り消すこともできます。

### 鍵 {#key}

- **Hex で入力**: 鍵のバイト列を入力します。長さはアルゴリズムに合わせます (たとえば AES-256 は 32 バイト)。長さが違うと、ダイアログにその旨が表示されます。
- **パスフレーズから作る (PBKDF2-HMAC-SHA256)**: **パスフレーズ**、**反復回数** (既定 600,000)、**ソルト** (Hex) を入力します。ソルトを空欄にすると 16 バイトの乱数を作り、処理の後に表示します。復号に必要なので控えてください。

鍵の欄はパスワードの入力欄です。**表示** を選ぶと入力した内容が見えます。

### IV とナンス {#iv}

CBC・CFB・CTR は 16 バイトの IV を使います (3DES・DES は 8 バイト)。CTR では IV がカウンタの初期値です。GCM・ChaCha20-Poly1305 は 12 バイトのナンスを使います。ECB と RC4 には IV は要りません。暗号化では **乱数で生成** で乱数の IV を入れられます。

### パディング {#padding}

ECB・CBC では **PKCS#7** (既定)、**ゼロ埋め**、**ANSI X9.23**、**ISO 10126**、**なし** を選べます。**なし** では、長さはブロック長の倍数にします。復号でパディングが正しくないときは、**パディングなしで復号する** を選べます。ゼロ埋めは、復号しても取り除きません。

### 認証タグ {#tag}

GCM・ChaCha20-Poly1305 では **追加認証データ** を Hex で入力できます。暗号化では、16 バイトのタグを既定で結果の末尾に付けます。**認証タグを別の欄に表示するだけ** を選ぶと、別の欄に表示します。復号では、タグは既定で選択範囲の末尾 16 バイトです。Hex で入力することもできます。タグが一致しないときは「認証に失敗しました」と表示し、データは変えません。

### 鍵は保存しません {#not-saved}

鍵・パスフレーズ・IV は、設定・履歴・復旧用データ・ログに保存しません。ダイアログを閉じると、鍵のバイト列をメモリから消します。記憶するのは、選んだアルゴリズム・モード・パディングだけです。

## 圧縮と展開 {#compress}

1. バイトを選択します。
2. **データ > 圧縮** または **データ > 展開** を選びます。
3. **形式** を選びます。圧縮では **圧縮レベル** も設定します。
4. 結果の書き込み先を選び、**圧縮** または **展開** を選びます。

形式は deflate (raw)、zlib、gzip、Brotli、zstd、LZ4 (フレーム・ブロック)、LZMA (.lzma)、XZ です。gzip では、ファイル名と更新日時をヘッダに入れられます。

### 形式の自動判別 {#detect}

**自動判別** で展開すると、先頭のバイトから形式を判別します。gzip、zlib、zstd、LZ4 フレーム、XZ、LZMA を判別できます。deflate (raw)、Brotli、LZ4 ブロックには手がかりがありません。判別できなかったときは、ダイアログで形式を選んでください。

展開は圧縮データの終わりで止まります。選択範囲が圧縮データの後ろまで続いているときは、使ったバイト数を表示し、残りは変えません。

### 誤りと大きなデータ {#errors}

- 圧縮データが壊れているときは、誤りのオフセットを表示します。それまでに展開できた分を新しいタブで開けます。
- チェックサム (gzip の CRC-32、zlib の Adler-32、zstd、LZ4) が一致しないときは、結果を使うかを確かめます。
- 展開後のデータが **展開の確認を出す大きさ (MiB)** (既定 4 GiB) を超えると、展開を一時停止し、**続ける** か **中止する** かを確かめます。圧縮爆弾への対策です。中止すると、ドキュメントは変わりません。
- LZ4 のブロック形式で圧縮できるのは 256 MiB までです。大きなデータには LZ4 のフレーム形式を使ってください。

### 圧縮データの範囲を選択 {#select-compressed}

圧縮データの先頭 (たとえば zip のエントリのローカルファイルヘッダの直後) にカーソルを置き、**データ > 圧縮データの範囲を選択** を選びます。カーソル位置から展開を試み、圧縮データの範囲を選択します。形式と展開後の大きさを表示します。データは変えません。

## 結果の書き込み先 {#destination}

- **選択範囲を置き換える**: 結果で範囲を 1 回の編集で置き換えます。<kbd>Ctrl</kbd>+<kbd>Z</kbd> で元に戻せます。圧縮と暗号化の既定です。
- **新しいタブで開く**: 結果を新しいタブで開きます。展開の既定です。

読み取り専用のドキュメントや、長さを変えられないドキュメントでは、結果は新しいタブでだけ開けます。

## 展開・復号したデータの編集 {#derived}

展開・復号の結果を新しいタブで開くと、そのタブは派生ドキュメントになります。タブの見出しには元の範囲と変換が出ます (例: `image.png [0x21-0x1A0 展開]`)。上部の帯には、元のドキュメント、範囲、変換が表示されます。

1. 派生ドキュメントをふつうに編集します。長さを変えてもかまいません。
2. 帯の **元に書き戻す**、またはコマンドパレットの **データ: 元に書き戻す** を選びます。

データをもう一度圧縮・暗号化して、元の範囲を 1 回の編集で置き換えます。元のドキュメントで <kbd>Ctrl</kbd>+<kbd>Z</kbd> を押すと元に戻せます。書き戻した後、帯には新しい範囲が表示されます。

- 復号したデータを書き戻すときは、鍵をもう一度入力します (鍵は保持していないため)。IV は開いたときと同じ値を使います。GCM・ChaCha20-Poly1305 では、同じナンスを使い直すのは安全ではないため、既定で新しいナンスを作ります。新しいナンスは書き戻した後に表示します。データの形式に合わせて、ナンスの保存位置に書き込んでください。
- 派生ドキュメントを開いた後に元の範囲が変更されていたときは、上書きするかを確かめます。
- 長さが変わり、元のドキュメントが長さを変えられないときは、書き戻しません。
- 元のドキュメントを閉じると、派生ドキュメントは通常の新規ドキュメントになり、書き戻せなくなります。

派生ドキュメントからさらに派生ドキュメントを開けます (8 段まで)。
