# デバイス情報と暗号化されたボリューム

作業を始める前にディスクの状態を記録し、ATA ディスクの隠し領域を見つけ、ボリュームが暗号化されているかを調べます。

## HPA と DCO {#hpa-dco}

ATA ディスクは、HPA (Host Protected Area) や DCO (Device Configuration Overlay) で容量の一部を Windows から隠せます。HexEditor は、ディスクが示す容量と本来の容量を比べます。

1. 物理ディスクを開きます (**ファイル > ディスクを開く...**)。
2. **フォレンジック > デバイス > HPA / DCO の確認** を選びます。コマンドパレットで **フォレンジック: HPA と DCO を確認** を実行してもかまいません。
3. **デバイス情報** のパネルが **HPA / DCO** のタブで開きます。

パネルには、ディスクが示す最大 LBA (28 bit と 48 bit)、本来の最大 LBA、DCO で設定された最大 LBA と、HPA・DCO の有無とサイズが出ます。ディスクを開くと、HexEditor は自動でこれを確かめ、隠し領域があれば通知を出します。自動の確認は **設定 > フォレンジック** でオフにできます。

HexEditor が送るのは、情報を読むだけのコマンドです。HPA・DCO を解除することはありません (ディスクを変えてしまうため)。

NVMe のディスクには HPA・DCO がありません。代わりに名前空間のサイズと容量が出ます。

一部の USB 変換や仮想ディスクなどで、コマンドがディスクに届かない場合は、パネルに「このデバイスでは確認できません」と出ます。コマンドが失敗した場合は、ATA のステータスとエラーレジスタの値が出ます。

この情報を読むには、ディスクを開くのと同じ権限が必要です。HexEditor が昇格した補助プロセスでディスクを開いた場合は、補助プロセスが読みます。

## SMART 情報 {#smart}

1. 物理ディスクを開いた状態で、**フォレンジック > デバイス > SMART 情報** を選びます。コマンドパレットで **フォレンジック: SMART 情報を表示** を実行してもかまいません。
2. **SMART** のタブに属性の一覧が出ます。

ATA・SATA のディスクでは、属性ごとに ID、名前、現在値、最悪値、閾値、生の値 (16 進と 10 進)、状態が出ます。現在値が閾値以下になっていると、状態が **注意** になります。HexEditor が知らない属性の名前は **不明** になります。

NVMe のディスクでは、警告ビット、温度、残りの予備領域、使用率、読み書きしたデータ量、電源投入回数・時間、異常終了の回数、メディアのエラー数が出ます。

**デバイス情報** のタブには、モデル名、シリアル番号、ファームウェア、容量、論理・物理のセクタサイズ、接続の種類、回転数、TRIM 対応の有無が出ます。

HexEditor が SMART のセルフテストを始めることはありません (ディスクの状態を変えるため)。

## 書き出しと記録 {#export}

パネルの **JSON に書き出す...** か **テキストに書き出す...** を選ぶと、情報を保存できます。ファイルには、読んだ日時 (UTC。例: `2026-10-07T03:15:42.1234567Z`) とシリアル番号が入ります。

ケースを開いているときは、確認するたびに監査ログに記録され、結果はフォレンジックのレポートの **デバイス情報** の節に入ります。

## 暗号化されたボリューム {#encryption}

HexEditor は、暗号化されたボリュームを見分けてメタデータを表示します。復号はしません。

1. ディスク・ボリューム・ディスクイメージを開きます。
2. コマンドパレットで **フォレンジック: 暗号化の情報を表示** を実行します。**フォレンジック > 暗号化の情報...** を選んでもかまいません。

HexEditor はパーティションごと (パーティション表がないイメージでは全体) に調べます。

- **BitLocker** と **BitLocker To Go**: 暗号化方式 (例: AES-XTS 128)、ボリュームの GUID、作成日時、説明 (コンピューター名と日付)、キー保護機能 (TPM、回復パスワード、スタートアップキー、パスワードなど。GUID と作成日時も)、暗号化の状態。3 つのメタデータの内容が食い違う場合や、壊れているものがある場合は、警告と、読めた項目が出ます。
- **LUKS1** と **LUKS2**: 暗号方式、UUID、キースロットの数。
- **APFS** (FileVault 2): コンテナの中のどのボリュームが暗号化されているか。
- **Core Storage**: パーティションの種類で見分けます。
- **暗号化または圧縮されたデータの可能性**: ファイルシステムの署名がなく、先頭 64 KiB が乱数のように見えるパーティション。VeraCrypt・TrueCrypt のボリュームには署名がないため、ここまでしか分かりません。

暗号化されたボリュームは、ファイルシステムブラウザで開きません。

Windows がロックを解除した BitLocker のボリュームにドライブ文字がある場合は、ボリュームを開けば復号された内容を読めることがダイアログに出て、**論理ボリュームとして開く** のボタンが出ます。選ぶと、`\\.\X:` などのボリュームを開きます。
