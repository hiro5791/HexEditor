# インポートとエクスポート

データを別の形式のテキストから読み込んだり、別の形式で書き出したりします。マイコンのファームウェア (Intel HEX、S-record) や、Base64、ソースコードの配列、ドキュメントに貼るためのダンプなどを扱えます。このページでは、選択範囲をファイルに保存する方法や、選択範囲を新しいタブで開く方法も説明します。

## エクスポートの形式 {#export-formats}

エクスポートは、ドキュメントの内容を、別の形式のファイルとして書き出します。元のドキュメントは変わりません。

1. 書き出す範囲を選択します。ドキュメント全体を書き出すときは、選択は要りません。
2. **ファイル > エクスポート > エクスポート...** を選びます。選択範囲だけなら、**ファイル > エクスポート > 選択範囲をエクスポート...** です。コマンドパレットの **ファイル: エクスポート** でも開けます。
3. **エクスポート** で書き出す範囲を選びます。**ドキュメント全体**、**選択範囲**、**オフセットの範囲** (開始と終わりを式で入力) から選びます。複数の範囲を選んでいるときは、**範囲ごとに別ファイル** か **つなげて 1 つのファイル** を選びます。別ファイルにするときは、**ファイル名の形式** に `{base}`、`{index}`、`{start}` などを使って、範囲ごとに違うファイル名にします。
4. **形式** を選びます。形式ごとの設定が出ます。
5. **プレビュー** で、出力の先頭と、出力のおおよその大きさを確かめます。
6. **保存先** を決めて、**エクスポート** を押します。

形式は、次のものから選べます。

| 形式 | 用途 |
| --- | --- |
| **Intel HEX**、**Motorola S-record** | マイコンのファームウェアなど。アドレスつきの形式 |
| **Base64**、**Base32**、**Ascii85**、**UUEncode**、**Quoted-Printable**、**URL エンコード** | バイト列をテキストにする |
| **Hex テキスト**、**10 進テキスト** | 16 進や 10 進の数字を並べたテキスト |
| **ソースコード** (C、C++、C#、Java、JavaScript、Python、Rust、Go、Pascal、VB.NET) | プログラムに埋め込む配列 |
| **ダンプ** (テキスト、HTML、RTF、TeX、Markdown) | 画面と同じ形の Hex ダンプ。文書や報告書に貼る |
| **バイナリ** | 範囲をそのままのバイト列で書き出す |

主な設定は次のとおりです。形式ごとの設定は、前回の値が記憶されます。

- **Intel HEX**: **1 レコードのデータ長** (初めは 16 バイト)、**アドレスの形式** (自動、I8HEX、I16HEX、I32HEX)、**開始アドレス**、**実行開始アドレス**、**16 進を大文字にする**。ギャップ (同じ値が続く部分) を省略することもできます。
- **Motorola S-record**: データ長、**アドレスの形式** (自動、S1、S2、S3)、**ヘッダ (S0)**、**レコード数 (S5 / S6) を出力する**。
- **Base64 など**: **1 行の文字数** (0 は改行なし)、パディング、**URL セーフ**。
- **Hex テキスト**: **1 行のバイト数**、**区切り**、**接頭辞** (`0x` や `\x` など)、大文字・小文字、**行頭にオフセットを付ける**。
- **ソースコード**: **変数名**、**要素のサイズ**、**10 進で書く**、**1 行の要素数**、**ヘッダファイルとして出す** (C / C++)、**長さの定数を付ける**、**元のファイル名・範囲・作成日時のコメントを付ける**。
- **ダンプ**: **1 行のバイト数**、**グループ化**、**オフセットの列**、**Hex の列**、**テキストの列**、**オフセットの基数**。HTML、RTF、TeX では、**色を付ける (変更バイト・ブックマーク)** ことができます。HTML には **ダークの配色** もあります。

テキストの形式では、**改行** (CRLF か LF) と **文字コード** (UTF-8 の BOM なし / あり、ASCII) も選べます。初めは CRLF と UTF-8 (BOM なし) です。

出力が 1 GB を超えそうなときは、おおよその大きさが出て、確認を求められます。テキストの形式は、元のデータの 2 〜 5 倍の大きさになります。書き出しは、バックグラウンドで進捗付きで行われます。キャンセルすると、書きかけのファイルは残りません。同じ名前のファイルがあるときは、上書きするかどうかを聞かれます。

## インポートの形式 {#import-formats}

インポートは、別の形式のテキストファイルを読み込んで、バイト列に変えます。

1. **ファイル > インポート...** を選びます。コマンドパレットの **ファイル: インポート** でも開けます。ファイルをダイアログにドラッグ & ドロップしてもかまいません。
2. **インポートするファイル** を選びます。形式は、ファイルの先頭の内容から自動で選ばれます。違うときは、**形式** で選び直します。
3. 形式ごとの設定を確認します。
4. **読み込み先** を選びます。
   - **新しいドキュメント** (初めの設定)
   - **カーソル位置に挿入**
   - **カーソル位置から上書き**
5. **プレビュー** で、変換後の先頭のバイトと、サイズ、アドレスの範囲、警告の数を確かめます。
6. **インポート** を押します。

カーソル位置への挿入や上書きは、<kbd>Ctrl</kbd>+<kbd>Z</kbd> 1 回で元に戻せます。

読み込める形式は、エクスポートの形式のうち、ダンプ以外のものです。

- **Intel HEX** と **Motorola S-record**: 各行のチェックサムを確かめます。**アドレスの配置** は、**最小アドレスを先頭にする** (初めの設定) か、**アドレスをそのままオフセットにする** かを選べます。データのないアドレス (ギャップ) は、**ギャップを埋める値** (初めは `FF`) で埋められます。**ギャップにブックマークを付ける** をオンにすると、ギャップの場所にブックマークが付きます。同じアドレスに複数のデータがあるときは、初めは誤りとして一覧に出ます。**重複したアドレスは後のデータを優先する** をオンにすると読み込めます。
- **Base64** などのエンコード形式: **空白・改行を無視する**、**パディングなしを許す**、**+ を空白として扱う** (URL エンコード) などの設定があります。PEM の囲みの行は、自動で取り除かれます。
- **Hex テキスト**: 空白、カンマ、`0x`、`\x`、改行で区切られた数字を読みます。**ダンプから読み取る** をオンにすると、`xxd` や `hexdump -C` の出力などから、オフセットとテキストの列を取り除いて読めます。
- **10 進テキスト**: 空白、カンマ、セミコロン、改行で区切られた 10 進の数を読みます。**1 つの値のサイズ**、**符号あり**、**ビッグエンディアン** を指定します。
- **ソースコード**: 配列の定義から数値を取り出します。16 進、10 進、8 進、`'A'` のような文字、`"..."` の文字列を読めます。要素のサイズは型の名前から推定されます。**要素のサイズ** で変えられます。
- **バイナリ**: ファイルをそのまま読みます。

形式の誤り (チェックサムの不一致、不正な文字など) があると、行、列、理由の一覧が **誤りと警告** に出ます。誤りを無視して読み込むか、キャンセルするかを選べます。初めはキャンセルです。

Intel HEX、S-record、Base64 のファイルは、**ファイル > 開く** で開くこともできます。その場合は、デコードされたバイナリがドキュメントとして開き、保存するときに元の形式に戻されます。くわしくは、[ファイルを開く](opening-files.md)を見てください。

## 範囲をファイルに保存する {#extract-range}

選択範囲だけを、バイナリのファイルとして保存できます。ファイルの一部を切り出したいときに便利です。

1. 保存したい範囲を選択します。
2. **ファイル > エクスポート > 選択範囲をバイナリで保存...** を選びます。コマンドパレットの **ファイル: 選択範囲をファイルに保存** でも実行できます。
3. 保存先を選びます。

選択範囲のバイトが、そのまま新しいファイルに書かれます。元のドキュメントは変わりません。形式を変えたいときや、複数の範囲を扱いたいときは、[エクスポートの形式](#export-formats)で **選択範囲** を選びます。

## 選択範囲を新しいタブで開く {#open-in-new-tab}

選択範囲を、新しいタブで、独立したドキュメントのように開けます。巨大なファイルの一部だけを編集したいときに便利です。範囲の大きさに関係なく、すぐに開きます。

1. 開きたい範囲を選択します。
2. **ファイル > 選択範囲を新しいタブで開く** から、開き方を選びます。コマンドパレットからも実行できます。ブックマークのパネルでは、ブックマークを右クリックして **新しいタブで開く** を選びます。

開き方は 2 つあります。

| 開き方 | 内容 |
| --- | --- |
| **連動ビュー** | 親のドキュメントの範囲を表示します。編集は親に反映されます。長さは変えられず、上書きだけです。<kbd>Ctrl</kbd>+<kbd>Z</kbd> は、親でも子でも同じ履歴に効きます。保存すると、親が保存されます。タブの名前は `data.bin [0x1000–0x1FFF]` のようになります。親のタブを閉じると、子のタブも閉じます。親の範囲が全部削除されると、「元の範囲が削除されました」と出ます |
| **コピーとして** | 範囲の内容を持つ、名前のないドキュメントを作ります。親とは独立していて、長さも変えられます。保存は **名前を付けて保存** です。親のファイルが後で変わっても、内容は開いたときのままです |

複数の範囲を選んでいるときは、最初の範囲を開くか、範囲ごとにタブを開くかを聞かれます。
