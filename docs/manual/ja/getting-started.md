# はじめに

このページでは、HexEditor をインストールし、ファイルを開いて書き換え、保存するまでを説明します。

## 動作環境 {#requirements}

- Windows 10 バージョン 1809 以降、または Windows 11。
- x64 または ARM64 の PC。
- .NET と Windows App SDK のインストールは要りません。どの版にも含まれています。

## 版を選ぶ {#choose-an-edition}

HexEditor には 3 つの版があります。機能は同じです。違うのは、インストールと更新の方法、設定の保存先です。

| | Microsoft Store 版 | インストーラ版 | ポータブル版 |
| --- | --- | --- | --- |
| 入手先 | Microsoft Store | GitHub Releases の `Setup.exe`、または winget | GitHub Releases の `.zip` |
| インストールに管理者権限 | 不要 | 不要 | 不要 (インストールしない) |
| 更新 | Microsoft Store | アプリの中で自動 | 自分でフォルダを入れ替える |
| 設定の保存先 | アプリ専用の保存場所 | `%LocalAppData%\HexEditorData\` | `HexEditor.exe` の隣の `Data` フォルダ |
| Explorer のメニューとファイルの関連付け | インストール時に追加 | インストール時に追加 | 設定で追加したときだけ |

迷ったら Microsoft Store 版を選んでください。

物理ディスクを開くなど、管理者権限が必要な機能があります。インストーラ版とポータブル版は、その機能を使うときだけ許可を求めます。Microsoft Store 版では、アプリ全体を管理者として実行すると使えます。詳しくは [管理者権限](opening-files.md#administrator) を見てください。

## インストールする {#install}

### Microsoft Store 版 {#install-store}

1. Microsoft Store を開き、**HexEditor** を検索します。
2. **入手** (または **インストール**) を選びます。
3. スタートメニューから HexEditor を起動します。

### インストーラ版 {#install-installer}

1. GitHub Releases のページから `HexEditor-<版>-x64-Setup.exe` をダウンロードします (ARM64 の PC では `-arm64-` のもの)。
2. ダウンロードしたファイルを実行します。今のユーザーに HexEditor をインストールし、起動します。途中で何も聞かれません。

winget でもインストールできます。

```text
winget install Hiroyura.HexEditor
```

インストーラ版はスタートメニューに HexEditor を追加します。デスクトップにショートカットは作りません。削除するときは、Windows の **設定 > アプリ > インストールされているアプリ** を使います。

### ポータブル版 {#install-portable}

1. GitHub Releases のページから `HexEditor-<版>-x64-portable.zip` (または `-arm64-` のもの) をダウンロードします。
2. zip を好きなフォルダに展開します。USB ドライブでもかまいません。
3. `HexEditor` フォルダの `HexEditor.exe` を実行します。

ポータブル版は、データをすべて `HexEditor.exe` の隣の `Data` フォルダに保存します。設定で Explorer のメニューやファイルの関連付けを追加しない限り、レジストリを変えません。削除するときは、先にそれらを解除してから (フォルダの `README.txt` を参照)、フォルダを削除します。

## 初めての起動 {#first-start}

ファイルを開いていないときは、スタートページが出ます。ファイルを開く、新規作成、ディスクを開く、プロセスを開くのボタンと、最近使ったファイルの一覧があります。

初めて起動したときは、スタートページに **はじめに** の欄も出ます。ここで表示言語、テーマ、ショートカットのプリセットを選べます。既定のままでもかまいません。あとで設定から変えられます。**閉じる** を選ぶと消えます。

## ファイルを開く {#open-a-file}

次のどれかで開きます。

- <kbd>Ctrl</kbd>+<kbd>O</kbd> を押すか、**ファイル > 開く** を選び、ファイルを選びます。
- Explorer からファイルをウィンドウにドラッグ & ドロップします。
- Explorer でファイルを右クリックし、**HexEditor で開く** を選びます。

HexEditor は、どんなに大きなファイルもすぐに開きます。画面に出ている部分だけを読むので、数百 GB のファイルでも待ちません。

## Hex ビューの見方 {#read-the-hex-view}

Hex ビューには 3 つの列があります。

- **オフセット**: その行の最初のバイトの位置。ファイルの先頭から数えます。
- **Hex 列**: 各バイトの値を 16 進数で表示します。
- **テキスト列**: 同じバイトを文字で表示します。

カーソルは、矢印キー、<kbd>Page Up</kbd>、<kbd>Page Down</kbd>、<kbd>Home</kbd>、<kbd>End</kbd> で動かします。<kbd>Ctrl</kbd>+<kbd>Home</kbd> と <kbd>Ctrl</kbd>+<kbd>End</kbd> で、ファイルの先頭と末尾に移動します。<kbd>Tab</kbd> で、カーソルが Hex 列とテキスト列の間を移ります。

下のステータスバーには、カーソルの位置、選択範囲、編集のモード、変更があるかどうかが出ます。

位置を指定して移動するには、<kbd>Ctrl</kbd>+<kbd>G</kbd> を押してオフセットを入力します (例: `0x1F00`)。検索するには <kbd>Ctrl</kbd>+<kbd>F</kbd> を押します。

## 書き換える {#make-a-change}

1. 書き換えたいバイトにカーソルを動かします。
2. 新しい値を入力します。Hex 列では 16 進数 (`0`〜`9`、`A`〜`F`) を、テキスト列では文字を入力します。

起動したときは上書きモードです。入力すると今のバイトを置き換え、ファイルサイズは変わりません。<kbd>Insert</kbd> を押すと挿入モードになり、新しいバイトを追加します。

変更したバイトは色が変わります。<kbd>Ctrl</kbd>+<kbd>Z</kbd> で元に戻し、<kbd>Ctrl</kbd>+<kbd>Y</kbd> でやり直します。ファイルを開いてからの変更は、すべて元に戻せます。

## 保存する {#save}

<kbd>Ctrl</kbd>+<kbd>S</kbd> を押すか、**ファイル > 保存** を選びます。別のファイルに保存するには、**ファイル > 名前を付けて保存** を選びます。

保存するまで、元のファイルは変わりません。保存のときは、いったん一時ファイルに書いてから元のファイルと置き換えます。保存に失敗しても、元のファイルは壊れません。

## コマンドを探す {#find-any-command}

<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd> (または <kbd>F1</kbd>) で、コマンドパレットが開きます。コマンドの名前の一部 (例: `ハッシュ`) を入力し、<kbd>Enter</kbd> で実行します。各コマンドのショートカットも表示されます。
