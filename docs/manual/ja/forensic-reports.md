# フォレンジックのレポート

ケースの HTML または PDF のレポートを作ります。ケースの情報、証拠とハッシュ、ブックマーク、カービングの結果、監査ログをまとめられます。

## レポートを作る {#create}

1. ケースを開きます。
2. **フォレンジック > レポートを作成...** を選びます。
3. 含める項目をオンにします。データがない項目は出しません。
4. **HTML** か **PDF** を選びます。PDF では、用紙を A4 かレターから選びます (縦向き)。
5. 監査ログを絞るときは、**監査ログの全件** をオフにして、開始と終了を UTC で入力します。ブックマークごとの Hex ダンプのバイト数も指定できます (0〜4096。既定は 64)。
6. 保存先 (既定はケースの `reports` フォルダ) を確かめて、**作成** を押します。

レポートには次の項目を入れられます。表紙 (ケース番号、ケース名、調査者名、組織名、作成日時とタイムゾーン、アプリの名前と版)、証拠一覧 (ハッシュと検証結果)、取得の記録、デバイス情報、パーティション、ファイルシステム、ブックマーク (各位置の Hex ダンプ付き)、カービングの結果、監査ログです。

HTML のレポートは、スタイルを中に含んだ 1 つのファイルで、ネットワークから何も読み込まないので、オフラインで開けます。PDF のレポートは、すべてのページにケース番号とページ番号を入れます。

日時は UTC を先に示し、その後ろにローカル時刻とタイムゾーン名を並べます。言語はアプリの表示言語に従います。

長い一覧は先頭の 1,000 行を表示し、全件はレポートの隣に CSV ファイルで保存します。PDF では長い一覧をさらに短く切り、全件は HTML のレポートか CSV を使うよう案内します。PDF を作れなかったときは、代わりに HTML のレポートを作って理由を示します。

作り終えると、レポートの SHA-256 をメッセージに表示します。同じ値を監査ログにも記録するので、後でレポートが変更されていないことを示せます。メッセージの **開く** または **フォルダを開く** で確認できます。

自分のロゴと 1 行の文を先頭に出すには、**設定 > フォレンジック** で指定します。
