# データ演算

**データ** メニューには、選択したバイトを一度にまとめて書き換える機能があります。たとえば、全バイトに 1 を足す、XOR の鍵をかける、エンディアンを入れ替える、文字コードを変換する、といった作業です。

どの演算も、バイトを同じ大きさの「要素」の並びとみなして、要素ごとに計算します。演算の結果は 1 回の編集になるので、<kbd>Ctrl</kbd>+<kbd>Z</kbd> 1 回で元に戻ります。ファイルの長さは変わりません。ただし、ビットの挿入・削除 (後述) と、文字コード変換では、長さが変わることがあります。

## データ演算ダイアログの使い方 {#dialog}

1. 対象のバイトを選択します。ドキュメント全体に使うときは、選択は要りません。
2. **データ > データ演算...** を選びます。
3. **分類** と **演算** を選びます。
4. 設定を決めて、下のプレビューを確認します。
5. **実行** を押します。

直前の演算を同じ設定でもう一度行うときは、**データ > 前回のデータ演算を繰り返す** を選びます。ダイアログは開かず、今の選択範囲に実行されます。コマンドパレットからは、**データ演算: 加算** のように、演算ごとに実行できます。

ダイアログの共通の設定は次のとおりです。

| 設定 | 内容 |
| --- | --- |
| **対象範囲** | **選択範囲**、**ドキュメント全体**、**範囲を指定** (開始と長さ)。複数の範囲を選んでいるときは、範囲ごとに要素を数えます |
| **要素の型** | **符号なし整数**、**符号付き整数**、**浮動小数点**。浮動小数点は、算術演算と制限だけで使えます |
| **要素の大きさ (バイト)** | 整数は 1、2、4、8。浮動小数点は 4、8。初めは 1 です |
| **エンディアン** | **リトルエンディアン** か **ビッグエンディアン**。初めはドキュメントの設定です |
| **オペランド** | 演算に使う値。`0x10` や式を入力できます。浮動小数点では `0.5` や `1e-3` も入力できます |
| **オペランドの増分** | 1 要素処理するごとにオペランドに足す値。初めは 0。たとえば、加算でオペランド 0、増分 1 にすると、i 番目の要素に i を足します |
| **処理する要素の数 (N)** と **飛ばす要素の数 (M)** | 「N 個を処理して、M 個を飛ばす」を繰り返します。初めは 1 と 0 です |
| **範囲ごとの増分** | 複数の範囲を選んでいるとき、増分を **範囲ごとにやり直す** か **範囲をまたいで続ける** かを選びます |

プレビューには、対象の先頭 64 バイトの変更前と変更後が出ます。何バイトが変わるかも出ます。範囲の長さが要素の大きさの倍数でないときは、「最後の N バイトは要素に満たないため変更しません」と出て、端数のバイトは変わりません。

結果は、全部できあがってからドキュメントに反映されます。キャンセルしたときや、途中で失敗したときは、ドキュメントは変わりません。4 MiB を超える範囲は、バックグラウンドで進捗付きで実行されます。大きな範囲では、一時的に同じ大きさの空き容量が要ります。足りないときは、実行されずに、必要な容量が出ます。値が変わらない設定のときは、「データは変わりません」と出ます。

読み取り専用のドキュメントでは、使えません。

### 右クリックメニューから使う {#context-menu}

バイトを選んで右クリックし、**データ演算** を選ぶと、サブメニューが開きます。

- **データ演算...**: データ演算ダイアログを開きます。
- **算術**、**ビット演算**、**シフト・ローテート**、**並べ替え**、**制限**、**ビットの挿入・削除**: 分類ごとの演算の一覧です。演算を選ぶと、その演算を選んだ状態でダイアログが開きます。

**並べ替え** の演算は、選択範囲があれば、ダイアログを開かずにすぐ実行します。読み取り専用のドキュメントでは、**データ演算** は使えません。

## 算術演算とビット演算 {#arithmetic}

### 算術演算 {#arithmetic-ops}

分類で **算術** を選びます。

| 演算 | 結果 |
| --- | --- |
| **加算** | x + オペランド |
| **減算** | x − オペランド |
| **逆減算** | オペランド − x |
| **乗算** | x × オペランド |
| **除算** | x ÷ オペランド (整数は 0 方向に切り捨て) |
| **逆除算** | オペランド ÷ x (x が 0 の要素は変えません) |
| **剰余** | x を割った余り (整数のみ) |
| **符号反転** | −x (オペランドなし) |
| **絶対値** | \|x\| (符号付き整数と浮動小数点のみ) |

整数では、結果が要素の範囲を超えたときの扱いを、**あふれたときの扱い** で選びます。

- **ラップ** (初めの設定): 要素の大きさで切り捨てます。符号なし 1 バイトで `FF` に 2 を足すと `01` になります。
- **飽和**: 要素の最小値か最大値で止めます。同じ例では `FF` のままです。

完了すると、あふれた要素の数が知らされます。浮動小数点では、NaN や ∞ になった要素の数が知らされます。0 で割ることはできません。増分によって途中で除数が 0 になる場合も、実行前に知らされます。

### ビット演算 {#bitwise-ops}

分類で **ビット演算** を選びます。**AND**、**OR**、**XOR**、**NOT**、**NAND**、**NOR**、**XNOR** が使えます。

**オペランドの指定** は、次のどちらかです。

- **数値**: 要素の大きさの値。
- **バイト列の鍵**: Hex、テキスト、ファイル、クリップボードから入力します。1 バイトから 16 MiB までです。要素は 1 バイトになり、鍵を繰り返して使います。**鍵の起点** で、範囲の先頭から使うか、オフセット 0 から数えるかを選びます。**鍵の増分 (1 周ごと)** で、鍵を 1 周するたびに各バイトへ足す値も指定できます。

同じ設定で XOR を 2 回実行すると、元のデータに戻ります。XOR で暗号化や難読化されたデータを調べるときに便利です。

## シフトとローテート {#shift-and-rotate}

分類で **シフト・ローテート** を選びます。

| 演算 | 内容 |
| --- | --- |
| **左シフト** | ビットを左へずらす。空いたビットは 0 |
| **右シフト (論理)** | ビットを右へずらす。空いたビットは 0 |
| **右シフト (算術)** | ビットを右へずらす。空いたビットには符号ビットを入れる |
| **左ローテート** | ビットを左へ回す。はみ出したビットは右から戻る |
| **右ローテート** | ビットを右へ回す。はみ出したビットは左から戻る |

**ビット数** に、ずらす量を入力します。たとえば、1 バイトの `81` を左ローテート 1 にすると `03` になり、右ローテート 1 にすると `C0` になります。

**回転量の増分** を指定すると、処理する要素ごとに回す量が増えていきます。i 番目の要素の量は、(ビット数 + i × 増分) を要素のビット数で割った余りです。たとえば、ビット数 1、増分 1 の左ローテートで、`01 01 01` は `02 04 08` になります。

範囲全体を 1 つのビット列として動かしたいときは、シフトではなく、ビットの挿入・削除を使います (後述)。

## バイトスワップと反転 {#byte-swap}

分類で **並べ替え** を選びます。エンディアンの変換に便利です。

| 演算 | 例 |
| --- | --- |
| **バイトスワップ (16 bit)** | 2 バイトごとに順序を逆にする。`01 02` → `02 01` |
| **バイトスワップ (32 bit)** | 4 バイトごと。`01 02 03 04` → `04 03 02 01` |
| **バイトスワップ (64 bit)** | 8 バイトごと |
| **16 bit ワードのスワップ (32 bit 内)** | 4 バイトの前半と後半を入れ替える。`01 02 03 04` → `03 04 01 02` |
| **バイト順を反転** | 範囲全体の順序を逆にする。`01 02 03` → `03 02 01` |
| **ビット順の反転 (各バイト)** | 各バイトのビットを逆順にする。`01` → `80` |
| **ニブルの入れ替え (各バイト)** | 上位と下位の 4 ビットを入れ替える。`12` → `21` |

バイトスワップは、要素の大きさを演算が決めます。端数が出たときは、端数のバイトは変わらず、注記が出ます。コマンドパレットからも、**バイトスワップ (32 bit)** のように実行できます。

範囲全体の反転は、大きな範囲でも実行できます。バックグラウンドで進みます。

## 最小値・最大値での制限 {#limits}

分類で **制限** を選びます。各要素の値を、指定した範囲に収めます。

1. **最小値** と **最大値** を入力します。片方だけでもかまいません。**制限しない** を選ぶと、その側は制限されません。
2. 最小値より小さい要素は最小値に、最大値より大きい要素は最大値になります。

たとえば、符号なし 1 バイトで、最小値 `0x10`、最大値 `0x80` にすると、`00 50 FF` は `10 50 80` になります。浮動小数点の NaN は変わりません。最小値が最大値より大きいときは、実行できません。完了すると、変更した要素の数が知らされます。

## ビットの挿入・削除 {#bit-insert-delete}

分類で **ビットの挿入・削除** を選ぶと、データを 1 本のビット列とみなして、ビット単位でずらせます。ビット単位でずれたデータを揃えるときに使います。

1. **演算** で **ビットを挿入** か **ビットを削除** を選びます。
2. **位置 (バイトのオフセット)** と **バイト内のビット** (7 が最上位)、**ビット数** を入力します。挿入のときは、**埋める値** (0 か 1) も指定します。
3. **ずらす範囲** を選びます。**選択範囲の中だけ** は、長さが変わらず、はみ出したビットは捨てられます。**ドキュメントの末尾まで** は、長さが変わります。
4. **ビットの並び順** で、最上位ビットから数えるか、最下位ビットから数えるかを選びます。

位置より後ろのデータをすべて書き直すので、ずらす範囲が 1 GiB を超えるときは、確認が出ます。長さを変えられないドキュメントでは、**選択範囲の中だけ** を使います。

## 文字コードの変換 {#encoding-conversion}

選択範囲のバイト列を、ある文字コードの文字列として読み、別の文字コードに書き換えます。たとえば、Shift_JIS を UTF-8 に変えたり、ASCII と EBCDIC を相互に変えたりできます。

1. 変換したいバイトを選択します。
2. **データ > 文字コード変換...** を選びます。
3. **変換元の文字コード** と **変換先の文字コード** を選びます。初めは、変換元が今の表示の文字コード、変換先が UTF-8 です。
4. 必要なら、下の設定を変えます。
5. プレビューを確認して、**変換** を押します。

| 設定 | 内容 |
| --- | --- |
| **変換元で解釈できないバイト列** | **最初の箇所でエラーにして中止する** (初めの設定)、**U+FFFD に置き換える**、**そのまま残す** |
| **変換先で表せない文字** | **最初の箇所でエラーにして中止する** (初めの設定)、**? に置き換える**、**指定した文字に置き換える** |
| **変換元の先頭の BOM を取り除く** | 初めはオンです |
| **変換先に BOM を付ける** | 初めはオフです |
| **改行の変換** | **そのまま** (初めの設定)、CRLF、LF、CR |
| **Unicode の正規化** | **しない** (初めの設定)、NFC、NFD、NFKC、NFKD |

プレビューには、変換前後の先頭のバイトと、変換後の長さの見込み (「12 バイト → 18 バイト」など) が出ます。

文字コードによって、変換後の長さが変わります。その場合、選択範囲が変換結果で置き換わります。長さを変えられないドキュメントでは、変換後の長さが同じ場合だけ実行できます。

エラーで止まったときは、ドキュメントは変わりません。最初の問題の箇所のオフセットと文字が出ます。**そのオフセットへ移動** で、その場所へ移れます。

## 大文字・小文字の変換 {#case-conversion}

英字の大文字と小文字は、**データ > 大文字・小文字の変換** で変えられます。**大文字に**、**小文字に**、**大文字と小文字を入れ替える** から選びます。

初めの設定では、ASCII の英字 (`a`〜`z` と `A`〜`Z`) のバイトだけが変わり、長さは変わりません。「文字コードに従う」方法では、表示の文字コードで読んで、Unicode の規則で変換します。コマンドパレットには、方法ごとのコマンド (「大文字と小文字を入れ替える (ASCII の英字だけ)」など) があります。
