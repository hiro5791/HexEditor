# 移動とナビゲーション

このページでは、目的の位置へすばやく移動する方法を説明します。オフセットを入力する移動、戻る・進む、セクタ単位の移動、ブックマークの説明を読む位置マネージャを取り上げます。

## オフセットへ移動 {#go-to-offset}

1. <kbd>Ctrl</kbd>+<kbd>G</kbd> (**移動 > オフセットへ移動**) を押します。エディタの上に移動バーが開きます。ステータスバーのカーソル位置を選んでも開きます。
2. オフセットか式を入力します。入力欄の横に、解釈した結果が出ます (例: `= 0x1F00 (7,936)`)。
3. <kbd>Enter</kbd> で移動します。バーは閉じ、フォーカスはエディタに戻ります。

- <kbd>Shift</kbd>+<kbd>Enter</kbd>: 移動して、バーを開いたままにします。続けて何か所も見るときに便利です。
- <kbd>Esc</kbd>: 移動せずに閉じます。
- 移動先がファイルの外のときは、入力欄が赤くなり、理由が出ます。
- 前回の入力が、全選択された状態で入っています。<kbd>↑</kbd> <kbd>↓</kbd> で、過去の入力 (20 件まで) を呼び出せます。
- **選択しながら移動** をオンにすると、今の位置から移動先までを選びます。

ファイルの先頭と末尾へは、<kbd>Ctrl</kbd>+<kbd>Home</kbd> と <kbd>Ctrl</kbd>+<kbd>End</kbd> (**移動 > ファイルの先頭** / **ファイルの末尾**) でも移動できます。

コマンドパレットの入力欄に、`:` に続けてオフセットを入力しても、移動できます (例: `:0x1F00`)。

移動のあとは、移動先の行が見えていればスクロールしません。見えていないときは、移動先が見える位置にスクロールします。

## オフセットの書き方 {#offset-formats}

オフセット、長さ、範囲を入力する欄は、すべて同じ書き方を使えます。

### 数値

| 書き方 | 意味 | 例 |
| --- | --- | --- |
| `0x` で始まる | 16 進 | `0x1F00` |
| `h` で終わる | 16 進 | `1F00h` |
| `$` で始まる | 16 進 | `$1F00` |
| `0b` で始まる | 2 進 | `0b1010` |
| `0o` で始まる | 8 進 | `0o777` |
| 何もつかない / `d` で終わる | 10 進 | `4096`、`4096d` |
| `_` を含む | 桁の区切り (無視) | `0x1_0000` |
| `K` `M` `G` `T` で終わる | 1024 の倍数 | `4K` は 4096、`1.5G` |

### 式

足し算 (`+`)、引き算 (`-`)、掛け算 (`*`)、割り算 (`/`)、剰余 (`%`)、ビット演算 (`&` `|` `^` `~` `<<` `>>`)、括弧を使えます。次の名前も使えます。

| 名前 | 意味 |
| --- | --- |
| `cur` | カーソルの位置 |
| `start` | ファイルの先頭 (0) |
| `end` | ファイルの末尾 (ファイルの長さ) |
| `sel.start` | 選択範囲の先頭のバイト |
| `sel.last` | 選択範囲の最後のバイト |
| `sel.end` | 選択範囲の直後 |
| `sel.len` | 選択範囲の長さ |
| `sector` | セクタサイズ |
| `bm.名前` | その名前のブックマークの位置 |

`u32le(0x3C)` のように、`u8`、`u16le`、`u32be`、`u64le` などの関数で、その位置の値を読めます。ヘッダに書かれたポインタをたどるときに便利です。

### 相対と絶対

移動バーで **基準** を選べます。

- **自動** (既定): `+` か `-` で始まる入力はカーソルから、それ以外は先頭からの位置です。
- **先頭から**
- **カーソルから**: 入力した値をカーソルの位置に足します (負の値も可)。
- **末尾から**: ファイルの末尾から数えます。

例を挙げます。

| 入力 | 移動先 |
| --- | --- |
| `0x1F00` | 先頭から 0x1F00 |
| `+0x100` | 今の位置から 0x100 先 |
| `-16` | 今の位置から 16 手前 |
| `end-0x10` | 末尾の 0x10 手前 |
| `sel.end` | 選択範囲の直後 |
| `u32le(0x3C)+4` | オフセット 0x3C にある 32 bit の値に 4 を足した位置 |

**単位** で、入力した値の単位を **バイト** (既定)、**行**、**セクタ** から選べます。たとえば、単位がセクタで `100` を入力すると、100 セクタ目の先頭に移動します。

ベースアドレスを設定しているときは、**アドレスで指定** と **オフセットで指定** を切り替えられます。

## 戻ると進む {#back-and-forward}

ジャンプする前の位置は、記録されます。Web ブラウザのように、戻ったり進んだりできます。

- <kbd>Alt</kbd>+<kbd>←</kbd> (**移動 > 戻る**): 前の位置に戻ります。
- <kbd>Alt</kbd>+<kbd>→</kbd> (**移動 > 進む**): 戻る前の位置に進みます。
- **移動 > 履歴**: 最近の 20 件を、アドレスとその位置の 8 バイトと一緒に一覧にします。選ぶと、その位置に移ります。

次の操作が、履歴に記録されます。

- オフセットへ移動、ファイルの先頭と末尾への移動
- セクタ・ページ・レコード単位の移動
- 検索の次と前の一致への移動、検索結果の一覧からの移動
- ブックマークへの移動
- ミニマップや画像表示のクリック
- マウスのクリックで、1 画面以上離れた場所に移ったとき

矢印キー、<kbd>Page Up</kbd> / <kbd>Page Down</kbd>、スクロールは、記録されません。履歴は、ペインごとに 100 件まで残ります。挿入や削除をしても、記録した位置は、データに合わせてずれます。履歴は、アプリを終了すると消えます。

## セクタ単位の移動 {#sectors}

ディスクやディスクイメージを、セクタ単位で動くときに使います。セクタサイズは、ディスクではデバイスの値、ファイルでは 512 バイトです ([ディスクイメージとして開くとき](opening-files.md#disk-images) は、選んだ値になります)。**表示 > オフセットの基数 > セクタサイズ** で変えられます。

- **移動 > 次のセクタ**: 次のセクタの先頭に移ります。
- **移動 > 前のセクタ**: セクタの途中にいるときは、そのセクタの先頭に移ります。先頭にいるときは、ひとつ前のセクタの先頭です。
- **移動 > セクタへ移動**: 移動バーが **セクタ** の単位で開きます。セクタ番号を入力します。

移動したセクタの先頭の行が、画面の一番上に出ます。ディスクでは、ステータスバーに今のセクタ番号が出ます。

オフセット列も、セクタの単位で表示できます。**表示 > オフセットの基数 > セクタ** を選ぶと、`15:100` のように、セクタ番号と、セクタの中の位置で出ます ([表示の設定](hex-view.md#display-settings))。

セクタごとに線を引くには、**表示 > 区切り線 > セクタ** を使います。プロセスのメモリでは、コマンドパレットの **移動: 次のメモリ領域** と **移動: 前のメモリ領域** で、読める領域の先頭に移動できます。

## 位置マネージャ {#position-manager}

位置マネージャは、ブックマークに付けた長い説明 (コメント) を、読み書きするためのパネルです。解析した内容を記録しながら作業するときに使います。

1. **移動 > ブックマーク > 位置マネージャ** を選びます。右側にパネルが開きます。
2. 一覧から、ブックマークを選びます。エディタが、その位置に移動します。
3. コメントの欄に、説明を書きます。プレビューも見られます。

- 一覧は、ブックマークを位置の順に並べたものです。ブックマーク一覧と同じデータなので、コメントを直すと、ブックマーク一覧にも反映されます。
- エディタでカーソルを動かすと、そのカーソルを含むブックマークが、一覧で選ばれます。
- **説明のあるものだけ** で、コメントがあるものに絞れます。
- Hex ビューのブックマークの範囲に、マウスを 0.5 秒合わせると、名前、範囲、コメントが吹き出しで出ます。キーボードでは、**移動 > ブックマーク > カーソル位置の説明を表示** を使います。
- 内容は、Markdown または HTML のファイルに書き出せます。

ブックマークそのものの作り方は、[ブックマークと注釈](bookmarks.md) を見てください。ブックマークの位置へは、<kbd>F2</kbd> (次) と <kbd>Shift</kbd>+<kbd>F2</kbd> (前) で順に移動できます。<kbd>Ctrl</kbd>+<kbd>F2</kbd> で、今の位置にブックマークを付けたり外したりします。
