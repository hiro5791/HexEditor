# HexEditor マニュアル

HexEditor は Windows 向けのバイナリエディタです。どんなに大きなファイル・ディスク・プロセスのメモリも開けて、バイトを表示・編集・検索・解析できます。

初めて使うときは、[はじめに](getting-started.md) から読んでください。
