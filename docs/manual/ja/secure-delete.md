# 安全な削除

ファイルの内容を別のデータで上書きしてから削除し、一般的な復元ツールでは元に戻せないようにします。取り消せないので、注意して使ってください。

## ファイルを安全に削除する {#delete}

1. **ツール > ファイルツール > 安全な削除** を選びます。コマンドパレットの **ファイルツール: 安全な削除** でも開けます。
2. **追加** と **フォルダを追加** か、一覧へのドラッグ & ドロップで、削除するファイルとフォルダを足します。フォルダは、中のファイルをすべて対象にします。
3. 上書きの方式を選びます。

   | 方式 | 書き込む内容 |
   | --- | --- |
   | **0 で 1 回** (既定) | `00` を 1 回。 |
   | **乱数で 1 回** | 暗号論的な乱数を 1 回。 |
   | **DoD 5220.22-M (3 回)** | `00`、`FF`、乱数の順に 3 回。 |
   | **任意** | 1〜35 回。1 回分を 1 行に書きます。`A5 5A` のような 16 進のバイト列か `random`。行が回数より少ないときは、最後の行を繰り返します。 |

   **最後の上書きを読み戻して確認する** にチェックを付けると、最後の上書きを書いた後に確かめます (乱数の回は確かめません)。
4. **削除** を選びます。確認ダイアログに、ファイルの数・合計サイズ・方式が出ます。**完全に削除する** で進めるか、**キャンセル** で戻ります。

ファイルごとに、排他で開き、全体を上書きして各回の後にディスクへ書き出し、長さを 0 にし、ランダムな名前に変えてから削除します。ごみ箱には入りません。NTFS の代替データストリームも同じ方式で上書きします。

処理は処理センターに出ます。キャンセルすると、上書きの途中だったファイルは削除せずに残し、内容が壊れていることをお知らせします。他のプログラムが使っているなどで開けない・書けないファイルは飛ばし、最後に理由と一緒に一覧で示します。

## できないこと {#limits}

- SSD・USB メモリ・SD カードでは、ウェアレベリングのため、上書きしても元のデータが別の場所に残ることがあります。
- ボリュームシャドウコピー、バックアップ、OneDrive などの同期フォルダ、圧縮・暗号化・重複除去されたファイル、ReFS などのコピーオンライトのファイルシステムでは、元のデータが残ることがあります。
- 空き領域とスラック領域は消去しません。消去するには [安全な消去](secure-wipe.md) を参照してください。

## 削除できないもの {#rules}

- HexEditor で開いているファイル。先にタブを閉じてください。
- `C:\Windows` や `Program Files` などのシステムフォルダと、ドライブのルート。
- 書き込み保護モードの間のすべて。メニュー項目は無効になり、理由が出ます。
