# ハッシュとチェックサム

ハッシュは、データから計算する短い値です。データが少しでも変わると、値も変わります。ファイルが壊れていないか、配布元のファイルと同じかを確かめるときに使います。このページでは、選択範囲やドキュメント全体のハッシュ・チェックサムを計算する方法を説明します。

## ハッシュを計算する {#calculate}

1. **解析 > ハッシュ** を選びます。**ハッシュ** パネルが開きます。**表示 > パネルの表示切り替え > ハッシュ** やコマンドパレットの **解析: ハッシュを計算** でも開けます。選択範囲を右クリックして **ハッシュを計算** を選んでもかまいません。
2. **対象範囲** を選びます。**選択範囲**、**マルチ選択**、**ドキュメント全体**、**範囲を指定** のどれかです。範囲を指定するときは、**開始** と、**長さ** か **終了 (このバイトを含む)** を入力します。空欄にすると末尾までです。
3. 計算したいアルゴリズムにチェックを付けます。
4. **計算** を押します。

結果の表に、アルゴリズムの名前、値、ビット数が出ます。複数のアルゴリズムを選んでも、データの読み込みは 1 回で済みます。

覚えておくことがあります。

- 計算はバックグラウンドで行われ、進捗と速度 (MB/s) が出ます。計算中も、スクロールや編集ができます。**キャンセル** すると、途中までの結果は捨てられます。
- **自動で再計算** をオンにすると、対象範囲が変わって 0.3 秒後に計算し直します。対象が 64 MB を超えるときは、自動では計算せず、**計算** が強調されます。
- ドキュメントを編集すると、「結果は編集前の内容のものです」と出ます。**再計算** で計算し直します。
- 前回と値が変わった行には、**変更** の印が付きます。
- 読めない場所があると、計算を止めて「オフセット ... を読み込めないため計算できません」と出ます。**読めない範囲を除外範囲に追加** で、その範囲を除いて計算できます。

### マルチ選択のとき

複数の範囲を選んでいるときは、**マルチ選択** の **計算方法** を選びます。

- **連結して 1 つの値を求める**: オフセットの小さい順につなげて、1 つの値にします。
- **範囲ごとに値を求める**: 範囲ごとの行が出ます。

### 除外範囲

計算に含めない範囲を指定できます。たとえば、チェックサムが入っている欄そのものを除いて計算したいときに使います。

1. **除外範囲** を開き、**開始** と **長さ** を入力して **追加** を押します。**選択範囲を追加** で、今の選択範囲を加えることもできます。
2. **除外の方法** を選びます。**飛ばす** は、その範囲のバイトを入力に含めません。**値に置き換える** は、その範囲のバイトを指定の値 (初めは `0x00`) とみなして計算します。

対象範囲の外にある除外範囲には警告が出て、計算では無視されます。

### 表示を変える

- **表示形式**: **Hex 大文字** (初めの設定)、**Hex 小文字**、**Base64**、**10 進** (64 bit 以下)。
- **バイト順 (64 bit 以下)**: **ビッグエンディアン (数値)** か **リトルエンディアンのバイト列**。

### 結果をコピーする・保存する

- 行の **値をコピー** で値をコピーします。「名前: 値」の形や、チェックサムファイルの形式 (`<値> *<ファイル名>`) でもコピーできます。
- **すべてコピー** で、すべての行を「名前: 値」、チェックサムファイル形式、JSON、CSV のどれかでコピーできます。
- **チェックサムファイルとして保存...** で、`.sha256` などのチェックサムファイルを保存できます。`sha256sum -c` で確かめられる形です。
- **カーソル位置に書き込む...** で、計算した値のバイト列をカーソル位置に書き込めます。ファイルにチェックサムを入れる作業に使います。値が 64 bit 以下のときは、バイト順を選びます。書き込みは上書きで、<kbd>Ctrl</kbd>+<kbd>Z</kbd> 1 回で戻せます。書き込み先が計算の対象範囲に含まれているときは、値が変わるため警告が出ます。コマンドパレットの **解析: ハッシュ値をカーソル位置に書き込む** からも実行できます。

## アルゴリズム {#algorithms}

アルゴリズムの一覧は、グループごとに折りたためます。**アルゴリズムを絞り込む** の欄に名前を入力して探せます。

| グループ | 主なもの |
| --- | --- |
| **チェックサム** | 加算 8 / 16 / 32 / 64 bit、ワード単位の加算、インターネットチェックサム、XOR |
| **CRC** | CRC-8、CRC-16 (ARC、MODBUS、CCITT など)、CRC-24、CRC-32 (標準、CRC-32C、BZIP2、MPEG-2 など)、CRC-64。別名でも探せる |
| **非暗号学的ハッシュ** | Adler-32、Fletcher、FNV、xxHash、MurmurHash、SipHash など |
| **暗号学的ハッシュ** | MD5、SHA-1、SHA-224 / 256 / 384 / 512、SHA-3、RIPEMD、Whirlpool、Tiger、BLAKE2、BLAKE3 など |

MD5 や SHA-1 などには、「安全ではありません (改ざんの検出には使わないでください)」と注記が出ます。壊れていないかの確認には使えますが、改ざんを見つける用途には SHA-256 以上を使ってください。Whirlpool などの遅いアルゴリズムを選ぶと、全体の速度がそれに合わせて遅くなります。そのことが行の注記に出ます。

この環境で使えないアルゴリズムは、一覧で無効になり、理由が出ます。

アルゴリズムの組み合わせは、**セット** として選べます。初めから、次のセットがあります。

- **よく使う**: CRC-32、MD5、SHA-1、SHA-256
- **暗号学的ハッシュ**
- **チェックサム**

自分の組み合わせは、アルゴリズムを選んでから **セットを保存** で、名前を付けて残せます。

アルゴリズムによっては、行の **設定** で値を指定します。

- 加算チェックサム: **結果の補数** (**なし**、**1 の補数**、**2 の補数**)。ワード単位のものは、ワードのエンディアンと符号も選べます。
- xxHash や MurmurHash など: **シード**。
- SipHash や BLAKE2 など: **鍵 (Hex)**、**出力長 (bit)**。

指定した値は、結果の行に `xxHash64 (seed=0x1234)` のように出ます。入力が正しくない行は、その行だけ計算されません。

## カスタム CRC {#custom-crc}

一覧にない CRC は、自分で定義できます。

1. **解析 > カスタム CRC を定義** を選びます。ハッシュパネルのアルゴリズム一覧の **カスタム CRC を追加...** でも開けます。
2. 次の項目を入力します。数は `0x8005` のように入力できます。
   - **名前**: 一覧に出る名前。ほかのアルゴリズムと重ならないようにします。
   - **幅 (width)**: 1〜64 ビット。
   - **多項式 (poly)**、**初期値 (init)**、**最終 XOR (xorout)**
   - **入力の反転 (refin)**、**出力の反転 (refout)**
3. 入力すると、`123456789` に対する値 (check) と、residue がその場で出ます。資料の値と合っているかを確かめてください。
4. **保存** を押します。

既存のプリセットを選んで **複製して編集** すると、近い設定から始められます。

定義した CRC は、設定に保存され、すべてのドキュメントで使えます。アルゴリズム一覧の **エクスポート...** と **インポート...** で、JSON ファイルとして書き出したり、取り込んだりできます。取り込むファイルに正しくない項目があると、何件目が読めないかが出て、正しい項目だけが取り込まれます。

## 期待する値との照合 {#compare-hashes}

配布元が公開しているハッシュ値と、計算した値が同じかどうかを確かめられます。

### 値を貼り付けて照合する

1. ハッシュを計算します。
2. パネルの下の **照合** の **期待値** に、公開されている値を貼り付けます。
3. 計算した結果のうち、同じ値の行に **一致** と出ます。違うときは **不一致** です。

期待値は、Hex (大文字・小文字、空白・`:`・`-` 区切り、`0x` 付きのどれでも)、Base64、チェックサムファイルの 1 行のどれでも貼り付けられます。表記の大文字・小文字や区切りは無視して比べます。64 bit 以下の値は、バイト順を逆にした値とも比べ、その場合は **一致 (バイト順が逆)** と出ます。

結果は、色だけでなく、印と文字でも分かります。

### チェックサムファイルで検証する

1. **チェックサムファイルで検証...** を押します。コマンドパレットの **解析: チェックサムファイルで検証** でも実行できます。
2. `.md5`、`.sha1`、`.sha256`、`.sha512`、`.sfv` のチェックサムファイルを選びます。
3. ドキュメントのファイル名に合う行が探されて、照合されます。アルゴリズムは、ファイルの拡張子と値の長さから決まります。

ファイルに該当する行がないときは、「このファイルの行が見つかりません」と出て、ファイルの中の行を選べます。

### 値だけが分かっているとき

アルゴリズムが分からないときは、**一致するアルゴリズムを探す** を使います。

1. **期待値** に値を貼り付けます。
2. **一致するアルゴリズムを探す** を押します。コマンドパレットの **解析: 一致するアルゴリズムを探す** でも実行できます。
3. 確認の表示を読んで、**探す** を押します。

長さが同じすべてのアルゴリズム (CRC のプリセット、自分で定義した CRC、チェックサムのオプションの組み合わせを含む) で計算して、一致したものが一覧に出ます。範囲が 1 MiB を超えるときは、かかる時間の目安が出ます。
