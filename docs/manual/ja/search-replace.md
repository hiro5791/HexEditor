# 検索と置換

このページでは、バイト列・文字列・数値の検索、すべて検索、置換、複数のファイルの検索を説明します。検索は、バックグラウンドで進みます。進み具合を見ながら、キャンセルもできます。数百 GB のファイルも検索できます。

## 検索バー {#find-bar}

検索バーは、エディタの上に重ねて出る帯です。ダイアログではないので、開いたまま編集を続けられます。

1. <kbd>Ctrl</kbd>+<kbd>F</kbd> (**検索 > 検索**) を押します。選択範囲が 1〜256 バイトのときは、その内容が検索欄に入ります。
2. **検索の種類** を選び、検索欄に入力します。
3. <kbd>Enter</kbd> で次の一致、<kbd>Shift</kbd>+<kbd>Enter</kbd> で前の一致に移動します。

| 操作 | キー |
| --- | --- |
| 次を検索 | <kbd>Enter</kbd> または <kbd>F3</kbd> |
| 前を検索 | <kbd>Shift</kbd>+<kbd>Enter</kbd> または <kbd>Shift</kbd>+<kbd>F3</kbd> |
| すべて検索 | <kbd>Alt</kbd>+<kbd>Enter</kbd> |
| 検索履歴をたどる | <kbd>↑</kbd> <kbd>↓</kbd> |
| 実行中の検索を取り消す。実行中でなければバーを閉じる | <kbd>Esc</kbd> |

- 一致した範囲が選択され、画面の中ほどに表示されます。
- 見えている範囲の一致は、すべて強調されます。検索欄の右に、一致の件数と今の番号が出ます。1 GiB を超える範囲では、**件数を数える** を選んだときだけ数えます。
- バーを閉じても、<kbd>F3</kbd> と <kbd>Shift</kbd>+<kbd>F3</kbd> で、最後の条件で検索できます。
- 検索欄の横に、検索語をバイト列にした結果の先頭が表示されます。たとえばテキスト `AB` を UTF-16 で検索するときは、`41 00 42 00` と出ます。
- 検索語が正しくないとき (Hex が奇数桁など) は、検索欄が赤くなり、理由が出ます。
- **入力しながら検索** (既定はオン) では、入力のたびに、バーを開いたときの位置から探し直します。<kbd>Esc</kbd> で閉じたとき、元の位置に戻すには **Esc で元の位置に戻る** をオンにします。
- 読み込めない部分に当たったときは、**飛ばして続ける** か **検索を中止する** かを選べます。いつも同じ動作にするには、設定の **検索中に読み込めないデータがあったとき** を使います。

検索の条件は、ウィンドウごとに覚えられています。タブを切り替えても残ります。

## テキストと Hex のバイト列の検索 {#text-and-hex}

### Hex のバイト列

**検索の種類** を **Hex** にして、`DE AD BE EF` のようなバイト列を入力します。空白、カンマ、`0x`、`\x` は、区切りとして読まれるので、`DEADBEEF` も `0xDE,0xAD` も同じです。桁数は偶数にします。

検索できる長さは、1 バイトから 1 MiB までです。

### テキスト

**検索の種類** を **テキスト** にして、探す文字列を入力します。入力した文字列は、**文字コード** で選んだ文字コードのバイト列にして探します。

- **文字コード** の既定は、**表示中の文字コードに合わせる** です。UTF-8、UTF-16 LE / BE など、すべての文字コードから選べます。
- **複数** を選ぶと、最大 8 種類の文字コードで、同時に探せます。文字コードが分からないデータで便利です。既定の組み合わせは ASCII、UTF-8、UTF-16LE、UTF-16BE です。名前を付けて保存できます。
- **大文字と小文字を区別する** は、既定でオフです。全角の英字は大文字と小文字を同じとみなしますが、全角と半角、ひらがなとカタカナは区別します。
- **単語単位で探す** は、前後が文字や数字ではない一致だけを見つけます。
- **エスケープを使う (\\n、\\xHH)** をオンにすると、`\n`、`\t`、`\0`、`\xHH`、`\uHHHH` を書けます。
- **文字の境界に揃える** は、UTF-16 / UTF-32 の一致の位置を、2 / 4 の倍数のオフセットに絞ります。

選んだ文字コードで表せない文字があるときは、その文字を示してエラーにします。

## 数値の検索 {#numbers}

**検索の種類** で **整数** か **浮動小数点** を選ぶと、数値をバイト列にして探します。値には、`0x1F`、`-1`、`4K` のような式を入力できます。

### 整数

- **整数のサイズ**: 8、16、24、32 (既定)、48、64 bit。
- **符号**: **符号あり**、**符号なし**、**どちらでも** (既定)。
- **エンディアン**: **リトルエンディアン**、**ビッグエンディアン**、**両方**。既定は、ステータスバーの表示に合わせます。
- 値の範囲を探すには、`1000..2000` のように入力します (両端を含みます)。**除外** をオンにすると、範囲に入らない値に一致します。

### 浮動小数点

- **形式**: half (16 bit)、float (32 bit、既定)、double (64 bit)。
- **許容誤差**: **誤差なし** (既定)、**絶対誤差**、**相対誤差**、**ULP**。計算の結果として少しずれた値を探すときに使います。相対誤差は、割合 (`0.001` など) で入力します。
- `1.5e-3`、`inf`、`-inf`、`nan` も入力できます。小数点は、いつも `.` です。

### ビットマスクと位置の条件

- **Hex** の検索で **ビットマスク** をオンにすると、決めたビットだけを比べます。**ビットパターン (0 1 x)** では、`1xx0 0001` のように書きます (`x` は無視)。**値とマスク** では、Hex で値とマスクを入力します。
- **位置の条件** を使うと、一致の位置が「オフセット mod x = y」を満たすものだけを探せます。**2 の倍数**、**4 の倍数**、**8 の倍数**、**16 の倍数**、**セクタの先頭** のボタンがあります。どの種類の検索でも使えます。

## ワイルドカードと正規表現 {#wildcards}

### Hex のワイルドカード

**Hex** の検索語に、次の書き方を使えます。

- `??`: 任意の 1 バイト (例: `DE AD ?? EF`)
- `?`: 任意の 1 ニブル (4 bit)。`A?` は、上位が A のバイトです。
- `*`: 0 バイト以上の任意の並び。長さは、設定の **一致の最大の長さ** (既定 4,096 バイト) までです。

先頭と末尾の `??` は無視されます。`??` だけの検索語は使えません。

### 正規表現

- **正規表現 (テキスト)**: 文字コードで読んだ文字に対して探します。ECMAScript (JavaScript) に近い書き方で、`i` (大文字小文字を区別しない)、`m`、`s` のフラグを使えます。
- **正規表現 (バイト列)**: 各バイトを 1 文字として探します。バイトは `\xHH` で書き、`[\x00-\x1F]` のように範囲も使えます。`.` は、任意のバイトに一致します。

構文が正しくないときは、位置と理由が出ます。後戻りが必要な書き方 (後方参照、先読み、後読み) を使うと、時間がかかり過ぎる範囲を飛ばすことがあります。長さ 0 の一致は報告されません。

### 一致しない箇所を探す

**Hex** の検索で **一致しない箇所を探す** をオンにすると、パターンの繰り返しから外れた場所を探します。`00` や `FF` で埋まった領域を飛ばして、データの始まりを見つけられます。

## 検索の条件と範囲 {#options}

| 項目 | 内容 |
| --- | --- |
| **方向** | **前方** (既定) か **後方**。<kbd>Enter</kbd> に働きます。<kbd>F3</kbd> は常に前方、<kbd>Shift</kbd>+<kbd>F3</kbd> は常に後方です |
| **折り返す** | 末尾まで探して見つからなかったら、先頭に戻って続けます (既定はオン) |
| **検索範囲** | **ドキュメント全体** (既定)、**選択範囲**、**オフセット範囲**、**開いているすべてのドキュメント** |
| **重なる一致を含める** | `AAAA` の中の `AA` のように、重なった一致も数えます (既定はオフ) |

**オフセット範囲** では、**開始** と **終了 (このバイトを含む)** を入力します。`0x100` や `end-0x10` のような式を使えます。範囲の端をまたぐ一致は、見つかりません。**選択範囲** を選んでいる間は、その範囲が薄い枠で示されます。

検索履歴は、検索欄で <kbd>↑</kbd> <kbd>↓</kbd> を押すか、ドロップダウンから呼び出せます。履歴の件数は 50 件です。**検索 > 検索履歴を消去** で消せます。

## すべて検索と結果のパネル {#find-all}

<kbd>Alt</kbd>+<kbd>Enter</kbd> か、検索バーの **すべて検索** で、範囲内の一致をすべて探して、下の **検索結果** のパネルに一覧にします。

- 一覧には、番号、オフセット、長さ、一致したデータ (Hex とテキスト)、前後のデータが並びます。検索の途中でも、見つかった順に出ます。
- 行を選ぶと (<kbd>Enter</kbd> かクリック)、その一致に移動して選択します。<kbd>↑</kbd> <kbd>↓</kbd> で行を動かします。
- 検索結果は、**絞り込み** で絞れ、列の見出しで並べ替えられます。
- 結果のある間、<kbd>F3</kbd> と <kbd>Shift</kbd>+<kbd>F3</kbd> は、一覧の次と前の結果に移動します。
- 一致は、エディタ上にも枠で示されます。ミニマップとスクロールバーにも印が出ます。
- 件数の上限は 1,000,000 件です。上限に達したら止まり、見出しに知らせます。

**変換** のボタンで、結果を使って次のことができます。対象は、**選択した行** か **すべての行** です。

- **選択範囲に**: 一致の範囲を、複数の範囲の選択にします ([複数の範囲の選択](selection-clipboard.md#multiple-selections))。
- **ブックマークに**: 一致ごとにブックマークを付けます ([ブックマークと注釈](bookmarks.md))。
- **CSV でエクスポート** / **JSON でエクスポート**: ファイルに書き出します。
- **一致したデータを Hex でコピー** / **テキストでコピー**: クリップボードに入れます。

設定の **すべて検索の結果を新しいタブに出す** で、結果を検索のたびに別のタブに出すこともできます。

## 置換 {#replace}

<kbd>Ctrl</kbd>+<kbd>H</kbd> (**検索 > 置換**) で、検索バーに **置換後の値** の欄が加わります。

1. 検索欄に探す値を、置換欄に置き換える値を入力します。置換する値の書き方は、検索の種類に合わせます (Hex なら Hex、テキストなら文字、整数なら数値)。
2. **置換** を選ぶと、今の一致を置き換えて、次の一致に移動します。置き換えずに進むなら **スキップ** です。
3. すべてを一度に置き換えるなら **すべて置換** を選びます。

- 1 回の置換は、1 回の操作として元に戻せます。**すべて置換** も 1 回で元に戻ります。
- Hex の置換語に `??` を書くと、その位置の元のバイトを残します。
- 正規表現では、置換語に `$1`、`$<名前>`、`$&` (一致の全体)、`$$` を使えます。
- 置換語を空にすると、一致を削除します。
- 読み取り専用のドキュメントでは、置換できません。
- 一致が 1,000,000 件を超えるときは、置換の前に確認が出ます。

### 長さが違うとき

置換語の長さが、一致の長さと違うときの扱いを、**長さが違う場合** で選びます。

| 選択肢 | 動作 |
| --- | --- |
| **長さを変える** | 挿入や削除をして、ファイルの長さが変わります。ファイルの既定です |
| **埋めて長さを保つ** | 短いときは、**埋め草** で残りを埋めます。長いときはエラーです。ディスクなどの既定です |
| **後ろを上書きする** | 長いときは後ろのバイトを上書きします。短いときは残りをそのままにします |

**埋め草** は、**00 で埋める** (既定)、**FF で埋める**、**空白で埋める**、**指定バイトで埋める** (Hex で 1〜16 バイト) から選べます。

## 複数のファイルの検索 {#multiple-files}

フォルダの中のファイルを、まとめて検索・置換します。

1. <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd> (**検索 > 複数ファイル検索**) を押します。左に **複数ファイル検索** のパネルが開きます。
2. 検索する値と種類を入力します。検索バーの条件をそのまま使うには、**検索バーの条件を使う** を選びます。
3. **対象** に、フォルダを追加します。既定は、今のドキュメントのフォルダです。
4. 必要なら、条件を絞ります。
   - **サブフォルダを含める** (既定はオン)
   - **含めるマスク** (例: `*.bin;*.dat`)、**除外するマスク** (例: `.git;node_modules`)
   - **最小サイズ**、**最大サイズ**
   - **隠しファイル・システムファイルを含める**、**シンボリックリンク・ジャンクションをたどる**
   - **開いているドキュメントを含める** (既定はオン。保存していない編集も検索します)
5. **検索** を選びます。

結果は、ファイルごとにまとめて出ます。行をダブルクリックすると、そのファイルを開いて、一致の位置に移動します。読めなかったファイルは、**スキップしたファイル** に、理由と一緒に出ます。

ファイルを置換するには、パネルの上の **置換** に切り替えます。

1. 検索して、結果を確認します。置換しない行や、ファイルのチェックを外せます。
2. **置換語** と、長さが違うときの扱いを決めます。
3. **置換を実行** を選びます。確認で、**置換して保存する** を選びます。

ファイルは直接書き換えられ、元に戻せません。そのため、**置換の前にバックアップ (.bak) を作る** が、既定でオンです。開いているドキュメントは、ファイルではなくエディタの内容が置き換えられます (保存前なら元に戻せます)。検索のあとで変更されたファイルや、読み取り専用のファイルは、スキップされます。

## 文字列の抽出 {#strings}

データの中から、読める文字が続く場所を、すべて一覧にします。`strings` コマンドと同じ働きです。

1. **検索 > 文字列の抽出** を選びます。下に **文字列の抽出** のパネルが開きます。
2. 設定を決めます。
   - 最小の長さ (既定 4 文字)
   - **文字コード** (ASCII、UTF-8、UTF-16LE、UTF-16BE など。複数選べます)
   - **文字の種類**: **印字可能な文字**、または **印字可能な文字と改行**
   - 範囲 (ドキュメント全体、選択範囲、オフセット範囲)
3. **抽出** を選びます。

一覧には、オフセット、バイト数、文字数、文字コード、文字列が出ます。単語や正規表現で絞り込めます。行を選ぶと、その場所に移動します。すべて検索の結果と同じく、選択範囲やブックマークへの変換、CSV / JSON / テキストへのエクスポートもできます。

## テンプレートの値の検索 {#template-values}

構造体テンプレートを適用した結果の中から、フィールドの名前・型・値に合うものを探せます。テンプレートの結果のパネルの検索欄に、`name:*size* value>0x1000` のような条件を入力します。結果は **検索結果** のパネルに出て、選ぶと、その場所に移動します。詳しくは [構造体テンプレート](templates.md) を見てください。
