# 安全な消去

範囲、ディスク全体、ボリュームの空き領域、ファイルのスラックを上書きして、元のデータを読めなくします。消去は取り消せないので、確認ダイアログで対象をよく確かめてください。

## 方式 {#methods}

どの消去も、[安全な削除](secure-delete.md#delete) と同じ方式を使います。

| 方式 | 書き込む内容 |
| --- | --- |
| **0 で 1 回** (既定) | `00` を 1 回。 |
| **乱数で 1 回** | 暗号論的な乱数を 1 回。 |
| **DoD 5220.22-M (3 回)** | `00`、`FF`、乱数の順に 3 回。 |
| **任意** | 1〜35 回。1 回分を 1 行に書きます。`A5 5A` のような 16 進のバイト列か `random`。 |

処理センターに、何回目か、その回の進み具合、全回数分の残り時間が出ます。

## 選択範囲を消去する {#range}

1. ファイル・ディスクイメージ・ディスク・ボリュームを開き、消去する範囲を選択します。
2. **フォレンジック > 消去 > 選択範囲を消去** を選びます。選択範囲を右クリックして **選択範囲を安全に消去** を選ぶか、コマンドパレットの **フォレンジック: 選択範囲を安全に消去** でも開けます。
3. 開始位置と長さを確かめ、方式を選んで **消去** を選びます。
4. 確認ダイアログに、対象 (ディスクでは番号・モデル名・シリアル番号・容量・含まれるボリューム)、範囲 (開始 LBA・セクタ数・バイト数)、方式と回数、所要時間の目安が出ます。ディスクでは範囲をセクタ境界に広げ、そのことも示します。
5. **N バイトを消去する** で始めるか、**キャンセル** で戻ります。既定のボタンは **キャンセル** なので、<kbd>Enter</kbd> だけでは消去されません。

**最後に読み直して検証する** は既定でオンです。最後の回を書いた後に範囲を読み直し、書いた内容と一致するかを確かめます。一致しない範囲は結果に一覧で出ます。

データは編集としてではなく、ファイルやデバイスに直接書き込みます。<kbd>Ctrl</kbd>+<kbd>Z</kbd> では元に戻せません。消去の後、同じファイルやデバイスを開いているタブは読み直されます。

ドキュメントに未保存の編集があるときは、先に **保存** するか **破棄** するかを選びます。

## ディスク全体を消去する {#disk}

1. 物理ディスク全体をタブで開きます。
2. **フォレンジック > 消去 > ディスクを消去** を選びます。
3. 方式を選んで **消去** を選びます。
4. 確認ダイアログに、ディスクの名前 (例: `ディスク 2`) を入力します。名前が一致するまで **ディスク 2 を消去する** は選べません。

書き込む前に、範囲に重なるボリュームをすべてロックします。プログラムがファイルを開いていてロックできないときは、ディスマウントするかを尋ねます。Windows が使用中のディスク (システム・ブート・ページファイルのあるディスク) は消去しません。

## 空き領域を消去する {#free-space}

削除したファイルの内容が残っている、ボリュームの未割り当て領域を上書きします。

1. **フォレンジック > 消去 > 空き領域を消去** を選びます。コマンドパレットの **フォレンジック: 空き領域を消去** でも開けます。
2. 方法を選びます。
   - **OS 経由 (マウント中のボリューム)**: ボリュームを選びます。ボリュームに一時フォルダを作り、空き容量がなくなるまでパターンを書いたファイルで埋めて、最後に削除します。NTFS では小さいファイルも多数作り、MFT の空きレコードに残っていたデータも上書きします。ボリュームはロックしないので作業を続けられますが、実行中はボリュームの空き容量がなくなります。
   - **直接書き込み (このタブのファイルシステム)**: 先にタブのファイルシステムを表示します ([ファイルシステム](file-systems.md) を参照)。割り当て情報から未割り当てクラスタを求め、直接上書きします。NTFS・FAT12・FAT16・FAT32・exFAT に対応しています。
3. 方式を選んで **消去** を選びます。
4. ボリューム、消去する容量、方法、所要時間の目安を確かめ、**空き領域を消去する** を選びます。

OS 経由の方法をキャンセルしても、一時ファイルは必ず削除します。削除できなかった一時ファイルがあれば、結果にパスが出るので、手動で削除してください。

直接書き込みは、ファイルシステムの割り当て情報が正しくないとファイルを壊すおそれがあります。そのため、先にファイルシステムを確かめます。ボリュームに dirty の印がある (Windows を正しく終了しなかったときなど) か、ほかの不整合が見つかったときは書き込まず、chkdsk で修復してから実行するよう案内します。直接書き込みの前に、タブの編集を保存するか破棄してください。

## スラックを消去する {#slack}

ファイルのスラックは、ファイルの末尾から最後のクラスタの終わりまでの部分です。以前のファイルのデータが残っていることがあります。

1. タブのファイルシステムを表示します。
2. **フォレンジック > 消去 > スラックを消去** を選ぶか、コマンドパレットの **フォレンジック: ファイルスラックを消去** を使います。
3. 方式を選んで **消去** を選びます。確認ダイアログに、対象のファイルの数と消去するスラックの量が出ます。
4. **スラックを消去する** を選びます。

ファイルの内容は変わりません。圧縮・スパース・常駐 (NTFS で MFT の中に入っている小さいファイル) のファイルは対象外にし、その数を結果に示します。

## できないこと {#limits}

- SSD・フラッシュメディアでは、ウェアレベリングのため、上書きしても元のデータが別の場所に残ることがあります。ATA Secure Erase・NVMe Format・Sanitize は実行しません。
- 書き込み保護モードの間は消去できません。証拠一覧のデータソースも消去できません。メニュー項目は無効になり、理由が出ます。
- 消去は、実行・拒否・キャンセルのどれも監査ログに記録します。
