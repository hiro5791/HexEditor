# アクセシビリティ

HexEditor は、マウスを使わなくても、すべての操作ができます。スクリーンリーダー、ハイコントラスト、大きな文字、画面の拡大にも対応します。このページでは、それぞれの使い方を説明します。

## キーボードだけで使う {#keyboard-only}

すべてのコマンドに、キーを割り当てられます。メニューは <kbd>Alt</kbd> か <kbd>F10</kbd> で開き、アクセスキー (メニュー名の下線の文字) で選べます。名前しか分からないコマンドは、<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd> か <kbd>F1</kbd> のコマンドパレットで探せます ([コマンドパレット](settings.md#command-palette))。キーの割り当ては、[ショートカット](settings.md#keyboard-shortcuts) で変えられます。

### 画面の領域を移る

<kbd>F6</kbd> で次の領域に、<kbd>Shift</kbd>+<kbd>F6</kbd> で前の領域に、フォーカスが移ります。領域は、タブ列、エディタ、右のパネル、下のパネル、左のパネル、ステータスバーの順です。

- Hex ビューの中では、<kbd>Tab</kbd> が Hex 列とテキスト列の切り替えに使われます。Hex ビューから出るには、<kbd>F6</kbd> を使います。
- 各領域の中では、<kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd> と矢印キーで移ります。タブ列、ツールバー、ステータスバーは、矢印キーで項目を移ります。
- 画面分割したペインも、<kbd>F6</kbd> で移れます。
- ステータスバーの項目は、<kbd>Enter</kbd> で、クリックと同じ動作をします。

### よく使う操作

- 右クリックメニューは、<kbd>Shift</kbd>+<kbd>F10</kbd> かアプリケーションキーで開きます。
- ダイアログとフライアウトは、<kbd>Esc</kbd> で閉じます。閉じると、元の場所にフォーカスが戻ります。
- 一覧のパネル (ブックマーク、検索結果など) では、<kbd>Enter</kbd> で選んだ項目へ移動、<kbd>Delete</kbd> で削除、<kbd>Space</kbd> で切り替え、<kbd>Esc</kbd> でエディタにフォーカスを戻します。
- 検索バーでは、<kbd>Enter</kbd> で次、<kbd>Shift</kbd>+<kbd>Enter</kbd> で前、<kbd>Esc</kbd> で閉じます。
- フォーカスのある場所には、枠がいつも見えます。

ドラッグでしかできないように見える操作にも、キーボードの手段があります。タブの並べ替えは、コマンドパレットの **タブ: 左へ移動** と **右へ移動** です。画面分割は、<kbd>Ctrl</kbd>+<kbd>\\</kbd> です。パネルの移動は、パネルの **パネルのオプション** のメニューにあります。

Hex ビューの移動と選択のキーは、[Hex ビュー](hex-view.md#moving-the-cursor) と [選択とクリップボード](selection-clipboard.md#select) を見てください。

## スクリーンリーダー {#screen-readers}

ナレーターと NVDA で使えます。Hex ビューは、「16 進エディタ」として読み上げられます。ヘルプテキストとして、「Tab で Hex 列とテキスト列を切り替え」と案内されます。

カーソルを動かすと、位置が読み上げられます。

- 例: 「オフセット 0x1F00、値 4A、文字 J、Hex 列、変更あり、ブックマーク header」
- 値の 16 進数は、1 桁ずつ読まれます。`00` は「ヌル」、表示できない文字は「表示できない文字」と読まれます。
- 上書きと挿入の切り替え、列の切り替え、読み取り専用の切り替え、選択範囲の変化 (「選択 16 バイト、0x1F00 から 0x1F0F」)、長い処理の完了、画面上部のバーのメッセージも読み上げられます。
- キーを押し続けて動かしている間は、読み上げを控えます。止めてから、1 回だけ読み上げます。

読み上げの量は、**ツール > 設定 > アクセシビリティ** の **読み上げの詳しさ** で選べます。

| 選択肢 | 読み上げ |
| --- | --- |
| **詳しく** (既定) | オフセット、値、文字、列、状態 (変更あり、ブックマークなど) |
| **簡潔に** | 値と文字だけ (例: 「4A J」) |
| **オフセットだけ** | オフセットだけ |
| **読み上げない** | 読み上げない |

今の位置を、もう一度聞きたいときは、コマンドパレットの **現在位置を読み上げ** (**表示 > 現在位置を読み上げ**) を実行します。選択範囲とファイルのサイズも読み上げます。

Hex ビューの文字は、スクリーンリーダーから、画面と同じ書式で読めます。メニューやパネルのボタンなど、すべての操作部品に名前が付いています。

## ハイコントラストと文字サイズ {#high-contrast}

### ハイコントラスト

Windows のコントラストテーマ (**設定 > アクセシビリティ > コントラスト テーマ**) を有効にすると、HexEditor は自動で、Windows のシステムの色に切り替わります。再起動は要りません。

- Hex ビューは、配色やバイトテーマを使わず、システムの色だけで表示します。
- 色だけで意味を伝えません。変更されたバイトは下線、検索の一致は枠線、ブックマークは三角形の印、現在行は上下の線、差分は斜線の背景でも示します。
- 色に頼る **バイトテーマ** と、背景素材は、使えなくなります。

ライトとダークは、**表示 > テーマ** で選べます。**Windows の設定に従う** を選ぶと、Windows に合わせて切り替わります。詳しくは [テーマ・フォント・配色](settings.md#appearance) を見てください。

### 文字サイズ

Windows の **設定 > アクセシビリティ > 文字のサイズ** (100〜225%) を大きくすると、メニューやパネルの文字が大きくなります。Hex ビューの文字も大きくなります。ただし、設定の **Windows の文字の大きさに合わせる** をオフにすると、Hex ビューだけは変わりません。画面の文字が切れたり、重なったりしないように作られています。

Windows の **視覚効果 > アニメーション効果** をオフにしていると、HexEditor のアニメーションも止まります。

## ズームと高 DPI {#zoom-and-dpi}

HexEditor には、2 種類のズームがあります。

- **Hex 表示のズーム**: データの文字だけを拡大します。<kbd>Ctrl</kbd>+<kbd>=</kbd>、<kbd>Ctrl</kbd>+<kbd>-</kbd>、<kbd>Ctrl</kbd>+<kbd>0</kbd> (100% に戻す)、<kbd>Ctrl</kbd>+ホイールで変えます。
- **画面全体のズーム**: メニュー、パネル、ダイアログ、ステータスバーを含めた全体を拡大します。**表示 > ズーム** の **画面全体を拡大** などで変えます。

どちらも 50〜400% です。ズームしても、カーソルのあるバイトは、画面に残ります。倍率は、ステータスバーに出ます。選ぶと 100% に戻ります。詳しくは [ズームと全画面表示](hex-view.md#zoom) を見てください。

画面の拡大率が違うモニターの間でウィンドウを動かしたり、Windows の表示スケール (100〜400%) を変えたりしても、Hex ビューは自動で描き直されます。文字はぼやけません。
