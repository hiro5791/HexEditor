# 印刷と PDF

ドキュメントのバイト列を Hex ダンプの形で印刷します。印刷の前にプレビューで確かめることも、同じページを PDF として保存することもできます。

## ドキュメントを印刷する {#print}

1. **ファイル > 印刷** を選ぶか、<kbd>Ctrl</kbd>+<kbd>P</kbd> を押します。コマンドパレットの **ファイル: 印刷** でも開けます。
2. 左で設定を選びます。設定を変えると、右のプレビューもすぐに変わります。
3. **印刷** を選びます。

設定:

| 設定 | 選べるもの |
| --- | --- |
| **プリンタ** | Windows に登録されたプリンタ (**Microsoft Print to PDF** を含む)。最初は Windows の既定のプリンタです。 |
| **印刷範囲** | **すべて**、**選択範囲** (選択があるときだけ。マルチ選択は範囲ごとに新しいページから)、**オフセットの範囲** (`開始:長さ` または `開始..終了`。例: `0:0x1000`、`0x100..0x200`。終了は含みません)、**ページの範囲** (例: `1-3, 8`)。選択があるときは最初に **選択範囲** になります。 |
| **用紙**、**向き** | 用紙の大きさと、縦・横。 |
| **余白** | 0〜50 mm。地域設定がインチの場合は、インチで表示します。 |
| **フォント**、**サイズ** | 等幅フォントと 6〜24 pt。既定は Cascadia Mono の 9 pt です。 |
| **1 行のバイト数** | 4〜64、または **用紙に合わせる** (入る最大の 8 の倍数)。選んだバイト数が用紙に入らないときは、**用紙に合わせる** になります。 |
| **列** | オフセット・Hex・テキストの列。グループ化、オフセットの基数、文字コードは画面と同じです。 |
| **色** | **白黒** は、変更したバイトを下線で、ブックマークと色付けルールを灰色の網掛けで示します。**カラー** は、それらの背景色を印刷します。 |
| **ヘッダ**、**フッタ** | 左・中央・右の文字列。下の記号が使えます。 |
| **部数** | 1〜999。 |

ヘッダの既定は、左にファイル名、右に印刷範囲です。フッタは、中央にページ番号、右に日付です。**既定として保存** を選ぶと、次からこの設定で始まります。

ヘッダとフッタに使える記号は、波括弧で書きます。`{name}` (ファイル名)、`{path}` (フルパス)、`{page}`、`{pages}`、`{date}`、`{time}`、`{range}` (印刷範囲のオフセット)、`{size}` (ドキュメントのサイズ)、`{modified}` (未保存の変更があると「(変更あり)」)。

未保存の変更も印刷されます。印刷は **印刷** を選んだ時点の内容で行うので、印刷中も編集を続けられます。処理は処理センターにページ数で出て、止めることもできます。

### 大きなファイル {#large}

ページ数はファイルのサイズから計算するので、数百 GB のファイルでもダイアログがすぐに開きます。印刷するページと表示しているページだけを読みます。

- 1,000 ページを超えるとき: ページ数を示して確認します。**印刷する** で続けるか、**範囲を変える** でダイアログに戻ります。
- 100,000 ページを超える範囲は、印刷も PDF への保存もできません。範囲を狭めてください。

不良セクタなどで読めない範囲があると、そのバイトは `??` で印刷し、最後にお知らせします。

## 印刷プレビュー {#preview}

**ファイル > 印刷プレビュー** を選ぶか、コマンドパレットの **ファイル: 印刷プレビュー** を実行します。印刷ダイアログの右側もプレビューです。ページの下に「12 / 3,456 ページ」のように出ます。

- ボタン、ページ番号の欄、またはプレビューにフォーカスがあるときの <kbd>Page Up</kbd>・<kbd>Page Down</kbd>・<kbd>Home</kbd>・<kbd>End</kbd> でページを移ります。欄にページ番号を入れて <kbd>Enter</kbd> を押すと、そのページへ移ります。
- **ページ全体**、**幅に合わせる**、50〜400% を選べます。**2 ページ見開き** で見開きにできます。

## PDF として保存する {#pdf}

1. **ファイル > エクスポート > PDF** を選ぶか、コマンドパレットの **ファイル: PDF としてエクスポート** を実行します。印刷ダイアログの **PDF として保存...** でも書き出せます。
2. 設定を選びます。用紙は A4・Letter・A3・Legal から選びます。プリンタと部数は使いません。
3. 保存先を選びます。

PDF の文字は画像ではなくテキストなので、Hex の値を検索したりコピーしたりできます。フォントは使った文字だけを埋め込みます。テキスト列の日本語のように、選んだフォントにない文字は、代わりのフォントで書きます。タイトルはファイル名で、1,000 ページごとにしおりが付きます。いったん一時ファイルに書いてから置き換えるので、失敗しても書きかけの PDF は残りません。

**Microsoft Print to PDF** でも PDF にできますが、**PDF として保存...** のほうがファイルが小さく、文字も検索できます。
