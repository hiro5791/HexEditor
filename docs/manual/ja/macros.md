# マクロ

このページでは、操作を記録して、あとで何度でも再生する方法を説明します。同じ編集を何十回も繰り返すときに便利です。プログラミングは要りません。

マクロは、JavaScript のスクリプトとして保存されます。必要なら、あとから[スクリプトエディタ](scripting.md#script-editor)で手直しできます。

## マクロを記録する {#record}

1. 記録を始めたい状態に、カーソルを動かします。
2. <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>R</kbd> を押します。**ツール > マクロ > 記録の開始 / 停止** や、コマンドパレットの **マクロ: 記録の開始 / 停止** でも始められます。
3. **マクロの記録** のダイアログで、マウスで指した位置の記録方式を選び、**記録を開始** を選びます。
   - **カーソルからの相対** (既定): 記録を始めたときのカーソルからの距離で記録します。別の場所で再生したいときに向いています。
   - **絶対オフセット**: オフセットそのものを記録します。いつも同じ場所を直したいときに向いています。
   - **今後は確認しない (この選択を使う)** にチェックを入れると、次からこのダイアログは出ません。
4. 記録したい操作をします。
5. もう一度 <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>R</kbd> を押して、記録を止めます。ステータスバーの **記録中** を選んでも止められます。

記録中は、ステータスバーに赤い丸と「記録中」の文字、記録した操作の数が出ます。

### 記録されるもの {#what-is-recorded}

マクロは、キー入力そのものではなく、操作の意味を記録します。そのため、表示言語を変えても同じように動きます。

| 操作 | 記録される内容 |
| --- | --- |
| Hex やテキストの入力 | 続けて入力した分が、1 回の書き込みにまとまります |
| カーソルの移動 (矢印、<kbd>Page Up</kbd>、<kbd>Page Down</kbd>、<kbd>Home</kbd>、<kbd>End</kbd>) | 移動と回数。続けた同じ移動はまとまります |
| マウスでのクリックと選択 | 位置の記録方式に従います |
| ダイアログを使う操作 (塗りつぶし、データ演算、置換など) | ダイアログで確定した値。再生のときはダイアログが出ません |
| 検索 | 検索の条件 |
| ファイルを開く、保存 | ファイルのパス |
| タブの切り替え | 「次のタブ」のような相対的な指定 |

### 記録できない操作 {#unrecordable}

次のような操作は、記録できません。ステータスバーに「記録できない操作: 名前」と一時的に出て、その操作は記録されません。

- キーボードでの選択範囲の変更
- 削除
- マルチカーソルでの入力
- 他のアプリとのやりとりや、スクリプトの実行中の操作

選択はマウスで行うか、**移動 > オフセットへ移動** などの操作を使うと、記録できます。

### 記録を保存する {#save-the-recording}

記録を止めると、**マクロを保存** のダイアログが出ます。

1. **名前** を入力します。
2. **保存先** のフォルダを選びます。
3. 必要なら **ショートカット** を入力します (例: <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>F9</kbd>)。省略できます。
4. **保存** を選びます。

**保存しない** を選んでも、記録した内容は「直前のマクロ」として、HexEditor を終了するまで再生できます。

何も操作しないで止めたときは、「記録された操作はありません。」と出て、保存のダイアログは出ません。

## マクロを再生する {#play}

### 1 回再生する {#play-once}

**ツール > マクロ > 直前のマクロを再生**、またはコマンドパレットの **マクロ: 直前のマクロを再生** を選びます。直前に記録した (または再生した) マクロが 1 回実行されます。

保存したマクロは、次のどれからでも実行できます。

- **スクリプト一覧**の **マクロ** のところで、選んで **実行** します。[スクリプト一覧](scripting.md#script-list)を参照してください。
- コマンドパレットに **スクリプト: 名前** で出ます。
- 保存のときや、スクリプト一覧の **ショートカットの割り当て** で付けたキー。

自分で記録して保存したマクロは、実行のときに信頼の確認は出ません。ただし、保存したあとに外部のエディタで書き換えると、通常のスクリプトと同じように確認が出ます。

### 繰り返し再生する {#play-repeatedly}

1. **ツール > マクロ > 繰り返し再生** を選びます。コマンドパレットの **マクロ: 繰り返し再生** でも開けます。
2. **マクロ** を選びます。
3. 繰り返しかたを選びます。
   - **回数を指定**: **回数** に 1〜1,000,000 の数を入力します。
   - **ファイルの末尾に達するまで**: カーソルが末尾に達するか、動けなくなったら止まります。
   - **検索結果ごと**: 検索結果の各位置にカーソルを置いて、1 回ずつ実行します。
   - **選択範囲の中で**: カーソルが選択範囲の外に出たら止まります。
4. **再生** を選びます。

繰り返し再生は、全体が 1 つの [元に戻す](editing.md#undo-redo)の単位です。1 万回繰り返したあとでも、<kbd>Ctrl</kbd>+<kbd>Z</kbd> を 1 回押すと、全部が戻ります。

再生中の様子は処理センターに出ます。回数の進捗と **停止** のボタンがあります。長い繰り返しでも、画面は固まりません。

再生の途中で操作が失敗すると (たとえば検索で見つからない、範囲の外に出る)、そこで止まります。「マクロが 3 回目の「検索」で止まりました」のように、何回目のどの操作で止まったかが出ます。

ヒント: 回数を間違えて再生しても、保存する前なら <kbd>Ctrl</kbd>+<kbd>Z</kbd> で全体を戻せます。大切なファイルでは、再生の結果を確かめてから保存してください。

## マクロをスクリプトとして保存する {#save-as-script}

保存したマクロは、`.js` のスクリプトのファイルです。マクロのフォルダに入り、スクリプト一覧の **マクロ** に並びます。

**スクリプト一覧** でマクロを選んで **編集** を選ぶと、スクリプトエディタで開けます。次のようなことができます。

- 記録された値を書き換える (たとえば、書き込むバイトを変える)。
- 操作の順序を入れ替える、足す、消す。
- 繰り返しや条件分岐を書き足す。

記録された内容には、操作ごとにコメントが付いています。たとえば、次のようになります。

```javascript
// ==HexEditorScript==
// @name  マクロ 2026-10-07 14:03
// @api   1.0
// ==/HexEditorScript==
let doc = app.activeDocument;
// オフセットへ移動
doc.goTo(doc.cursor + 0x10);
// 塗りつぶし
await app.commands.execute("edit.fill", { range: "sel", pattern: "00" });
```

スクリプトの書きかたは、[スクリプト](scripting.md)のページを参照してください。
