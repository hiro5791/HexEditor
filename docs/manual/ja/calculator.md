# 電卓とプログラマモード

電卓は、式を計算して、結果を 16 進・10 進・8 進・2 進で同時に表示します。オフセットの入力欄と同じ書き方で式を書け、開いているドキュメントの値も使えます。プログラマモードでは、ビット幅、ビットの表、ビット演算が加わります。

## 電卓を開く {#open}

**ツール > 電卓** を選びます。コマンドパレットの **ツール: 電卓** でも開けます。電卓はパネルとして開くので、編集の邪魔になりません。ドキュメントを開いていなくても使えます。

## 式を計算する {#expressions}

1. **式** に式を入力します。例: `0x1F00 + 10h * 2`。入力しながら結果が更新されます。式が途中のときは、前の結果が薄く表示されます。
2. <kbd>Enter</kbd> を押すと、式が履歴に加わります。

数値、単位 (`4K`、`1.5G`)、演算子、名前 (`cur`、`end`、`sel.len`、`bm.header`)、読み取り関数 (`u32be(0x3C)`) は、オフセットの入力欄と同じです。ドキュメントがないときに名前や読み取り関数を使うと、エラーになります。

電卓だけで使える書き方もあります。ほかの入力欄では使えません。

| 書き方 | 意味 |
| --- | --- |
| `ans` | 直前の結果 |
| `u16(x)`、`u32(x)`、`u64(x)`、`s16(x)` から `s64(x)` | オフセット `x` の値を、アクティブなドキュメントのバイト順で読む |
| `min(a, b)`、`max(a, b)`、`abs(a)` | 小さい方、大きい方、絶対値 |
| `align(a, n)` | `a` を `n` の倍数に切り上げる |
| `popcnt(a)`、`clz(a)`、`ctz(a)` | 1 のビットの数、上位の 0 のビットの数、下位の 0 のビットの数 |
| `rol(a, n)`、`ror(a, n)`、`bswap(a)` | ビットの回転、バイト順の反転 |
| `==`、`!=`、`<`、`<=`、`>`、`>=` | 比較。結果は 1 か 0 |

整数は 64 bit の符号付きで計算します。結果が収まらないときは **桁あふれ** と表示し、値は折り返します。`1.5 + 1` のように小数点を含む数値は、小数として計算します。小数点は、地域設定によらず常に `.` です。0 での割り算と、64 以上のシフトはエラーです。

式に誤りがあると、入力欄が赤枠になり、誤りの位置と説明が表示されます。

## 結果を見る {#results}

表には、16 進、10 進、8 進、2 進 (4 桁ごとに区切る)、`1.5 GiB` のようなファイルサイズ表記で結果が出ます。結果が負のときは、符号なしの 10 進も出ます。10 進の桁区切りは地域設定に従います。各行の **コピー** ボタンは、桁区切りなしの値をコピーします。

## 結果を使う {#use}

- **この位置へ移動** は、カーソルを結果の位置へ移します。
- **選択範囲の長さにする** は、カーソルからその長さを選択します。
- **カーソル位置に書き込む** は、結果をカーソル位置に書き込みます。先にサイズ (1・2・4・8 バイト) とバイト順を選びます。<kbd>Ctrl</kbd>+<kbd>Z</kbd> を 1 回押すと元に戻ります。

## 履歴 {#history}

電卓は、直近の 1,000 件の式と結果を覚えていて、HexEditor を再起動しても残ります。項目を選ぶと、その式が入力欄に戻ります。

## プログラマモード {#programmer}

**プログラマ** を選びます。コマンドパレットの **ツール: 電卓 (プログラマモード)** でも切り替えられます。

1. **ビット幅** (8・16・32・64 ビット) と **符号付き** を選びます。結果はビット幅で折り返します。たとえば、8 ビット・符号付きでは `0x7F + 1` は `-128` です。
2. **ビットの表** にすべてのビットが並び、下にビット番号が出ます。ビットをクリックするか、移動して <kbd>Space</kbd> を押すと反転します。ほかの基数の表示も更新されます。ビット間の移動は <kbd>←</kbd> と <kbd>→</kbd> です。
3. ビットの上をドラッグするか、<kbd>Shift</kbd> を押しながら <kbd>←</kbd> または <kbd>→</kbd> を押すと、範囲を選べます。表の下に、そのビットフィールドの値と、取り出す式 (例: `(x >> 4) & 0xF`) が出ます。
4. ボタンで、**オペランド** との **AND**・**OR**・**XOR**・**NAND**・**NOR** と、現在の値への **NOT**・シフト・回転・**符号反転**・**バイトスワップ** を実行します。
5. **カーソル位置から読む** は、ビット幅ぶんのバイトを、選んだバイト順で読み込みます。

各ビットには、スクリーンリーダー用に「ビット 31、値 1」のような名前が付いています。
