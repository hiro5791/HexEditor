# 書き込み保護

調べている証拠を HexEditor が変えないようにします。このページでは、書き込み保護モードと、USB ストレージへの書き込みを止める Windows の設定を説明します。

## 書き込み保護モード {#mode}

書き込み保護モードは、このアプリが開いているものへの書き込みをすべて止めます。証拠を開く前に有効にしてください。

1. **フォレンジック > 書き込み保護モード** を選びます。コマンドパレットで **フォレンジック: 書き込み保護モードの切り替え** を実行してもかまいません。
2. ステータスバーの左端に錠のアイコンと **書き込み保護** が出ます。ウィンドウのタイトルに **[書き込み保護]** が付き、各タブに錠が付きます。

モードが有効な間は、次のようになります。

- すべてのドキュメントが読み取り専用になり、解除できません。入力・削除・貼り付け・塗りつぶし・データ演算は使えません。
- 書き込みのために開いていたディスク・ボリューム・プロセスのメモリは、読み取り専用で開き直します。新しく開くディスクとファイルも、読み取り専用で開きます。
- **保存** は使えません。未保存の変更は残ります。**名前を付けて保存** で、証拠以外の場所に保存できます。
- 安全な削除と、代替データストリームの作成・削除は使えません。ツールチップに、書き込み保護モードが有効であることが出ます。消去、クローン、セクタ範囲の復元、パーティション表の書き込みも使えません。
- ディスクを読む昇格した補助プロセスも、書き込み・ロック・ディスマウントの要求をすべて拒否します (誤って要求が届いた場合も同じです)。

HexEditor 自身のデータ (設定、復旧用データ、一時ファイル、監査ログ、作成したイメージとレポート) は書き込みます。それらの出力先を証拠の上に置くことはできません。

書き込み保護モードが止めるのは、このアプリだけです。Windows や他のアプリは書き込めます (Windows がボリュームをマウントするときなど)。初めてモードを有効にしたときに、このことを知らせる通知が出ます。ハードウェアの書き込み防止装置か、[OS の USB 書き込み保護](#usb) も併せて使ってください。

モードは HexEditor を再起動しても有効のままです。起動するたびに有効にするには、**設定 > フォレンジック** の **起動時に常に書き込み保護モードを有効にする** をオンにします。HexEditor を `--write-block` を付けて起動してもかまいません。最初のドキュメントを開く前にモードが有効になります。

## モードを解除する {#turn-off}

1. もう一度 **フォレンジック > 書き込み保護モード** を選びます。ステータスバーの項目を選んでもかまいません。
2. ダイアログに、開いている証拠のドキュメントの数と名前が出ます。
3. **書き込み保護を解除する** を選びます。モードを有効のままにするには **キャンセル** を選びます。

モードの有効化と解除は、日時と Windows のユーザー名と一緒に監査ログに記録されます。ケースを開いていないときは、設定フォルダの `forensics-audit.log` に記録されます。

## 1 つのドキュメントだけ書き込みを許可する {#exception}

モードを有効にしたまま、メモのファイルなど 1 つのファイルだけを編集できます。

1. ファイルのタブを右クリックし、**このドキュメントへの書き込みを許可** を選びます。
2. ダイアログに示されたファイル名を入力します。名前が一致するまで、ボタンは使えません。
3. ファイル名の付いた **への書き込みを許可する** のボタンを選びます。

タブに開いた錠が付き、閉じるまでそのファイルを編集・保存できます。例外の設定と解除は監査ログに記録されます。証拠に登録したデータソースと、ディスク・ボリューム・プロセスには、書き込みを許可できません。

## OS の USB 書き込み保護 {#usb}

Windows に、USB ストレージへの書き込みを拒否させることができます。書き込み保護モードでは防げない、他のアプリや Windows 自身の書き込みも止まります。

1. **フォレンジック > OS の USB 書き込み保護** を選びます。コマンドパレットで **フォレンジック: OS の USB 書き込み保護の切り替え** を実行してもかまいません。
2. ダイアログを読み、**設定を変更する** を選びます。管理者権限が必要です。HexEditor を管理者として実行していなければ、Windows が許可を求めます。
3. 設定を変えた後に、USB ストレージを接続します。すでに接続されているデバイスには、接続し直すまで効きません。

この設定が保護するのは USB ストレージだけです。内蔵の SATA・NVMe のディスクは保護しません。

設定が有効な間は、メニューの項目にチェックが付きます。無効にするには、もう一度項目を選びます。設定は有効にする前の状態に戻ります。もともと値がなかった場合は、値を削除します。

設定が有効なまま HexEditor を終了しようとすると、**無効にして終了** か **有効のまま終了** を選ぶように求められます。変更はそれぞれ監査ログに記録されます。

グループポリシーで管理されているなどの理由で設定を変えられない場合は、理由が出て、何も変わりません。
