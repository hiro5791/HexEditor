# YARA スキャン

YARA のルールは、バイトの並びと条件を書いたものです。自分で用意したルールで、ドキュメント・選択範囲・フォルダ内のファイルをスキャンし、ルールが一致した箇所を確かめられます。

HexEditor にはルールは付いていません。自分で書くか、信頼できる入手先のルールを使ってください。

## ドキュメントをスキャンする {#scan}

1. **検索 > YARA** を選びます。下に **YARA** パネルが開きます。
2. **ルールファイルを追加** を選び、`.yar` または `.yara` のファイルを選びます (複数選べます)。**フォルダを追加** では、フォルダとそのサブフォルダのルールファイルをすべて加えます。
3. **範囲** を選びます: **ドキュメント全体**、**選択範囲**、**フォルダ内のファイル**。
4. **スキャン** を選びます。

スキャンは、保存していない編集を含む今のドキュメントの状態を対象にします。大きなドキュメントはバックグラウンドでスキャンし、進捗を表示します。**キャンセル** で取り消せます。それまでに見つかった結果は残ります。

## 結果 {#results}

一致は結果一覧に出ます。一致した文字列ごとに 1 行で、ルール名、名前空間、タグ、メタ情報、文字列の識別子 (`$a` など)、オフセット、長さ、一致したバイトが表示されます。文字列を使わずに条件だけで一致したルールは、オフセットのない行になります。行を開くと一致した位置に移動し、そのルールのメタ情報をすべて表示します。

一致した範囲は、Hex ビューに注釈として強調表示されます。強調表示されたバイトにポインタを合わせると、ルール名と文字列の識別子が表示されます。結果一覧を閉じると強調表示も消えます。一覧を閉じずに隠すには、**表示** メニューの注釈の設定を使います。

結果は、ほかの検索の結果と同じく、ブックマークや選択範囲に変換したり、エクスポートしたりできます。

フォルダ内のファイルをスキャンするときは、**フォルダ** と **ファイル** のマスク (`*.exe;*.dll` など) を入力します。一致はパネルにファイルごとに表示されます。行を選ぶと、そのファイルを開いて一致を選択します。

## ルールセットと外部変数 {#rule-sets}

- **セットを保存** で、今のルールファイルと外部変数を名前を付けて保存します。**ルールセット** で保存したセットを選ぶと読み込みます。**セットを削除** で削除します。
- **外部変数** は、ルールの中で使える値です (yara コマンドの `-d` に当たります)。`name=value` を 1 行に 1 つ入力します。`true` と `false` は真偽値、数は数、それ以外は文字列になります。

## 誤りと制限 {#limits}

- ルールファイルに誤りがあるときは、ファイル名・行番号・メッセージをパネルに一覧で表示し、スキャンを始めません。
- `yarac` で作ったコンパイル済みのルールファイルは使えません (形式が YARA の版によって違うため)。ルールのソースのファイルを加えてください。
- 使えるモジュールは `pe`、`elf`、`math`、`hash`、`time`、`string`、`console` です。`cuckoo` など外部のデータが必要なモジュールは使えません。
- データはブロック (既定 64 MiB) に分け、64 KB ずつ重ねてスキャンします。1 ブロックに収まらないドキュメントでは、重なり幅より長い一致や、別のブロックにある文字列に関わる条件が見つからないことがあります。この制限はパネルに常に表示されます。
- `pe`・`elf` モジュールは先頭のブロックを読みます。
- スキャンは既定で 600 秒で止まり、それまでの結果を残します。
- 正規表現の一致は 4,096 バイトまで、16 進文字列の上限のないジャンプは 64 KiB までです。
- 文字列 1 つにつき、一致は 1,000,000 件まで残します。

ブロックの大きさ (**YARA: ブロックの大きさ (MiB)**) と時間の上限 (**YARA: 時間の上限 (秒)**) は、検索の設定で変えられます。
