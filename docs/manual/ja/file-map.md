# ファイルマップ

ファイルマップは、ドキュメントのどこに何があるか (既知の形式の構造、埋め込まれたファイル、圧縮・暗号化されたデータ、テキスト、ゼロの埋め草、繰り返しのレコード) を示します。このページでは、ファイルマップの作り方と使い方を説明します。

## ファイルマップを作る {#create}

ファイルマップは、作る操作をしたときだけ作ります。ファイルを開いたときには作りません。

1. ドキュメントを開きます。
2. **解析 > ファイルマップ** を選びます。コマンドパレットの **解析: ファイルマップを作成** や、ミニマップの右クリックメニューの **ファイルマップを作成** でも作れます。
3. **ファイルマップ** パネルが開き、次の 3 つの段階で作ります。
   - **概観 (標本)**: ドキュメント全体に散らばった小さな標本から、すばやく推定します。とても大きなファイルでも数秒で出ます。
   - **全体の走査**: ドキュメント全体を 1 回読みます。走査が済んだ部分から、推定を置き換えます。
   - **構造の解析**: テンプレートで、ファイル形式の構造と、埋め込まれたファイルの正確な範囲を求めます。

進捗はパネルの上部と処理センターに出ます。**キャンセル** で止められます。走査が済んだ部分は残り、残りは標本による推定のままです。

タブで変換ビューを使っている場合は、変換後のデータからファイルマップを作り、パネルにその旨を出します。

ファイルマップは、シグネチャと統計に基づく推定です。パネルには常に「シグネチャと統計に基づく推定で、誤りがありえます。」と出ます。

## 帯の見方 {#band}

パネルの上部の帯は、ドキュメント全体を左から右に示します。右から左に書く言語でも、オフセットは右に向かって大きくなります。

- 上のレーンは **構造** です。ファイル形式の部分 (実行ファイルの `header` や `sections` など) と、埋め込まれたファイルを示します。
- 下のレーンは **内容** です。圧縮、暗号化・乱数、テキスト、ゼロ、埋め草、繰り返しのレコード、バイナリ、読み込み不可を示します。このレーンでは、どのバイトも 1 つの種類に入ります。
- 種類ごとに色と模様が違うので、色が見えなくても種類を見分けられます。帯の下の凡例に、模様と、種類ごとのバイト数が出ます。
- まだ標本による推定の部分は、薄い色と点で描きます。
- 枠が Hex ビューに表示中の部分を、縦線がカーソルを示します。

拡大・縮小は、<kbd>Ctrl</kbd> を押しながらマウスホイールを回すか、拡大・縮小のボタンで行います。領域にマウスを合わせると、種類、ラベル、範囲、確度、根拠の最初の文が出ます。

## 帯で移動する {#navigate}

- 帯をクリックすると、その位置にカーソルが移ります。Hex ビューで <kbd>Alt</kbd>+<kbd>Left</kbd> を押すと戻れます。
- 領域をダブルクリックすると、その範囲を選択します。
- <kbd>Tab</kbd> で帯にフォーカスを移すと、カーソルの位置の領域が選ばれます。<kbd>Left</kbd> と <kbd>Right</kbd> で領域の間を移り、<kbd>Up</kbd> と <kbd>Down</kbd> でレーンを切り替えます。<kbd>Enter</kbd> で領域の範囲を選択します。<kbd>+</kbd> と <kbd>-</kbd> で拡大・縮小します。
- <kbd>Shift</kbd>+<kbd>F10</kbd> またはアプリケーションキーで、領域のメニューを開きます。
- **表で表示** で、領域の一覧にフォーカスを移します。

## 一覧と詳細 {#list}

一覧には、すべての領域が、開始、終了、長さ、種類、ラベル、確度、段階とともに出ます。列の見出しを選ぶと並べ替え、**表示する種類** で 1 つの種類だけを出せます。一覧で行を選ぶと帯でも同じ領域が選ばれ、帯で選ぶと一覧でも選ばれます。

- **一覧の行をブックマークに** で、一覧の行ごとにブックマークを足します。
- **一覧の行をマルチ選択に** で、一覧の行をまとめて選択します。

一覧の横の詳細に、選んだ領域の根拠が出ます。エントロピーと p 値、レコードのずらしと一致の割合、埋め込まれたファイルを解析したテンプレートなど、判断のもとになった数値を示します。どの領域にも確度 (**高**、**中**、**低**) があります。

## 領域を操作する {#actions}

帯か一覧で領域を右クリックするか、詳細のボタンを使います。その種類の領域で使える操作だけが出ます。

| 操作 | 出る領域 | 動作 |
| --- | --- | --- |
| **範囲を選択** | すべて | 領域を選択します |
| **ブックマークに追加** | すべて | ラベルを名前、種類と根拠をコメントにしたブックマークを足します |
| **テンプレート "…" を適用** | 形式の構造、テンプレートの決まった埋め込まれたファイル | 適用の画面を出さずに、領域の先頭でテンプレートを適用します |
| **新しいタブで開く** | 埋め込まれたファイル、圧縮、テキスト、繰り返しのレコード | 範囲を新しいタブで開きます |
| **ここから展開...** | 形式の分かっている圧縮 | 範囲と形式を入れた状態で展開の画面を開きます |
| **テンプレートを推定...** | 繰り返しのレコード | 範囲とレコード長を入れた状態でテンプレートの推定を開きます |
| **文字列を抽出...** | テキスト | 範囲を指定して文字列の抽出を開きます |
| **ファイルとして保存...** | 埋め込まれたファイル | 範囲をファイルに保存します |

## 埋め込まれたファイルのテンプレート {#templates}

テンプレートで解析できる埋め込まれたファイルが見つかると、テンプレートを適用するかを尋ねるメッセージが出ます。**適用** で適用し、**一覧を表示** で埋め込まれたファイルを一覧に出します。コマンドパレットの **解析: 見つかったファイルにテンプレートを適用** でも適用できます。

1 つのドキュメントに適用できるテンプレートは 32 個までです。埋め込まれたファイルがそれより多い場合は、適用しなかった数をメッセージで知らせます。

テンプレートを自動で適用することはありません。メッセージを出さないようにするには、詳細設定の **ファイルマップ: 埋め込まれたファイルのテンプレート** を **しない** にします。

## 編集した後 {#edit}

ファイルマップを作った後にドキュメントを編集すると、パネルに「結果は編集前の内容のものです。」と出ます。**作り直す** で、今の内容でファイルマップを作り直します。

ファイルマップは、ドキュメントを閉じるまで持ちます。ドキュメントと一緒には保存しません。残したいときはエクスポートします。

## エクスポート {#export}

**エクスポート** を選び、形式を選びます。

- **JSON**: ドキュメントの情報、段階、各領域 (オフセット、長さ、種類、レーン、ラベル、確度、根拠、段階、テンプレート、親)、種類ごとのバイト数。
- **CSV**: 1 行に 1 領域。表計算ソフトで文字化けしないよう、BOM 付きの UTF-8 にします。
- **テキストのレポート**: 種類ごとのバイト数と、1 行に 1 領域の一覧を読みやすくまとめたもの。

種類・レーン・確度・段階の語は、常に英語の語になります。ラベルと根拠は表示言語で書きます。

## 大きなファイル {#large-files}

概観で読むのは最大で約 16 MB なので、数百 GB のファイルでもすぐに出ます。全体の走査はファイルを先頭から末尾まで 1 回読み、使うメモリはファイルの大きさに比例しません。作っている間も Hex ビューは滑らかに動きます。

ミニマップには、印の横にファイルマップの内容のレーンを出せます。クリックすると、その位置でパネルが開きます。この印は、ミニマップのメニューで表示・非表示を切り替えられます。
