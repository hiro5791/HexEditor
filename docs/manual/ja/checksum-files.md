# チェックサムファイル

チェックサムファイルは、`SHA256SUMS` のように、ファイルとそのハッシュ値を並べたファイルです。フォルダのチェックサムファイルを作っておくと、あとでファイルが変わっていないか確かめられます。Linux の `sha256sum -c` や macOS の `shasum -c` など、ほかのツールでも検証できます。

## チェックサムファイルを作る {#create}

1. **ツール > ファイルツール > チェックサムファイルの作成...** を選びます。コマンドパレットの **ファイルツール: チェックサムファイルを作成** でも開けます。
2. ハッシュを計算するファイルとフォルダを、1 行に 1 つ入れます。**ファイルを追加...** と **フォルダを追加...** で選べます。フォルダには **サブフォルダを含める** が効きます。
3. **アルゴリズム** を選びます。既定は SHA-256 です。
4. **形式** を選びます。

   | 形式 | 書く内容 | 既定のファイル名 |
   | --- | --- | --- |
   | GNU | 1 ファイル 1 行: `ハッシュ値  パス` | `SHA256SUMS` |
   | BSD | 1 ファイル 1 行: `SHA256 (パス) = ハッシュ値` | `CHECKSUM.SHA256` |
   | ファイルごと | 各ファイルの横に `ファイル名.sha256` (GNU 形式の 1 行) | `ファイル名.sha256` |
   | SFV | 1 ファイル 1 行: `パス CRC` (CRC-32 のみ) | `フォルダ名.sfv` |

5. 必要なら、GNU の行にバイナリモードの印 (`*`) を付けたり、パスの区切り (既定は `/`。ほかの OS でも検証できます) や改行 (既定は LF) を選んだり、出力のファイル名を変えたりします。
6. **作成** を選びます。

パスは、チェックサムファイルの場所からの相対パスで書きます。文字コードは BOM なしの UTF-8 です。同じ名前のファイルがあるときは、置き換える前に確認します。

処理はバックグラウンドで動き、処理センターにファイルごとの進捗が出ます。取り消せます。読めないファイルは飛ばし、最後に理由つきの一覧を表示します。チェックサムファイルには含めません。

## チェックサムファイルを検証する {#verify}

1. **ツール > ファイルツール > チェックサムファイルの検証...** を選びます。コマンドパレットの **ファイルツール: チェックサムファイルを検証** でも開けます。チェックサムファイルを選びます。`file.bin.sha256` のようなチェックサムファイルが横にあるふつうのファイルを選んだときは、そのファイルで検証するかを確認します。
2. 1 ファイルずつ確かめるたびに、結果が一覧に出ます。各行に **状態**・**パス**・**期待値**・**計算値**・**サイズ** が出ます。一覧の上に、「一致 120、不一致 1、見つからない 2」のような要約が出ます。

状態は、色に加えて、アイコンと文字で示します: **一致**、**不一致**、**見つからない**、**読み取りエラー**。ハッシュ値の比較では、英字の大文字・小文字を区別しません。一覧のファイルを開くには、行で <kbd>Enter</kbd> を押すか、右クリックして **開く** を選びます。

形式とアルゴリズムは、拡張子、ファイル名、ハッシュ値の長さ、行の書式から自動で判定します。`sha256sum` で作った GNU 形式 (`*` 付きの行を含む)、BSD 形式、`.md5`・`.sha1`・`.sha256`・`.sha512`・`.sfv` のファイルが使えます。アルゴリズムを判定できないときは、選んでもらいます。書式の誤りの行は飛ばし、行番号をメッセージで知らせます。

チェックサムファイルを HexEditor で開くと、「チェックサムファイルです。」という通知と **検証する** ボタンが出ます。

見出しをクリックすると並べ替え、状態で絞り込み、CSV / JSON への書き出しもできます。
