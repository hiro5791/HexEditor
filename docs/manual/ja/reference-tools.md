# 変換・参照ツール

これらのツールは、値をほかの表し方に変えたり、元に戻したりします。どれも **ツール** メニューからパネルとして開き、ドキュメントを開かなくても使えます。アクティブなドキュメントのカーソル位置から読んだり、カーソル位置に書き込んだりもできます。

## 基数・データ型の変換 {#converter}

**ツール > 基数・データ型の変換** を選びます。どの欄に入力しても、ほかの欄が更新されます。

- **バイト列 (Hex)** がすべての変換の基準です。検索バーと同じ書き方 (`DE AD BE EF`、`0xDE,0xAD` など) を受け付けます。
- **16 進**、**10 進 (符号なし)**、**10 進 (符号付き)**、**8 進**、**2 進** は、バイト列を整数として示します。1〜8 バイトで使えます。
- **half**、**float**、**double** は、2・4・8 バイトのときに、IEEE 754 の数として示します。
- **ASCII** は、表示できない範囲のバイトを `\xNN` で示します。
- **UTF-8**、**UTF-16 LE / BE**、**UTF-32 LE / BE**、**コードページの文字列** は、バイト列を文字列として示します。その文字コードで不正なバイト列は、置換文字と警告で示します。コードページは **コードページ** で選びます。Shift_JIS と EBCDIC のコードページも選べます。
- **Base64** は、バイト列の Base64 です。

文字列の欄に入力すると、その文字コードでバイト列に変換して示します。変換できない文字があると、その欄が赤枠になり、何も変わりません。

**バイト順** を切り替えると、数値の欄の読み方だけが変わります。バイト列は変わりません。

**カーソル位置から読む**、**カーソル位置に書き込む**、**検索バーに送る** のボタンは、最大 64 バイトを扱います。読み取りは、選択範囲があれば選択範囲を使います。書き込みは <kbd>Ctrl</kbd>+<kbd>Z</kbd> で元に戻せます。

## 浮動小数点のビジュアライザ {#float}

**ツール > 浮動小数点のビジュアライザ** を選びます。データインスペクタの float / double の行を右クリックして **ビジュアライザで開く** を選んでも開けます。

1. **形式** を選びます: half、bfloat16、float、double、x87 拡張精度。
2. **10 進の値** (`0.1`、`inf`、`nan` など) か **バイト列 (Hex)** を入力します。10 進の値は、その形式で表せる最も近い値に丸め、丸めの誤差を表示します。
3. ビットの構成に、**符号**・**指数部**・**仮数部** が、上のラベルとともに並びます。色に頼らず区別できます。ビットをクリックすると反転します。

ビットの下に、指数部 (ビット列、格納された値、実際の指数)、分類 (正規化数・非正規化数・ゼロ・無限大・ペイロード付きの NaN)、同じビットに戻る最短の 10 進表記、正確な 10 進の値、`0x1.921fb6p+1` のような 16 進の浮動小数点表記、1 つ大きい値と小さい値、ULP が出ます。形式を切り替えると、同じ値を新しい形式で表した値と丸めの誤差が出ます。

## 文字コード表 {#chars}

**ツール > 文字コード表** を選びます。文字コードを選ぶと、その 256 のバイト値が 1 行 16 個で並びます。制御文字は `NUL`、`LF` などの略称で出ます。文字がないバイトは斜線です。

- Shift_JIS のように 2 バイトの文字がある文字コードでは、先行バイトのセルを選ぶと、2 バイト目の表が開きます。
- セルを選ぶと、バイト値 (16 進・10 進・8 進・2 進)、文字、Unicode のコードポイントと英語の文字名、UTF-8 と UTF-16 のバイト列が出ます。**UTF-16 のバイト順** のボタンで、リトルエンディアン (LE) とビッグエンディアン (BE) を切り替えます。
- <kbd>Enter</kbd> を押すか、ダブルクリックするか、**カーソル位置に入力** を選ぶと、そのバイトがカーソル位置に入ります。今の上書き / 挿入のモードに従い、元に戻せます。
- セルの間は矢印キーで移動します。スクリーンリーダーは、各セルを「0x41、A、LATIN CAPITAL LETTER A」のように読み上げます。
- **一覧表示** は 1 行に 1 バイトの表です。**文字の検索** で、文字・名前・`U+3042` のようなコードポイントからセルを探せます。

## カラーピッカー {#color}

**ツール > カラーピッカー** を選びます。データインスペクタの色の型の行を右クリックして **カラーピッカーで開く** を選んでも開けます。

1. 色を選ぶか、`#RRGGBB` または `#AARRGGBB` の形で入力します。色の見本の横に、値が文字でも出ます。
2. 一覧に、その色を各ピクセル形式 (RGB888、BGRA8888、RGB565 など) で表したバイト列が出ます。16 ビットの形式には、リトルエンディアンとビッグエンディアンを切り替えるボタンがあります。
3. **カーソル位置から読む** は、**読み取り・書き込み・検索の形式** で選んだ形式で、カーソル位置のバイト列を読みます。**カーソル位置に書き込む** はそのバイト列を書き込みます。**この色を検索** は、バイト列を検索バーに送ります。

## 日時の変換 {#datetime}

**ツール > 日時の変換** を選びます。**日時 (ISO 8601)** に日時を入力するか、どの形式の行にも数値やバイト列を入力すると、ほかの行が更新されます。形式は、Unix 時刻 (32 / 64 bit。秒・ミリ秒・マイクロ秒・ナノ秒)、FILETIME、DOS の日付と時刻、OLE オートメーションの日付、HFS+、APFS、Java、.NET の Ticks、GPS 時刻、Mac の絶対時刻です。データインスペクタの日時の型と同じ定義です。

- **タイムゾーン** は、UTC、ローカル時刻、そのほかのタイムゾーンから選べます。日時は、地域設定の書式と ISO 8601 の両方で表示します。
- **現在の日時** は、今の時刻を入れます。
- 形式で表せない値 (1980 年より前の DOS の日付など) は「表せません」と表示します。
- **カーソル位置から読む** と **カーソル位置に書き込む** は、選んだ形式とバイト順を使います。
