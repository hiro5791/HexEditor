# 編集

このページでは、バイトを書き換える・消す・挿入する方法と、変更を元に戻す方法を説明します。元のファイルは、保存するまで変わりません。変更は、いくつでも元に戻せます。

## 上書きモードと挿入モード {#overwrite-and-insert}

入力のしかたには、2 つのモードがあります。

- **上書きモード**: 入力したバイトで、今のバイトを置き換えます。ファイルの長さは変わりません。
- **挿入モード**: 入力したバイトを、カーソルの位置に差し込みます。ファイルが長くなります。

<kbd>Insert</kbd> (**編集 > 上書き / 挿入の切り替え**) で切り替えます。ステータスバーの **上書き** / **挿入** を選んでも切り替えられます。カーソルの形も変わります。上書きは塗りつぶしの四角、挿入は縦線です。

- モードは、タブごとに持ちます。新しく開いたファイルのモードは、設定の **新しく開いたファイルの入力モード** で決まります (既定は上書き)。
- ファイルの末尾に入力すると、どちらのモードでもファイルが長くなります。
- ディスクやプロセスのメモリのように、長さを変えられないデータでは、上書きモードだけです。ステータスバーに **上書き (固定長)** と出ます。<kbd>Insert</kbd> を押すと、理由が出ます。
- 貼り付け (<kbd>Ctrl</kbd>+<kbd>V</kbd>) も、モードに従います。モードに関係なく上書きするには、<kbd>Ctrl</kbd>+<kbd>B</kbd> (**編集 > 上書き貼り付け**) を使います。

## Hex 列とテキスト列での入力 {#typing}

書き換えたい場所にカーソルを動かし、そのまま入力します。<kbd>Tab</kbd> で、入力する列を切り替えます。

### Hex 列

`0`〜`9` と `A`〜`F` (小文字も可) を入力します。1 桁ずつ入力でき、上位の桁、下位の桁の順に進み、2 桁入力するとカーソルが次のバイトに移ります。

- 上書きモードでは、桁ごとにバイトの半分が置き換わります。
- 挿入モードでは、上位の桁を入力した時点で新しいバイトが挿入されます。
- 16 進数以外のキーは無視されます。全角の `０`〜`９`、`Ａ`〜`Ｆ` は、半角として受け付けます。
- セルの表示形式を 10 進・8 進・2 進にしているときは、その数字で入力します。10 進と 8 進は 3 桁、2 進は 8 桁で 1 バイトです。16 bit 以上の整数や float の形式では、セルに直接入力できません。

### テキスト列

文字を入力します。日本語入力 (IME) も使えます。変換中の文字は、確定するまでデータを変えません。

- 入力した文字は、今の文字コードのバイト列にして書き込まれます。UTF-8 なら `あ` は 3 バイトです。
- 今の文字コードで表せない文字を入力すると、何も書かずに理由が出ます。文字コードを変えてください。
- UTF-16 と UTF-32 では、BOM を付けずに文字だけを書き込みます。
- <kbd>Enter</kbd> の動作は、設定の **テキスト列での Enter** で選べます (何もしない、CR LF、LF、CR)。既定は何もしません。

### 選択範囲があるとき

選択範囲があるときに入力すると、挿入モードでは選択範囲を消して入力を始めます。上書きモードの動作は、設定の **上書きモードで選択範囲に入力したとき** で、**先頭から上書き** か **選択範囲を 00 にしてから上書き** を選べます。

入力した場所は、色が変わり、変更されたバイトとして示されます。

### 複数の場所に同時に入力する

<kbd>Alt</kbd>+クリックでカーソルを増やすと、同じ入力を複数の場所に同時にできます。<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> は、上や下の行の同じ列にカーソルを足します。<kbd>Esc</kbd> で 1 つに戻します。詳しくは [選択とクリップボード](selection-clipboard.md#multiple-selections) を見てください。

## バイトの削除 {#delete}

- **選択範囲がないとき**: <kbd>Delete</kbd> はカーソルの位置のバイトを消します。挿入モードの <kbd>Backspace</kbd> は、カーソルの前のバイトを消します。
- **選択範囲があるとき**: <kbd>Delete</kbd> と <kbd>Backspace</kbd> のどちらでも、選択範囲を消します。右クリックの **削除** でも消せます。

バイトを消すと、ファイルは短くなり、後ろのバイトが前に詰まります。

- 上書きモードの <kbd>Backspace</kbd> は、何も消さず、カーソルを 1 つ戻します。
- 上書きモードで <kbd>Delete</kbd> を押したときに長さを変えたくない場合は、設定の **上書きモードでは Delete で長さを変えない** をオンにします。
- ディスクやプロセスのメモリなど、長さを変えられないものでは、削除できません。

切り取り (<kbd>Ctrl</kbd>+<kbd>X</kbd>) は、コピーしてから消します。

## 元に戻すとやり直し {#undo-redo}

変更は、いくつでも元に戻せます。回数に上限はなく、メモリの使用量はファイルの大きさに比例しません。

| 操作 | キー | メニュー |
| --- | --- | --- |
| 元に戻す | <kbd>Ctrl</kbd>+<kbd>Z</kbd> | **編集 > 元に戻す** |
| やり直し | <kbd>Ctrl</kbd>+<kbd>Y</kbd> または <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | **編集 > やり直し** |

- メニューとツールバーのボタンには、操作の名前が出ます (例: **元に戻す: 塗りつぶし**)。
- 続けて入力した文字は、1 回の操作にまとまります。カーソルを動かす、ほかの操作をする、2 秒あける、のどれかで区切れます。間隔は、設定の **入力をまとめる間隔** で変えられます。
- 貼り付け、塗りつぶし、すべて置換のように、1 つのコマンドで多くの場所を変える操作は、1 回で元に戻ります。
- 元に戻すと、その操作の範囲が選択されて、見える位置にスクロールします。
- カーソルの移動、選択、表示の設定は、元に戻す対象ではありません。
- 保存しても、履歴は消えません。保存の前の状態にも戻れます。履歴を消したいときは、設定の **保存時に履歴を消す** をオンにします。
- 元に戻したあとに新しく変更すると、やり直しの履歴は捨てられます。
- ドキュメントを閉じると、履歴は消えます。

## 履歴パネル {#history}

履歴パネルは、変更の履歴を一覧で見せます。任意の時点に、一度で戻れます。**表示 > パネルの表示切り替え > 履歴** で出します。

- 各行に、番号、操作の名前、変更した範囲、長さの変化 (+N / −N)、日時が出ます。保存した時点の行には、印が付きます。
- 今の状態の行は、太字で強調されます。その後ろの行は、やり直せる操作です (薄く出ます)。
- 行をダブルクリックするか <kbd>Enter</kbd> を押すと、その操作を行った直後の状態に移ります。
- **この範囲へ移動** で、その操作の範囲を選択して表示します。状態は変わりません。

## 塗りつぶしとバイトの挿入 {#fill-and-insert}

### 塗りつぶし

**編集 > 塗りつぶし** で、選択範囲 (または指定した範囲) を、決めた内容で埋めます。長さは変わりません。

1. 範囲を選びます。**選択範囲** か、**範囲を指定** (**開始** と **長さ**) です。
2. **内容** の種類を選びます。

| 内容 | 指定するもの |
| --- | --- |
| **バイト値** | 1 バイトの値 (既定 `00`) |
| **Hex パターン** | `DE AD BE EF` のようなバイト列 (1 MiB まで) |
| **テキスト** | 文字列と文字コード。改行とタブは `\r` `\n` `\t` と書きます |
| **乱数** | 最小値と最大値 (既定 0〜255)。**シード** を入れると、同じ結果になります |
| **暗号論的乱数** | なし (システムの暗号用の乱数生成器を使います) |
| **カウンタ** | 開始値、増分、要素の大きさ、エンディアン、あふれたときの扱い (**ラップ** か **飽和**) |
| **ファイルの内容** | ファイルと、そのファイルの中の開始位置と長さ |
| **クリップボードの内容** | 実行するときのクリップボード |

パターンやテキストが範囲より短いときは、**範囲より短い場合は繰り返す** で繰り返します。**パターンの起点** は、範囲の先頭か、オフセット 0 から数えるかを選べます。変更の前と後は、先頭の 64 バイトでプレビューできます。内容を決めたら、**塗りつぶし** を選びます。

バイト値の塗りつぶしは、範囲が 100 GB でもすぐに終わります。

### バイトの挿入

**編集 > バイトの挿入** で、指定した数のバイトを、カーソルの位置に挿入します。

1. **挿入する位置** を入力します (既定はカーソルの位置)。
2. **バイト数** を入力します。
3. 内容を選びます (塗りつぶしと同じ種類。既定は `00`)。
4. **挿入** を選びます。

**挿入後に挿入した範囲を選択する** (既定はオン) で、入れた範囲が選ばれます。

### ファイルの内容の挿入

**編集 > ファイルの内容を挿入** で、別のファイルの全体または一部を、カーソルの位置に挿入するか、上書きします。ファイルを選び、**ファイル内の開始位置** と **長さ** を指定します。<kbd>Ctrl</kbd> を押しながらファイルをウィンドウにドロップしても、ドロップした位置に挿入できます。

## ファイルサイズの変更 {#file-size}

ファイルの長さは、次の 2 つの方法で変えられます。

- **編集 > ファイルサイズの変更**: **新しい長さ** を入力します (例: `4096`、`1M`)。短くするときは末尾を切り捨て、長くするときは末尾に指定した内容 (既定は `00`) を足します。切り捨てるバイト数が表示されます。どちらも元に戻せます。
- **編集 > カーソル位置で切り詰める**: カーソルの位置から末尾までを消します。

長さを変えられないデータ (ディスクなど) では使えません。

## ビット単位の挿入と削除 {#bits}

バイトではなく、ビットの単位で、挿入や削除ができます。データを 1 本のビット列として扱い、後ろのビットを詰めたり、ずらしたりします。

1. **データ > データ演算** を選びます。
2. **分類** で **ビットの挿入・削除** を選び、**ビットを挿入** か **ビットを削除** を選びます。
3. **位置 (バイトのオフセット)** と **バイト内のビット (7 が最上位)** で、場所を指定します。
4. **ビット数** を入力します。挿入するときは **埋める値** (0 か 1) も選びます。
5. **ずらす範囲** を選びます。**選択範囲の中だけ** (長さが変わらず、はみ出したビットは捨てます) か、**ドキュメントの末尾まで** です。
6. **実行** を選びます。

ビット数が 8 の倍数なら、ふつうのバイトの挿入と削除と同じです。コマンドパレットの **ビットを挿入** からも実行できます。詳しくは [データ演算](data-operations.md) を見てください。

## 大文字・小文字の変換 {#case}

選択範囲の英字の大文字・小文字を、まとめて変えられます。**データ > 大文字・小文字の変換** から選びます。

- **大文字に**
- **小文字に**
- **大文字と小文字を入れ替える**

変換するのは、ASCII の英字 (`a`〜`z`、`A`〜`Z`) のバイトだけです。ほかのバイトは変えず、長さも変わりません。選択範囲が複数あるときは、範囲ごとに変換します。
