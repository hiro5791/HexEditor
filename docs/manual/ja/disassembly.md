# 逆アセンブル

逆アセンブルパネルは、バイト列を機械語として解釈し、命令の一覧を表示します。Windows (PE)、Linux (ELF)、macOS (Mach-O) の実行ファイル、.NET のアセンブリ、さまざまなプロセッサのコードを扱えます。このページでは、シンボル名のデマングルも説明します。

## 逆アセンブルを表示する {#show-disassembly}

- **解析 > 逆アセンブル** を選びます。カーソル位置 (選択範囲があれば選択範囲の先頭) から表示します。
- **表示 > パネルの表示切り替え > 逆アセンブル** を選びます。
- バイトを選択し、右クリックして **逆アセンブル** を選びます。
- コマンドパレットで **解析: 逆アセンブル** か **解析: カーソル位置から逆アセンブル** を実行します。

パネルは右に開きます。幅が必要なときは下部に移せます。

ドキュメントが実行ファイルの場合は、ヘッダを読んで、アーキテクチャ・モード・エンディアン・ベースアドレスを自動で設定し、エントリポイントから表示します。どれもツールバーで変えられます。

## リスティング {#listing}

各行には、アドレス、バイト列 (既定で 8 バイトまで。長い命令は「…」で省略)、命令、コメントが表示されます。コメントには、シンボル名、分岐先の名前、参照している文字列が出ます。実行ファイルでは、アドレスは仮想アドレスです。

- `main:` のような行は、エントリポイントとシンボルの位置を示します。シンボルのない分岐先には、`sub_140001040` (call の先) や `loc_140001030` (ジャンプの先) の名前が付きます。
- 命令として解釈できないバイトは `db 0x06` と 1 バイトずつ表示し、次のバイトから解釈を続けます。
- アドレスの左の矢印は、分岐が前方か後方かを示します。分岐元と分岐先の両方が画面にあるときは、線で結びます。
- 命令にマウスを置くと、命令の長さ、オペランド、読み書きするレジスタ、命令グループが表示されます。
- 行の半分以上が `db` のときは、このアーキテクチャのコードではない可能性があることを知らせます。

リスティングは、表示言語が右から左に書く言語でも、左から右に表示します。

矢印キー、<kbd>Page Up</kbd>、<kbd>Page Down</kbd>、<kbd>Ctrl</kbd>+<kbd>Home</kbd>、<kbd>Ctrl</kbd>+<kbd>End</kbd> で移動します。スクロールバーはファイル上の位置に対応するので、大きなファイルでもどこへでもすぐに移動できます。解釈するのは画面に見えている行だけです。

### Hex ビューとの連動 {#hex-view-link}

- 行を選ぶと、その命令のバイトが Hex ビューで選択されます。
- **カーソルに追従** がオン (既定) のときは、Hex ビューでカーソルを動かすと、そのバイトを含む命令の行が選ばれます。
- 今の命令は、Hex ビューで破線の枠で示します。
- ドキュメントを編集すると、編集した位置から解釈し直します。

### コピーとエクスポート {#copy-export}

- <kbd>Ctrl</kbd>+<kbd>C</kbd> を押すか、行を右クリックして **コピー** を選ぶと、タブ区切りのテキストとしてコピーします。
- 右クリックして **アセンブリとしてエクスポート...** を選ぶと、テキストファイルに保存します。保存するのは、Hex ビューの選択範囲 (なければ選んだ行のセクション) です。

## ツールバー {#toolbar}

| 項目 | 内容 |
| --- | --- |
| **アーキテクチャ** と **モード** | プロセッサとモード (x86 64 bit、ARM Thumb、RISC-V RV64C など) |
| **エンディアン** | 両方を持つプロセッサで、リトルかビッグを選ぶ |
| ユニバーサルバイナリの一覧 | Mach-O のユニバーサルバイナリで、x86_64・arm64 などを選ぶ |
| **開始位置** | カーソル位置、選択範囲の先頭、指定したオフセット、仮想アドレス、エントリポイントのどこから表示するか |
| ベースアドレス | 先頭のバイトのアドレス。空欄なら実行ファイルの値 (それ以外のファイルでは 0) |
| **構文 (x86)** | Intel、AT&T、MASM |
| **表示オプション** | 数値の書式、大文字、列 ([表示オプション](#display-options)) |
| **カーソルに追従** | Hex ビューのカーソルにリスティングを合わせる |
| **命令を検索** | 命令のパターンで検索する ([命令を検索する](#find-instructions)) |

対応するアーキテクチャ: x86 (16 / 32 / 64 bit)、ARM (ARM、Thumb、ARMv8、Cortex-M)、ARM64、MIPS (MIPS32、MIPS64、microMIPS、MIPS32R6)、PowerPC (32 bit、64 bit、QPX)、SPARC (SPARC、SPARC V9)、SystemZ、XCore、68K (68000〜68060)、RISC-V (RV32、RV64、圧縮命令付き)、6502 (6502、65C02、W65C02、65816)、TMS320C64x、BPF (従来の BPF、eBPF)、WebAssembly。一覧の **その他** には、M680X、EVM と、プラグインが加えたアーキテクチャがあります。

## セクションとシンボル {#sections-symbols}

実行ファイルでは、パネルの左側に 2 つの一覧が出ます。パネルの幅が 600 ピクセルより狭いときは、リスティングの上に出ます。

- **セクション**: 名前、仮想アドレスとサイズ、ファイル上の位置とサイズ、属性 (R、W、X)。選ぶと、そのセクションの先頭から表示します。
- **シンボル**: エクスポート、インポート (`KERNEL32!CreateFileW` の形)、シンボル表、PLT の項目 (`puts@plt`)、スタブ。C++・Rust・D の名前はデマングルして表示します。**名前で絞り込み** に入力すると一覧を絞り込めます。選ぶと、そのシンボルから表示します。

ヘッダの一部が壊れているときは、読める部分だけを使い、「ヘッダの一部を解釈できません」と理由を表示します。

仮想アドレスへ移動するには、**解析: 仮想アドレスへ移動** を実行して、アドレスを入力します (移動と同じ入力式が使えます)。対応するオフセットとセクションが表示されます。どのセクションにも含まれないアドレスは、そのことが表示され、確定できません。**解析: エントリポイントへ移動** はエントリポイントへ移動します。

## 分岐先へ移動する {#branch-targets}

call やジャンプの行を選んで <kbd>Enter</kbd> か <kbd>F12</kbd> を押すか、ダブルクリックするか、右クリックして **分岐先へ移動** を選びます。リスティングと Hex ビューが分岐先へ移動します。<kbd>Alt</kbd>+<kbd>←</kbd> で戻れます。

- 命令の位置からの相対でメモリを参照する命令 (`call qword ptr [rip + 0x1000]` など) は、参照先のアドレスへ移動します。
- 分岐先がインポートした関数のときは、移動せずに、ステータスバーに「外部関数: KERNEL32!CreateFileW」のように名前を表示します。
- 分岐先がファイルに含まれないときは、ステータスバーでそのことを知らせます。
- Hex ビューで <kbd>F12</kbd> を押すと、逆アセンブルパネルが開いていてテンプレートを適用していなければ、カーソル位置の命令の分岐先へ移動します。

### 参照を探す {#references}

行を右クリックして **参照を探す** を選ぶ (または **逆アセンブル: 参照を探す** を実行する) と、そのアドレスを呼ぶ・ジャンプする・参照する命令を探します。実行ファイルでは実行可能なセクションの全部を、それ以外のファイルでは選択範囲 (なければ全体) を解釈します。結果は **検索結果** パネルに、アドレス、命令、種類 (call、jmp、データ参照) で表示します。結果は、ドキュメントを編集するまで覚えています。

## 表示オプション {#display-options}

パネルの **表示オプション** か、**設定 > 逆アセンブル** で設定します。すべてのアーキテクチャで共通で、保存されます。

- **x86 の構文**: Intel (既定)、AT&T、MASM。AT&T では、`48 89 E5` を `movq %rsp, %rbp` と表示します。
- **16 進数の書式**: `0x10` (既定) か `10h`。**16 進数を大文字にする** で A〜F を大文字にします。
- **負の即値を符号付きで表示**: 負の即値をマイナス記号付きで表示します (x86)。
- **ニーモニックとレジスタ名を大文字にする**。
- **ARM のレジスタの別名**: `r13`、`r14`、`r15` の代わりに `sp`、`lr`、`pc` (既定) と表示します。
- **バイト列の列を表示** と **表示する最大バイト数** (4〜16)。
- **アドレス列**: 仮想アドレス、ファイル上のオフセット、両方。
- **分岐の線** と **コメント列**。

## .NET のアセンブリ {#dotnet}

ドキュメントが .NET のアセンブリのときは、MSIL で表示できることを知らせる通知が出ます。**MSIL で表示** を選ぶか、**アーキテクチャ** で **MSIL (.NET)** を選ぶか、**解析: .NET のメソッドを逆アセンブル** を実行します。

1. 左側に **型とメソッド** (名前空間、型、メソッド) が出ます。項目を展開すると中身が出ます。
2. メソッドを選びます。リスティングに、メソッドのヘッダ、ローカル変数、IL の命令、例外処理の節が出ます。

トークンは、`call void [System.Console]System.Console::WriteLine(string)` や `ldstr "Hello"` のように名前で表示します。各行はファイル上のバイトに対応しているので、行を選ぶと Hex ビューでそのバイトが選択されます。分岐の行で <kbd>Enter</kbd> を押すと分岐先の行へ、同じアセンブリのメソッドを呼ぶ行で <kbd>Enter</kbd> を押すとそのメソッドへ移動します。ReadyToRun でコンパイルしたアセンブリでは、**ネイティブコードを表示** でそのメソッドの x64 か ARM64 のコードを表示できます。

## 命令を検索する {#find-instructions}

パネルの **命令を検索** を選ぶか、**逆アセンブル: 命令パターンを検索** を実行して、パターンを入力します。

- 1 つの命令か、`;` で区切った複数の命令を書きます: `push rbp; mov rbp, rsp`。
- `*` は任意の文字列、`?` は任意の 1 文字に一致します: `call *`、`mov e?x, [rip+*]`。
- 命令の位置に `{n}` か `{n-m}` を書くと、その数の任意の命令に一致します: `cmp *; {0-3}; jz *`。
- 大文字・小文字と空白の数は区別しません。今の表示オプションで表示した命令と比べます。
- **正規表現** をオンにすると、命令ごとの .NET の正規表現として扱います。

<kbd>Enter</kbd> で次、<kbd>Shift</kbd>+<kbd>Enter</kbd> で前の一致へ移動します。<kbd>Alt</kbd>+<kbd>Enter</kbd> か **すべて検索** で、すべての一致を **検索結果** パネルに出します。<kbd>↑</kbd> と <kbd>↓</kbd> で前に入力したパターンを呼び出し、<kbd>Esc</kbd> で検索欄を閉じます。`{0-x}` のような誤りがあると、何文字目かと理由を表示します。

実行ファイルでは実行可能なセクションの全部を、それ以外のファイルでは選択範囲 (なければ全体) を探します。対象が 100 MB を超えるときは、かかる時間の目安をステータスバーに表示します。検索は取り消せます。それまでに見つかった結果は残ります。

## 命令を書き換える {#assemble}

x86 と x64 では、命令を入力して、その機械語でその場を書き換えられます。

1. 行を右クリックして **アセンブル...** を選びます (または **逆アセンブル: 命令を書き換える** を実行します)。
2. 新しい命令を入力します。複数のときは `;` で区切ります。入力に合わせて、バイト列と長さが表示されます。`jmp 0x401000` のような相対分岐は、その行のアドレスから計算します。
3. 新しいコードが短いときは、**残りを NOP (0x90) で埋める** (既定) か **残りのバイトをそのまま残す** を選びます。長いときは、上書きされる後ろの命令の一覧が警告として出ます。
4. **書き込む** を選びます。

挿入モードでも上書きで書き込むので、後ろの命令の位置はずれません。<kbd>Ctrl</kbd>+<kbd>Z</kbd> を 1 回押すと元に戻ります。アセンブルできないときは理由が表示され、**書き込む** は選べません。読み取り専用のドキュメントと、x86・x64 以外のアーキテクチャでは使えません。

## シンボル名をデマングルする {#demangle}

C++・Rust・D のコンパイラは、関数の名前を符号化した形 (マングル名) にします。デマングルすると、`_ZN3foo3barEi` を `foo::bar(int)` のような読める名前に戻せます。

1. **解析 > デマングル...** を選ぶか、**解析: シンボル名をデマングル...** を実行します。ドキュメントの中の文字列をデマングルするときは、選択して右クリックし、**デマングル** を選びます。
2. 上の欄に、名前を 1 行に 1 つずつ入力するか貼り付けます。入力に合わせて、下の欄に結果が出ます。

名前の先頭から、Itanium C++ ABI (GCC、Clang)、Microsoft Visual C++、Rust (旧方式と v0)、D を判定します。マングル名でない行はそのまま表示します。マングル名に見えても読めない名前には「(デマングルできません)」が付きます。

- **短い名前** は、引数と戻り値の型を省きます。
- **Rust のハッシュを表示** は、Rust の旧方式の名前の最後のハッシュを残します。
- **コピー** は、すべての結果をコピーします。

逆アセンブルパネルのシンボルの一覧と、テンプレートの関数 `std::sys::demangle` も、同じデマングラを使います。
