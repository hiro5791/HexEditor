# パーティション

ディスクやディスクイメージのパーティションを見る方法、パーティションを別のタブで開く方法、削除されたパーティションを探す方法を説明します。

## パーティションを見る {#show-partitions}

ディスクやディスクイメージを開くと、パーティション表を読んで **パーティション** パネルを表示します。

1. ディスクを開くか、**ファイル > ディスクイメージとして開く** でイメージのファイルを選びます。
2. **パーティション** パネルに、ディスクの配置図、パーティションの一覧、選んだ行の詳細が出ます。

一覧には、番号、形式 (MBR・論理・GPT・APM・BSD)、種類、名前、開始 LBA、終了 LBA、セクタ数、サイズ、開始オフセット、属性、先頭にあるファイルシステム、状態が出ます。1 MiB 以上の隙間は **未割り当て** の行として出ます。暗号化されたパーティション (BitLocker、LUKS、FileVault、Core Storage、暗号化されたように見えるデータ) では、詳細に暗号化の種類が出ます。

拡張パーティションを含む MBR、GPT (主ヘッダーとバックアップヘッダー)、Apple パーティションマップ、BSD ディスクラベルを読みます。読むのは数セクタだけなので、どんな大きさのディスクでもすぐに終わります。

パネルが出ていないときは、**フォレンジック > パーティション > パーティションを表示** を選びます。

## 警告 {#warnings}

問題のある行は状態が **警告** になります。行を選ぶと、一覧の下に理由が出ます。次の場合に警告します。

- GPT のヘッダーやエントリ配列の CRC32 が一致しない
- GPT の主ヘッダーとバックアップヘッダーが一致しない
- パーティションが重なっている、またはディスクの範囲の外を指している
- EBR の連鎖が循環している (たどるのをやめます)
- ハイブリッド MBR

指定したセクタサイズでは GPT が見つからず、別のセクタサイズ (512 または 4096) では見つかった場合は、そのセクタサイズで開き直すかを尋ねるメッセージが出ます。

## パーティションを操作する {#partition-actions}

行 (または配置図の区画) を右クリックして、操作を選びます。

- **パーティションの先頭へ移動**: 先頭のバイトへ移動します。行のダブルクリックや Enter キーでも移動できます。
- **パーティションを選択**: パーティション全体を選択します。
- **パーティションを別タブで開く**: パーティションを別のタブで開きます。そのタブでは、パーティションの先頭がオフセット 0 です。ディスクとデータを共有するので、セクタサイズと読み取り専用の状態を引き継ぎます。
- **エントリの構造を表示**: 表のエントリを MBR または GPT のテンプレートで表示します。
- **ファイルシステムを表示**: パーティションのファイルシステムのブラウザを開きます。[ファイルシステム](file-systems.md) を参照してください。

どの表にもないパーティションを開くには、先頭にカーソルを置き、Hex ビューを右クリックして **ここをパーティションの先頭として開く** を選びます。

ステータスバーに、カーソル位置の LBA と、カーソルのあるパーティションの番号が出ます。

## 失われたパーティションを探す {#lost-partitions}

パーティション表が消えたり壊れたりしたとき、ディスクの中のファイルシステムや表の痕跡を探せます。

1. **フォレンジック > パーティション > 失われたパーティションをスキャン** を選びます。
2. 範囲と、探す位置 (1 MiB 境界、シリンダ境界 (63 セクタ)、すべてのセクタ) を選びます。すべてのセクタは範囲全体を読むため、ディスクを読むのと同じだけ時間がかかります。
3. **スキャン** を選びます。処理センターに進捗・速度・残り時間が出ます。見つかった候補は、すぐに **フォレンジックの結果一覧** パネルに加わります。

候補ごとに、開始 LBA、推定サイズ、種類、確度が出ます。**高** は主と予備のブートセクタの両方が一致したもの、**中** は主の構造だけが一致したもの、**低** は署名だけが見つかったものです。

候補を右クリックすると、次の操作ができます。

- **パーティションとして開く**: 別のタブで開きます。
- **ファイルシステムを表示**: 候補のファイルシステムを表示します。
- **パーティション表のエントリを作成 (MBR)** / **(GPT)**: ドキュメントだけを変えます。保存するまでディスクやイメージは変わりません。書き込み保護モードでは使えません。

スキャンはいつでもキャンセルできます。それまでに見つかった結果は一覧に残ります。一覧を保存するには、右クリックして **一覧を CSV / JSON にエクスポート** を選びます。

## 論理ボリューム (LDM・LVM2) {#logical-volumes}

Windows の動的ディスク (LDM) と Linux の LVM2 の物理ボリュームは、パーティションの一覧に **LDM** または **LVM2 物理ボリューム** の行として出ます。その論理ボリュームを見るには、次のようにします。

1. ボリュームを構成するディスク・イメージをすべて開きます。
2. LDM・LVM2 の行を右クリックして **論理ボリュームを表示** を選ぶか、**フォレンジック > パーティション > 論理ボリュームを表示** を選びます。

パーティションの一覧の下の **論理ボリューム** の一覧に、名前、種類、サイズ、構成、状態が出ます。構成するディスクは、開いているディスク・イメージの中から、LDM のディスク GUID または LVM2 の PV UUID で探します。構成要素ごとのメタデータの写しが違うときは、最新のものを使い、警告を出します。

- **論理ボリュームを開く**: LDM のシンプル・スパン・ストライプ、LVM2 の linear・striped のボリュームを、1 つの読み取り専用のドキュメントとして開きます。構成するディスクからは、見ている部分だけを読みます。
- 構成要素が足りないときは開かず、足りないディスクの GUID または PV UUID をメッセージで示します。そのディスク・イメージを開くか、**構成要素を割り当てる** を選んで、足りない構成要素ごとに開いているドキュメントかファイルを選びます。
- LDM のミラーと RAID-5 のボリュームは、RAID の再構成で開きます。LVM2 のシン・スナップショット・キャッシュ・RAID の論理ボリュームは一覧に出すだけで、**非対応** と出ます。
