# NTFS の代替データストリーム

NTFS・ReFS のボリュームにあるファイルは、メインのデータとは別に、名前の付いたストリームを持てます。Windows は「インターネットから取得したファイル」の印 (`Zone.Identifier`) に使い、プログラムによってはプロパティなどを入れます。HexEditor では、これらを一覧し、開いて編集し、作成・削除できます。

## ファイルのストリームを見る {#list}

1. ファイルを開いて **ファイル > 代替データストリーム** (または **ツール > ファイルツール > 代替データストリーム**) を選びます。タブを右クリックして **代替データストリーム** を選んでも開けます。別のファイルやフォルダを見るには、パネルの **ファイルを選ぶ** を使います。
2. パネルにストリームが並びます。メインのストリームは `::$DATA` と表示します。列は、ストリーム名・サイズ・先頭 16 バイトの Hex・よく知られたストリームの説明です。`Zone.Identifier` は「インターネットから取得したファイルの印」と説明します。

FAT32 や exFAT のように、ストリームに対応しないボリュームのファイルでは、「このボリュームは代替データストリームに対応していません」と出て、ボタンは使えません。

## ストリームを開いて編集・保存する {#open}

ストリームを選んで **開く** を選ぶか、ダブルクリックします。`data.bin:Zone.Identifier` のような名前の新しいタブで開き、ほかのドキュメントと同じように編集できます。

- 長さが変わらないときは、変えたバイトだけを書きます。
- 長さが変わるときは、ストリームをファイルのように置き換えられないため、先に旧内容を復旧用のフォルダに保存してから、ストリームの内容を書き直します。失敗したら旧内容に戻します。復旧用のジャーナルの上限を超えるときの確認は、ふつうの保存と同じです。
- ファイルのメインのストリームを保存しても、代替データストリームは残ります。
- ReFS ではストリームの大きさに Windows の上限があります。上限を超える保存は、その旨を示して保存しません。

## 作成・名前の変更・削除・書き出し・読み込み {#manage}

- **作成** は、名前を尋ねて空のストリームを作り、開きます。名前に `:`・`\`・`/` と制御文字は使えません。使えない名前のときは入力欄が赤くなり、**作成** は押せません。同じ名前があるときは作りません。
- **名前の変更** は、新しい名前でコピーしてから元を削除します。Windows にストリームの名前を変える機能がないためです。
- **削除** は、先に名前とサイズを示して確認します。取り消せません。
- **書き出し** は、ストリームの内容をファイルに書きます。**読み込み** は、ファイルの内容でストリームの内容を置き換えます。

タブで開いているストリームは、名前の変更・削除・読み込みができません。先にタブを閉じてください。書き込み保護モードの間は、一覧と「開く」だけができ、作成・名前の変更・削除・読み込みは使えません。

## ストリームを知らせてもらう {#notice}

**設定** で **代替データストリームがあるファイルを開いたときに知らせる** をオンにすると、メイン以外のストリームがあるファイルを開いたときに、その数と **一覧を表示** ボタンのメッセージが出ます。既定はオフです。
