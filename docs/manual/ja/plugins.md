# プラグイン

このページでは、プラグインを追加して管理する方法を説明します。プラグインは、HexEditor に新しい機能を足す小さなプログラムです。プラグインの作りかたは開発者向けの文書にあり、このマニュアルでは扱いません。

プラグインは、あなたと同じ権限で PC 上のあらゆる操作ができます。信頼できる作成者のものだけを追加してください。

## プラグインを追加する {#install}

プラグインは `.hexplugin` というファイルで配られます。

1. **ツール > プラグイン > プラグインの管理** を選びます。コマンドパレットの **プラグイン: 管理** でも開けます。
2. **追加** を選んで `.hexplugin` のファイルを選びます。ファイルを一覧にドロップしても追加できます。
3. 確認のダイアログが出ます。内容を読んで、**有効にする** を選びます。詳しくは[プラグインの許可と信頼](#plugin-permissions)を参照してください。
4. **今すぐ再起動** を選びます。再起動すると、プラグインが読み込まれます。

未保存の編集があるときは、再起動の前に、通常の終了と同じ確認が出ます。

壊れたファイルや、プラグインでないファイルを選んだときは、追加されずに理由が出ます。同じプラグインの新しい版を追加したときは、更新として扱われます。

HexEditor の版に合わないプラグイン (新しすぎる、または古すぎる) は、読み込まれず、一覧に理由が出ます。

## プラグインの有効化・無効化・削除 {#manage}

**プラグインの管理** の画面に、入っているプラグインの一覧が出ます。各プラグインには、次のものが並びます。

- 名前、バージョン、発行者
- 署名の状態 (**署名あり**、**署名されていません**、**署名が無効**)
- 状態: **有効**、**無効**、**読み込めません** (理由が付きます)、**停止中**
- 説明と、そのプラグインが追加するものの一覧 (**追加するもの**)

操作は次のとおりです。

| 操作 | 内容 |
| --- | --- |
| **有効** のスイッチ | プラグインを有効 / 無効にします |
| **削除** | プラグインを削除します |
| **プラグインの設定** | プラグインが設定画面を持っているときに開きます |
| **プラグインのフォルダを開く** | プラグインを置いてあるフォルダを、エクスプローラーで開きます |
| **今すぐ再起動** | 変更を反映するために再起動します |

有効・無効の切り替え、削除、更新は、HexEditor を再起動したあとに反映されます。切り替えたプラグインには「再起動後に変わります」と出ます。

一覧は、キーボードだけで操作できます。

### 問題が起きたとき {#when-things-go-wrong}

- プラグインがエラーを出し続けたときは、そのプラグインを一時的に止めて、上に通知します。**プラグインを無効にする** か、**再起動時にもう一度試す** を選べます。エラーの内容は、**出力** パネルの **プラグイン: 名前** に残ります。
- HexEditor が異常終了したあと、原因がプラグインと思われるときは、次の起動で「プラグインを無効にしますか?」と確認します。**無効にする** か **有効のままにする** を選びます。
- プラグインが追加した項目には、ツールチップに「プラグイン「名前」が追加」と出ます。

## プラグインの許可と信頼 {#plugin-permissions}

プラグインを初めて有効にするときや、プラグインのファイルが変わったときは、「プラグイン「名前」を有効にしますか?」という確認が出ます。

ダイアログには、次のことが出ます。

- 名前、バージョン、発行者
- 「このコードはあなたの PC 上で、あなたと同じ権限で何でも実行できます」という警告。プラグインは、スクリプトのような制限された環境では動きません。
- プラグインが宣言している許可の一覧
- 署名されていないときは、発行者を確かめられない旨の警告

ボタンは **有効にする** と **有効にしない** です。**有効にしない** を選んだプラグインは、無効として記録され、起動のたびに確認されることはありません。

### 署名と発行者 {#signatures}

プラグインの実行できるファイルには、発行者の電子署名が付いていることがあります。HexEditor は署名を確かめて、状態を表示します。

- **署名あり**: 発行者の名前が出ます。
- **署名されていません**: 読み込めますが、確認のダイアログで警告が強くなります。
- **署名が無効**: ファイルが改ざんされているなど、署名に問題があります。このプラグインは読み込まれません。

確認のダイアログで **この発行者 (名前) を常に信頼する** にチェックを入れると、同じ発行者が署名したプラグインは、次から確認なしで有効になります。ただし、署名で守られていないファイル (設定ファイルなど) が変わったときは、もう一度確認が出ます。

信頼した発行者は、**プラグインの管理** の **信頼済みの発行者** に並びます。取り消すと、次からまた確認が出ます。

署名のないプラグインを読み込ませたくないときは、**設定 > 自動化** の **署名されたプラグインだけを読み込む** をオンにします。反映には再起動が必要です。

### 管理者として実行しているとき {#administrator}

HexEditor を管理者として実行しているときは、プラグインも管理者の権限で動きます。そのため、起動のたびに、読み込むプラグインの一覧がまとめて表示され、**読み込む** か **読み込まない** を選びます。**読み込まない** を選ぶと、その起動の間はプラグインを読み込みません。

### セーフモード {#safe-mode}

プラグインや自動実行のスクリプトが原因で HexEditor がうまく動かないときは、セーフモードで起動できます。

- ショートカットやコマンドラインで、`--safe-mode` を付けて起動します。[コマンドラインからファイルを開く](command-line.md#open-from-the-command-line)を参照してください。
- または、<kbd>Shift</kbd> キーを押したまま HexEditor を起動します。最初のウィンドウが出るまで押し続けます。

セーフモードでは、プラグインを 1 つも読み込まず、自動実行のスクリプトも動かしません。ウィンドウに「セーフモードで起動しました。プラグインと自動実行のスクリプトは読み込まれていません。」と出ます。自分で実行したスクリプトとマクロは、通常どおり動きます。

セーフモードでは、プラグインの一覧と設定は変わりません。プラグインの追加もできません。問題のプラグインを無効にしたいときは、いったん通常どおり起動し直して、**プラグインの管理** で切り替えます。通知の **通常どおり再起動** で、すぐ戻れます。

## プラグインで追加できるもの {#what-plugins-add}

プラグインは、次のようなものを足せます。足されたものは、HexEditor 本体の同じ種類の機能と同じ場所に、同じ見た目で出ます。

| 追加できるもの | 出る場所 |
| --- | --- |
| インスペクタの型 | データインスペクタ ([データインスペクタ](inspector.md)) |
| ハッシュ | ハッシュの画面 ([ハッシュ](hashes.md)) |
| インポート形式、エクスポート形式 | インポート・エクスポートの画面 ([インポートとエクスポート](import-export.md)) |
| データソース | **ファイル > プラグインのデータソースを開く**、コマンドパレットの **開く: 名前** |
| データ演算 | **データ > プラグインのデータ演算** ([データ演算](data-operations.md)) |
| コマンド | コマンドパレット。ショートカットも割り当てられます |
| メニューの項目 | **ツール > プラグイン**、または右クリックメニューの **プラグイン** |
| パネル | **プラグインのパネル** |
| テンプレートの関数 | [構造体テンプレート](templates.md)から呼べる関数 |
| ファイル形式の判定 | テンプレートの[自動適用](templates.md#auto-apply) |
| 色付けルール | 値に応じた色付け |
| スクリプトの API | スクリプトから使えるオブジェクト |

各プラグインがどの機能を追加するかは、**プラグインの管理** の **追加するもの** で分かります。

プラグインの作りかたは、開発者向けの文書 (SDK のドキュメント) にあります。
