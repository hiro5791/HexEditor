# 変換ビュー

変換ビューは、データを変えずに、鍵との XOR などの変換をかけた結果を表示します。簡単な変換で隠されたデータを、ファイルを復号せずにそのまま読み書きするときに使います。

## XOR して表示 {#xor-view}

1. **データ > 変換ビュー > XOR して表示...** を選びます。
2. **鍵** を Hex で入れます (例: `5A`、`5A 3C`。1〜256 バイト)。
3. 鍵がオフセット 0 から始まらない場合は、**鍵の起点のオフセット** を入れます。
4. <kbd>Enter</kbd> を押すか、**OK** を選びます。

複数バイトの鍵では、オフセット *o* のバイトは、鍵の (*o* − 鍵の起点) mod 鍵の長さ 番目のバイトとの XOR で表示されます。

## 変換を定義する {#define}

**データ > 変換ビュー > 変換ビューの設定...** で、演算を 8 個までつなげて定義するダイアログが開きます。上から順にかけます。

| 演算 | 説明 |
| --- | --- |
| **XOR** | バイト列の鍵、または要素の大きさの数値 |
| **加算**、**減算** | 要素の大きさでラップします |
| **NOT** | すべてのビットを反転します |
| **左ローテート**、**右ローテート** | 指定したビット数だけ回します |
| **バイトスワップ (16 / 32 / 64 bit)**、**ビット順の反転**、**ニブルの入れ替え** | バイトやビットの順を入れ替えます |

[データ演算](data-operations.md) と同じく、要素の大きさ、エンディアン、オペランドの増分を指定できます。**範囲を指定** (既定はドキュメント全体) と **鍵の起点** も選べます。プレビューに、カーソル位置の 16 バイトの元のデータと表示が出ます。**名前** を入れて **この名前で保存** を選ぶと、ほかのドキュメントでも使えます。使っている変換はファイルごとに記録され、もう一度開くと戻ります。

プラグインが変換を追加することもあります。

## 変換ビューでの操作 {#working}

変換ビューが有効な間は、次のようになります。

- Hex ビューの左上に「変換ビュー: XOR 5A」のようなバッジが出て、ステータスバーにも同じ文字が出ます。エディタの枠は破線になります。
- 入力・貼り付け・塗りつぶしで書く値は、表示上の値として扱います。逆変換してから、データに書き込みます。
- 挿入・削除はできません (鍵の位置とデータがずれるため)。
- 検索、データインスペクタ、ハッシュ、統計、構造体テンプレート、逆アセンブル、YARA スキャンは、表示されているデータを対象にし、「変換ビュー: …」と示します。結果のエクスポートにも変換ビューのことを記録します。印刷、展開・復号も、表示されているデータを使います。データインスペクタでは、**元のデータを解釈** をオンにすると、変換前のバイトを解釈します。
- 保存、パッチの作成・適用、分割・結合・インターリーブは、元のデータを使います。長さが変わるパッチは、変換ビューの間は適用できません。
- コピーは、表示されているデータをクリップボードに入れます。元のデータをコピーしたいときは、設定の編集の **変換ビューでのコピー** を変えます。
- ファイルは変わりません。変換ビューの設定・解除は、元に戻すの履歴に残りません。

プラグインの変換で逆変換がないものは、読み取り専用になります。編集するには、変換ビューを解除します。

変換ビューを終えるには、**データ > 変換ビュー > 変換ビューの解除** を選びます。

## 変換をデータに書き込む {#apply-to-data}

**データ > 変換ビュー > この変換をデータに適用...** で、変換を実際のデータに書き込みます。演算が 1 つなら、同じ演算・鍵・範囲で [データ演算](data-operations.md) のダイアログが開きます。**実行** を選ぶと、変換ビューを解除してから演算を行います。演算をつないだ変換では、確かめてから書き込みます。
