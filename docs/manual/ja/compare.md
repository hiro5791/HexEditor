# ファイルの比較

2 つのドキュメントを並べて比べ、違うところを探します。ファイルの更新前と更新後を比べたり、保存したファイルと編集中の内容の違いを確かめたりするときに使います。

## 比較を始める {#start-a-comparison}

1. **解析 > 比較 > ファイルを比較** を選びます。コマンドパレットの **比較: ファイルを比較** でもかまいません。
2. **ファイルを比較** ダイアログが開きます。**左** と **右** の **対象** を選びます。
3. 比較方式を選びます。[単純な比較と挿入・削除を考える比較](#modes)を見てください。
4. **比較** を押します。

左右の対象には、次のものを選べます。

- 開いているドキュメント (一覧から選ぶ)
- ディスク上のファイル (**ファイルを選択...** で選ぶか、**ファイルのパス** に入力する)
- 開いているドキュメントの、ディスクに保存されている内容 (後述)
- プロセスメモリのスナップショット (**スナップショット...**。[プロセスのメモリのスナップショットの比較](#process-snapshots)を見てください)

左右それぞれに **開始オフセット** と **長さ** を指定できます。初めは、開始が 0 で、末尾までです。たとえば、左は `0x200` から、右は `0` から、のように別々の位置から比べられます。式を入力できます。**左右を入れ替え** を押すと、左右の設定がまとめて入れ替わります。

入力に問題があるときは、入力欄の下に理由が出て、**比較** が押せなくなります。たとえば、ファイルが存在しない、アクセスが拒否された、開始オフセットがデータの長さを超えている、などです。左右が同じドキュメントの同じ範囲のときは、警告が出ますが、実行できます。

比較は、新しいタブで開きます。タブの名前は「左の名前 ↔ 右の名前」です。同じ組み合わせの比較タブがすでにあるときは、そのタブに切り替えて、もう一度比較します。比較している間も、左右のドキュメントは編集できます。比較は、始めたときの内容で行われます。

ほかの始め方もあります。

- **タブの右クリックメニュー**: 1 つ目のタブで **比較の左側に選択** を選び、2 つ目のタブで **選択した左側と比較** (または「<名前> と比較」) を選びます。
- **解析 > 比較 > 保存済みの内容と比較**: 編集中の内容を、ディスクに保存されている同じファイルと比べます。左に保存済みの内容、右に編集中の内容が出ます。未保存の編集がなければ、「保存済みの内容と同じです」と知らせて終わります。一度も保存していない新規のドキュメントでは使えません。
- Explorer から 2 つのファイルを <kbd>Shift</kbd> を押しながらウィンドウにドロップすると、その 2 つで比較ダイアログが開きます。

比較のタブには、上に再比較、方式、前の差分、次の差分、同期スクロール、レイアウト、差分のコピーなどのボタンがあります。中央に左右の Hex ビュー、下に差分の一覧があります。左右の並べ方は、**表示 > 比較を上下に並べる** で、左右と上下に切り替えられます。

ビューの右端には、差分の位置を示す「差分マップ」が出ます。クリックすると、その位置に移動します。

ステータスバーには、「差分 12 / 340」のような現在の差分の番号と、異なるバイト数、一致率が出ます。

比較のタブの中で編集すると、「内容が変更されました。比較結果は古くなっています。」と出ます。**再比較** を押すと、もう一度比べます。左右のファイルが外部で変更されたときも、同じように知らせます。

## 単純な比較と挿入・削除を考える比較 {#modes}

比較方式は 2 つあります。

| 方式 | 向いている場面 |
| --- | --- |
| **単純比較** (初めの設定) | 長さの変わらない更新を比べる。同じ位置のバイトどうしを比べる |
| **挿入・削除を考慮した比較** | 途中にバイトが足されたり消えたりしたファイルを比べる。そのあとの一致する部分を、正しく対応付ける |

差分は、種類で色分けされます。色のほかに、印でも区別できます。

| 種類 | 意味 |
| --- | --- |
| **変更** | 同じ位置で値が違う |
| **挿入 (右のみ)** | 右にだけあるバイト |
| **削除 (左のみ)** | 左にだけあるバイト |
| **読み込み不可** | 読めない範囲 (不良セクタなど) |

単純比較は、長さが違うと、短い方の末尾より後ろを「左のみ」か「右のみ」の差分にします。

挿入・削除を考慮した比較は、近似的な結果です。最短の編集手順とは限りません。結果の要約に「挿入・削除を考慮 (近似)」と出ます。

比較のオプションは、ダイアログの **オプション** か、比較タブの **オプション** で変えます。変えたら **再比較** を押します。前回の設定は、次回の初めの設定になります。

| オプション | 内容 |
| --- | --- |
| **比較の単位** | 1、2、4、8 バイト。単位の中の 1 バイトでも違えば、単位全体が差分になる |
| **近い差分をまとめる (バイト)** | 間の一致が指定のバイト数以下なら、1 つの差分にまとめる。0 〜 65,536 |
| **再同期ウィンドウ (バイト)** | 挿入・削除を考慮した比較で、一致を探す範囲。256 バイト〜16 MB。初めは 64 KB |
| **最小一致長 (バイト)** | 挿入・削除を考慮した比較で、一致と認める最小の長さ。1〜4,096。初めは 8 |

大きなファイルでも比較できます。ファイル全体をメモリに読み込まないので、メモリの使用量はファイルの大きさに比例しません。比較は、バックグラウンドで進み、進捗が表示されます。見つかった差分は、比較の途中からすぐに表示されます。途中でキャンセルしても、そこまでの結果は残ります。

## 差分の間の移動 {#differences}

次のどれかで、差分の間を移動します。

- <kbd>Alt</kbd>+<kbd>F5</kbd>: 次の差分。
- <kbd>Shift</kbd>+<kbd>Alt</kbd>+<kbd>F5</kbd>: 前の差分。
- **移動 > 次の差分** と **移動 > 前の差分**。
- 比較タブのツールバーの **次の差分**、**前の差分** ボタン。
- 差分の一覧で行を選ぶ。

移動すると、その差分の範囲が左右とも選択されます。最後の差分から次へ進むと、先頭に戻り、「先頭の差分に戻りました」と出ます。差分がないときは、「差分はありません」と出ます。比較の途中でも、見つかった差分の間を移動できます。移動はジャンプ履歴に残るので、<kbd>Alt</kbd>+<kbd>←</kbd> で元の位置に戻れます。

比較タブ以外のタブでも、そのドキュメントを含む比較が開いていれば、同じキーで差分の間を移動できます。

下のパネルの **差分** に、差分の一覧が出ます。**表示 > パネルの表示切り替え > 差分** で開き閉じします。一覧には、番号、種類、左右のオフセットと長さ、左右の先頭のバイトが出ます。

- 種類で絞り込めます。**最小の長さ** で、短い差分を隠せます。
- **並べ替え** で、番号順、長さの長い順、短い順を選べます。
- **エクスポート** で、CSV、JSON、テキストのレポートに書き出せます。選んだ行だけを CSV に出すこともできます。**比較: レポートを保存** (コマンドパレット) でも、要約と全差分のレポートを保存できます。
- 選んだ差分を、**マルチ選択に変換** したり、**ブックマークに変換** したりできます。左右のどちらのドキュメントに作るかを選びます。

一覧の横には、**差分の分布** のグラフが出ます。ファイル全体を区間に分けて、各区間で違うバイトの割合を棒で示します。棒をクリックすると、その区間の最初の差分に移動します。**表で表示** で、数値の表に切り替えられます。要約には、比較方式、比較したバイト数、差分の件数、異なるバイト数、一致率、かかった時間が出ます。

### 差分をコピーして揃える {#merge}

差分の内容を一方からもう一方へコピーして、2 つを揃えられます。

- **差分を右へコピー** と **差分を左へコピー**: 現在の差分、または一覧で選んだ差分をコピーします。
- **すべての差分を右へコピー** と **すべての差分を左へコピー**: すべてをコピーします。

右へコピーすると、左の内容で右が置き換わります。「変更」は右を左の内容で置き換え、「削除 (左のみ)」は左の内容を右に挿入し、「挿入 (右のみ)」は右の該当部分を削除します。左へのコピーは、この逆です。

覚えておくことがあります。

- 1 回の操作は、書き込み先のドキュメントの Undo 1 回分です。まとめてコピーしても、<kbd>Ctrl</kbd>+<kbd>Z</kbd> 1 回で戻ります。
- 書き込み先が読み取り専用のときは、コピーできません。
- ディスクやプロセスメモリのように長さを変えられない書き込み先には、長さが変わる差分はコピーされません。コピーしなかった件数が知らされます。
- コピーしても保存はされません。書き込み先のドキュメントが「変更あり」になるだけです。保存は自分で行います。

## 同期スクロール {#synchronized-scrolling}

比較のタブでは、初めから同期スクロールがオンです。片方をスクロールすると、もう片方も、対応する位置にスクロールします。カーソルを動かしたときも、相手のカーソルが対応する位置に動きます。

- 単純比較では、同じ位置の行が同じ高さに並びます。
- 挿入・削除を考慮した比較では、対応する位置が同じ高さに並びます。挿入や削除の位置には、揃えるための斜線の帯が出ます。

ツールバーの **同期スクロール** で、オンとオフを切り替えます。オフにすると、左右は別々にスクロールします。オンに戻すと、フォーカスのある側に合わせます。

## プロセスのメモリのスナップショットの比較 {#process-snapshots}

プロセスのメモリを、ある時点で保存しておき、別の時点のものや現在のメモリと比べられます。プログラムの動きによって、メモリのどこが変わるかを調べるときに便利です。

### スナップショットを作る

1. スナップショットを作りたいプロセスのメモリを、タブで開きます。
2. **解析 > 比較 > プロセスのスナップショットを作成** を選びます。
3. **名前** を付けて **作成** を押します。

このコマンドは、プロセスのメモリを開いているタブで使えます。名前のほかに、スナップショットの保存と同じく、**対象** (**読めるすべての領域**、**選んだ領域・モジュール (メモリマップのパネル)**、**書き込み可能な領域だけ**) と **取得中は対象のプロセスを一時停止する** を選べます ([プロセスのスナップショット・ミニダンプを保存する](opening-files.md#process-snapshot) を参照)。

スナップショットは、一時フォルダに `.hexsnap` ファイルとして保存されます。アプリを終了すると削除されます。残したいときは、**名前を付けて保存** で別の場所に保存します。プロセスによっては、読むのに管理者権限が必要です。その場合は、管理者権限で作り直すかどうかを聞かれます。読めなかったページは、スナップショットに含まれません。

### 比べる

1. 作ったスナップショットは、タブとして開いています。比べたいものを、タブで開いておきます。保存した .hexsnap ファイルも、**ファイル > 開く** で開けます。
2. **解析 > 比較 > スナップショットを比較** を選びます。コマンドパレットの **比較: スナップショットを比較** でもかまいません。
3. 比較ダイアログが開きます。左には最も古いスナップショット、右には最も新しいスナップショット (1 つしかないときは、プロセスメモリのタブ) が選ばれています。必要なら **対象** や **スナップショット...** で選び直して、**比較** を押します。

スナップショットどうしでも、スナップショットと現在のメモリでも比べられます。

領域ごとに、開始アドレスが同じものどうしを比べます。片方にしかない領域は、**領域の追加** と **領域の削除** として一覧に出ます。大きさの変わった領域は、短い方まで比べて、残りを「左のみ」「右のみ」にします。

差分の一覧には、オフセットの代わりに、仮想アドレスと領域の名前 (モジュール名 + オフセットなど) が出ます。読めなかったページは「読み込み不可」と表示され、差分の件数には数えません。

プロセスのメモリを開く方法は、[ファイルを開く](opening-files.md)を見てください。
