# 統計と解析

統計パネルは、ドキュメントの一部または全体に、どんな値がどれだけ含まれているかを調べます。データがテキストなのか、圧縮や暗号化されているのか、どんな繰り返しがあるのかを知る手がかりになります。ファイル形式の判定もここで説明します。

統計パネルは、**解析 > 統計** で開きます。**表示 > パネルの表示切り替え > 統計** や、コマンドパレットの **解析: 統計を表示** でも開けます。

バイトを選んで右クリックし、**統計** を選んでも開けます。この項目は、選択範囲があるときだけ使えます。選択範囲が **対象範囲** になります。

パネルの上の部分で、調べる範囲と設定を決めます。下にはタブ (**ヒストグラム**、**記述統計**、**エントロピー**、**ダイグラム**、**パターン**、**分類**) が並びます。

- **対象範囲**: **選択範囲**、**マルチ選択**、**ドキュメント全体**、**範囲を指定** から選びます。範囲を指定するときは、**開始** と、**長さ / 終了** を入力します。
- **型**: 1 つの値を何バイトの数として読むかを決めます。バイト (`u8`) が初めの設定です。16 〜 64 bit の整数や、浮動小数点の `f32` / `f64` も選べます。2 バイト以上の型では、**ビッグエンディアン** と **ストライド** (何バイトごとに読むか) も決められます。
- **自動で再計算**: オンにすると、対象範囲が変わって 0.3 秒後に、自動で計算し直します。対象が 64 MB を超えるときは、自動では計算せず、**再計算** のボタンが強調されます。
- **再計算** と **キャンセル**: 計算を始めたり、止めたりします。

計算は、バックグラウンドで 1 回の読み込みで行います。ファイルが大きくても、画面は固まりません。計算の途中の結果は、少しずつ画面に出ます。キャンセルしても、そこまでの結果が「途中で中止 (xx% まで)」と表示されて残ります。読めない範囲があるときは、その範囲を除いて計算し、読めなかった数が表示されます。編集したあとは、「結果は編集前の内容のものです」と出ます。

どのグラフにも **表で表示** があり、同じ値を表で見られます。

## バイトのヒストグラムとエントロピー {#histogram}

### ヒストグラムのタブ {#histogram-tab}

**ヒストグラム** のタブは、値ごとの出現回数を棒グラフにします。バイトの場合は 256 本の棒になります。

- 縦軸は、件数か割合 (%) です。**対数目盛り** をオンにすると、少ない値も見やすくなります。
- バイト以外の型では、**ビンの数** (2 〜 65,536) と範囲を指定します。**範囲を自動** がオンのときは、最小値から最大値までです。範囲の外の値は、「範囲より小さい」「範囲より大きい」の欄で数えます。16 bit の型は **値ごと (65,536 個)** も選べます。
- 浮動小数点の NaN と ±∞ は、ビンに入れず、別の欄で数えます。
- 表には、値、件数、割合、累積割合が出ます。バイトの場合は、文字の列も出ます。**並べ替え** で、値の順か件数の順を選べます。
- バイトの場合は、`0x00`、`0xFF`、印字可能な ASCII、空白類、その他の制御文字、`0x80`〜`0xFF` の割合も出ます。
- 棒または表の行をダブルクリックすると、その値の次の出現位置に移動します。右クリックの **この値をすべて検索** で、その値をすべて検索できます。
- **表をコピー** で、表をタブ区切りのテキストとしてコピーできます。**エクスポート** で、CSV か JSON に書き出せます。

### 記述統計 {#descriptive}

**記述統計** のタブには、次の値が並びます。項目名にマウスを重ねると、定義が出ます。

- **要素数**、**合計**、**最小値**、**最大値**、**範囲**、**平均**
- **母分散**、**標本分散**、**母標準偏差**、**標本標準偏差**
- **中央値**、**第 1 四分位数**、**第 3 四分位数**、**最頻値**
- **歪度**、**尖度**
- **カイ二乗値** (バイトのみ。値が一様に散らばっているかの目安)
- **系列相関係数** (隣り合う値の関係)
- **モンテカルロ法の π** (バイトのみ。乱数らしさの目安)

16 bit より大きい型で要素が 1,600 万を超えるときは、中央値と四分位数が近似値になり、先頭に `≈` が付きます。最頻値は求めません。計算できない項目は「—」で、理由がツールチップに出ます。**値をコピー** と **すべてコピー** で、結果をコピーできます。

### エントロピー {#entropy}

**エントロピー** のタブは、データのばらつきの度合いを示します。バイトでは 0 〜 8 ビット / バイトです。0 に近いほど同じ値の繰り返しで、8 に近いほど乱数に近くなります。

- **エントロピー** と **エントロピー (%)**、**冗長度**、**理論上の最小サイズ** が出ます。
- **圧縮率を推定する** をオンにすると、データの一部 (最大 64 MB) を実際に圧縮して、圧縮率を見積もります。標本の大きさが「標本: 64 MB / 10 GB」のように表示されます。
- バイトの場合は、目安が文章で出ます。「ほぼ同じ値の繰り返し」「テキストや構造化データの可能性」「一般的なバイナリ (実行形式など) の可能性」「圧縮または暗号化されたデータの可能性」のどれかです。

**エントロピーグラフ** は、対象範囲をブロックに分けて、ブロックごとのエントロピーを折れ線で示します。

- **ブロックの大きさ** は、初めは自動です。256 バイト〜64 MB から選べます。
- **0x00 の割合** と **印字可能な ASCII の割合** を重ねて表示できます。
- **しきい値 (ビット)** の線 (初めは 7.2) が引かれ、それを超える部分は模様で示されます。
- **拡大** と **縮小** (または <kbd>Ctrl</kbd> を押しながらマウスホイール) で、横に拡大できます。拡大すると、表示している範囲が細かいブロックで計算し直されます。
- グラフをクリックすると、そのブロックの先頭に移動します。ドラッグすると、その範囲を選択します。グラフにフォーカスがあるときは、<kbd>←</kbd> と <kbd>→</kbd> でブロックを移り、<kbd>Enter</kbd> で移動できます。
- **CSV にエクスポート** で、グラフの値を書き出せます。

ヒストグラムの値は、エントロピーの計算にも使われます。圧縮や暗号化されたデータは、エントロピーが 8 に近い平らなグラフになります。

## ダイグラムとバイト分布 {#digram}

**ダイグラム** のタブには、2 つの図があります。**図** で切り替えます。

- **ダイグラム**: 連続する 2 バイトの組が、どれだけ現れるかを示す 256 × 256 の図です。横軸が最初のバイト、縦軸が次のバイトです。色が濃いほど、その組が多く現れます。たとえばテキストなら、文字の範囲に偏ります。
- **位置ごとの分布**: 横軸がオフセット、縦軸がバイトの値の図です。ファイルのどの部分に、どんな値が多いかが分かります。

図にマウスを重ねると、値、件数、割合が出ます。ダイグラムのセルをダブルクリックすると、その 2 バイトの組を検索します。位置ごとの分布のセルをクリックすると、その区間の先頭に移動します。対象が 2 バイト未満のときは、「2 バイト以上の範囲を指定してください」と出ます。

## パターン統計 {#pattern-statistics}

**パターン** のタブは、よく現れるバイト列と、繰り返しの周期を調べます。設定してから **計算** を押します。

- **長さ (n)**: 調べるバイト列の長さ。2 〜 16 バイトです。初めは 4 です。
- **上位**: 何件まで出すか。10 〜 10,000 件です。初めは 100 です。
- **最小件数**: これ以上現れた列だけを出します。初めは 2 です。
- **オフセット mod ... の値**: 位置の条件です。たとえば「オフセット mod 4 が 0」にすると、4 の倍数の位置だけを数えます。
- **すべて 0x00 / 0xFF の列を除く**: 初めからオンです。

**結果** で、2 つの見方を切り替えます。

- **よく現れるバイト列**: 順位、Hex、テキスト、件数、割合、最初の出現位置が並びます。行をダブルクリックすると、最初の出現位置に移動します。右クリックの **すべて検索** で、その列をすべて探せます。
- **周期**: データが何バイトごとに繰り返されているかの推定です。固定長のレコードが並ぶファイルなら、レコードの長さが上位に出ます。右クリックの **この長さでレコード表示** で、その長さのレコードごとに背景色を交互に変える表示にできます。

大きなファイルでも、作業に使うメモリは 256 MB までです。件数は正確な値が出ます。キャンセルすると、途中の結果は捨てられます。

## 暗号化・圧縮・既知の形式のデータの検出 {#detection}

### 暗号化・圧縮データの検出 {#classify}

**分類** のタブ (または **解析 > 暗号化・圧縮データの検出**) は、対象範囲をブロックに分けて、ブロックごとに種類を判定します。

| 分類 | おおよその意味 |
| --- | --- |
| **ゼロ埋め** / **定数** | ほぼ同じ値だけ |
| **テキスト** | 文字がほとんど |
| **バイナリ** | 実行形式やデータなど |
| **圧縮** | エントロピーが高く、圧縮されたデータらしい |
| **暗号化・乱数** | エントロピーが非常に高く、値が一様 |
| **読み込み不可** | 読めなかったブロック |

**ブロックの大きさ** は、初めは 4 KB で、512 バイト〜1 MB から選べます。**分類する** を押すと、同じ分類が続く部分が 1 つの区間にまとまって、一覧に出ます。一覧には、開始、長さ、分類、平均エントロピー、判定の確度 (**高**、**中**、**低**) が並びます。上の帯は、分類の割合を色と模様で示します。

zlib、gzip、zstd、xz、bzip2、LZ4、7z、ZIP などの圧縮形式の印 (シグネチャ) も探して、見つかった位置を一覧に加えます。

この判定は、統計に基づく推定です。パネルに「統計に基づく推定で、誤判定がありえます」と常に出ます。結果を信じすぎないでください。

### ファイル形式の判定 {#file-type}

ファイルの形式は、先頭の印 (マジックナンバー) などから判定できます。

- **解析 > ファイル形式の判定** で、**ファイル形式** パネルが開きます。**判定** を押すと、候補が確度の高い順に並びます。形式の名前、MIME タイプ、拡張子、確度が出ます。
- **カーソル位置から判定** は、カーソルの位置をデータの先頭とみなして判定します。ファイルの中に埋め込まれたデータを調べるときに使います。
- **埋め込まれた形式を探す** は、対象範囲のすべての位置から、既知の形式の印を探します。見つかった位置が、一覧に出ます。
- 拡張子と内容が合わないとき (たとえば `.jpg` なのに中身が PNG) は、「拡張子と内容が一致しません」と出ます。
- どれにも当たらないときは、「不明な形式 (データ)」か、「テキスト (UTF-8)」などと出ます。

ファイルを開くと、先頭と末尾の 64 KB を使って形式が自動で判定され、最も確度の高い形式の名前がステータスバーに出ます。名前をクリックすると、パネルが開きます。
