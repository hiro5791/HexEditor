# 設定とショートカット

このページでは、設定画面の使い方、設定の保存場所、ショートカットの変え方、コマンドパレットを説明します。変更はすぐに反映されます。「OK」や「適用」を押す必要はありません。

## 設定画面 {#settings-screen}

<kbd>Ctrl</kbd>+<kbd>,</kbd> (**ツール > 設定**) で、設定画面がタブとして開きます。コマンドパレットの **設定: 設定を開く** からも開けます。

左にカテゴリ、右に項目が並びます。

| カテゴリ | 主な内容 |
| --- | --- |
| **全般** | 起動時の動作、ウィンドウ、最近使ったファイル |
| **外観** | テーマ、背景素材、配色、フォント |
| **表示** | Hex ビューの表示、ズーム、文字コード |
| **編集** | 入力モード、貼り付け、元に戻す |
| **検索** | 検索の初期値と上限 |
| **ファイルと保存** | バックアップ、復旧用データ、外部変更 |
| **キーボード** | ショートカット |
| **言語** | 表示言語 |
| **アクセシビリティ** | スクリーンリーダーの読み上げ |
| **自動化** | スクリプトとプラグイン |
| **逆アセンブル** | [逆アセンブル](disassembly.md#display-options) の構文、数値の書式、列 |
| **フォレンジック** | ケース、書き込み保護、監査ログ、日時の表示、カービング、レポート、パーティションとファイルシステム |
| **更新** | 自動更新とチャネル |
| **プライバシー** | ネットワークを使う機能 |
| **Explorer 連携** | 右クリックメニューとファイルの関連付け |
| **詳細** | データフォルダ、設定ファイル、リセット、インポート / エクスポート |

- 上の **設定を検索** 欄に入力すると、項目の名前と説明を、カテゴリをまたいで探せます。
- 既定値から変えた項目には、左に縦線が付きます。**既定に戻す** で、その項目だけ戻せます。
- カテゴリ名の横の **その他の操作** から、**このカテゴリを既定に戻す** も選べます。
- 再起動が必要な項目 (表示言語など) には、項目の下に「再起動後に反映されます」と出ます。上の **今すぐ再起動** を選ぶと、再起動します。開いているタブは、再起動のあとも元に戻ります。
- 入力した値が正しくないときは、赤い枠と理由が出て、保存されません。

コマンドパレットで `#` に続けて入力すると、設定項目を探して、その項目を開けます。

## 設定ファイル {#settings-file}

設定は、JSON のファイルに保存されます。設定を直接編集したい人や、設定を別の PC にコピーしたい人は、このファイルを使えます。ふつうに使うだけなら、触る必要はありません。

**ツール > 設定 > 詳細** の **データフォルダを開く** で、保存先のフォルダを開けます。コマンドパレットの **設定: データフォルダを開く** でも開けます。フォルダの場所は、配布形態によって違います。

| 配布形態 | 設定の保存先 |
| --- | --- |
| Microsoft Store 版 | アプリ専用の保存場所 (`%LocalAppData%\Packages\...\LocalState\`) |
| インストーラ版 | `%LocalAppData%\HexEditorData\` |
| ポータブル版 | `HexEditor.exe` の隣の `Data` フォルダ |

フォルダの中の主なファイルは、次のとおりです。

| ファイル | 内容 |
| --- | --- |
| `settings.json` | 既定から変えた設定だけ |
| `keybindings.json` | ショートカットの変更 |
| `themes\` | 独自の配色 |
| `session.json` | 開いていたタブの状態 |
| `recent.json` | 最近使ったファイル |
| `documents\` | ドキュメントごとの表示の設定、ブックマークなど |

`settings.json` を開くには、**設定: 設定ファイルを開く** (コマンドパレット) を使います。`settings.json` は、`"ui.theme": "dark"` のように、設定のキーと値を並べた形です。アプリを動かしたまま編集すると、1 秒ほどで反映されます。書き方に誤りがあると、直前の設定を使い続け、画面上部のバーに誤りの場所が出ます。

- 設定ファイルが壊れていたときは、既定の設定で起動し、壊れたファイルは残します。
- 新しい版の HexEditor で書かれた設定ファイルは、読み込むだけで、書き換えません。

## 設定のインポート・エクスポート・リセット {#import-export-settings}

### エクスポートとインポート

**ツール > 設定 > 詳細** で、設定を 1 つのファイルにまとめて書き出したり、読み込んだりできます。別の PC へ移すときや、配布形態を変えるときに使います。

1. **設定をエクスポート** を選び、含めるものを選びます (設定、ショートカット、独自の配色、最近使ったファイル)。
2. ファイルの名前と場所を決めます。

**設定をインポート** では、ファイルに含まれる区分ごとに、変わる項目の数が出ます。**置き換える** か **マージ** かを選べます。読み込む前に、今の設定のバックアップが作られます。データフォルダの場所のように、配布形態ごとの項目は含まれません。

### リセット

- 1 つの項目: **既定に戻す**。取り消すための **元に戻す** が、8 秒間出ます。
- カテゴリ全体: カテゴリ名の横の **その他の操作** から **このカテゴリを既定に戻す**。
- すべて: **ツール > 設定 > 詳細** の **すべての設定を既定に戻す**。戻す対象 (設定、ショートカット、独自の配色など) を選べます。

すべてを戻すときは、今のファイルが `backup-日時` のフォルダにコピーされます。直近の 5 個が残ります。

## テーマ・フォント・配色 {#appearance}

**ツール > 設定 > 外観** で、見た目を変えます。

- **テーマ** (**表示 > テーマ** でも変えられます): **Windows の設定に従う** (既定)、**ライト**、**ダーク**。Windows のハイコントラストは、いつも Windows の設定に従います。
- **ウィンドウの背景素材**: **Mica** (既定)、**Mica Alt**、**なし**。Mica が使えない環境では、自動で単色になります。
- **配色**: Hex ビューの色を、配色として選びます。同梱の配色は、複製して独自の配色を作れます。文字と背景のコントラストが低いときは、警告が出ます。
- **フォント**、**フォントの大きさ (pt)**、**行間**: Hex ビューの文字を決めます。フォントは、等幅フォントだけが出ます (**すべてのフォントを表示** で、すべて出せます)。既定は Cascadia Mono です。
- **アクセントカラー**: 選択範囲、フォーカスの枠、強調のボタンに使う色です。**Windows のアクセントカラー** (既定) か、**指定した色** を選びます。再起動後に反映されます。ハイコントラストでは使いません。
- **Windows の文字の大きさに合わせる** がオンのときは、Windows の「文字の大きさ」の設定に合わせて、Hex ビューも大きくなります。

メニューやダイアログの文字のフォントは、Windows の標準で、変えられません。

## ファイルとデータの扱い {#files-and-saving}

**ツール > 設定 > ファイルと保存** で、ファイルの扱いを変えます。

- **ファイルのロック**: 開いているファイルに、他のアプリが書き込めるかどうかを決めます。変えたあとに開いたファイルから反映されます。すでに開いているファイルは変わりません。
  - **編集中だけ他のアプリの書き込みを禁止する** (既定): 未保存の変更があるあいだだけ、他のアプリの書き込みを止めます。
  - **開いている間、常に他のアプリの書き込みを禁止する**: 開いているあいだずっと、他のアプリの書き込みを止めます。
  - **ロックしない (他のアプリの書き込みを常に許可する)**: 他のアプリがいつでも書き込めます。
- **代替データストリームがあるファイルを開いたときに知らせる**: 既定はオフです。[NTFS の代替データストリーム](alternate-streams.md#notice) を参照してください。

バックアップと復旧用データの設定は、[バックアップと復旧](opening-files.md#backups-and-recovery) を見てください。

## 自動化の設定 {#automation-settings}

**ツール > 設定 > 自動化** には、スクリプトとプラグインの設定があります。同時に実行できるスクリプトの数、実行時間とメモリの上限、スクリプトを追加するフォルダ、自動実行 (フック) などを変えられます。

- **信頼と許可**: 「常に許可する」を選んだスクリプトの一覧です。**取り消す** で、次の実行から確認が戻ります。組織の方針は読み取り専用で出ます。[「常に許可する」を確認して取り消す](scripting.md#revoke-trust)を参照してください。
- **C# スクリプト コンポーネント**: 入っているバージョンの確認、**追加...**、**削除**、**コンパイル結果のキャッシュを削除** ができます。[コンポーネントを管理する](scripting.md#csharp-component-manage)を参照してください。

## 表示言語 {#display-language}

HexEditor は、23 の言語で表示できます。既定では、Windows の表示言語に従います。

1. **ツール > 設定 > 言語** を開きます (コマンドパレットの **設定: 表示言語を変更** でも開けます)。
2. 一覧から言語を選びます。一覧の先頭は **Windows の設定に従う** です。各言語は、その言語自身の名前で並びます。
3. **今すぐ再起動** を選びます。

未保存の変更があるときは、再起動の前に確認が出ます。開いていたタブは、再起動のあとも元に戻ります。Windows の言語が一覧にないときは、英語で表示されます。

アラビア語とペルシア語では、画面の左右が反転します。Hex ビューの中は、いつも左から右です。

数字や日時の書式は、表示言語ではなく、Windows の地域の設定に従います。

翻訳の誤りを見つけたときは、[翻訳の誤りを報告する](troubleshooting.md#report-a-translation) を見てください。

## コマンドパレット {#command-palette}

<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd> か <kbd>F1</kbd> (**ヘルプ > コマンドパレット**) で、コマンドパレットが開きます。すべてのコマンドを、名前で探して実行できます。メニューのどこにあるか分からないときに便利です。

1. コマンドパレットを開きます。
2. コマンド名の一部を入力します。文字が順に含まれていれば一致します。日本語のコマンドには、ひらがなの読みでも一致します (例: 「ハッシュ」を「はっしゅ」で)。
3. <kbd>↑</kbd> <kbd>↓</kbd> で選び、<kbd>Enter</kbd> で実行します。<kbd>Esc</kbd> で閉じます。

候補には、カテゴリ、ショートカット、使えないときはその理由が出ます。入力が空のときは、最近使ったコマンドが先頭に出ます。

先頭に付ける記号で、探す対象を切り替えられます。

| 入力の先頭 | 探す対象 |
| --- | --- |
| `>` | コマンド (<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd> は、これで開きます) |
| なし | 開いているタブと最近使ったファイル |
| `:` | オフセットへ移動 (例: `:0x1F00`) |
| `@` | 今のドキュメントのブックマーク |
| `#` | 設定の項目 |
| `?` | 記号の一覧 |

### ショートカットを変える

1. **ツール > 設定 > キーボード** を開きます (コマンドパレットの **設定: キーボードショートカット** でも開けます)。
2. 上の検索欄で、コマンドの名前かキー (例: `ctrl+g`) を入力して絞り込みます。**キーで検索** を選ぶと、押したキーで探せます。
3. 変えたいコマンドの行の **編集** を選びます。
4. 新しいキーを押します。2 回押す組み合わせ (例: <kbd>Ctrl</kbd>+<kbd>K</kbd> のあとに <kbd>Ctrl</kbd>+<kbd>F</kbd>) も使えます。<kbd>Enter</kbd> で確定します。

- 1 つのコマンドに、複数のキーを割り当てられます。
- すでに別のコマンドで使っているキーは、一覧で知らせます。**置き換える** を選ぶと、そちらから外れます。
- **有効範囲** (グローバル、エディタ、検索バー、パネル) を選べます。狭い範囲の割り当てが、広い範囲の同じキーより先に働きます。
- 行の **既定に戻す** と、表の上の **すべて既定に戻す** で戻せます。
- Alt+F4、Windows キーとの組み合わせ、修飾キーのない文字や数字のキーは、割り当てられません。
- **エクスポート** と **インポート** で、割り当てをファイルに書き出して、別の PC で読み込めます。

## ショートカットのプリセット {#presets}

ほかのエディタに慣れている人のために、キーの割り当てを一式で切り替えられます。**ツール > 設定 > キーボード** の **プリセット** で選びます。初めて起動したときのスタートページの **はじめに** からも選べます。

| プリセット | 内容 |
| --- | --- |
| **既定** | HexEditor の標準 |
| **HxD 風** | HxD のキーに合わせる |
| **010 Editor 風** | 010 Editor のキーに合わせる |
| **VS Code 風** | VS Code のキーに合わせる |

プリセットを切り替えても、自分で変えた割り当ては残ります。プリセットと重なるときは、自分の割り当てを優先するか、プリセットを優先するかを選べます。

## ワークスペースとプロジェクト {#workspaces}

ワークスペースは、今のウィンドウのタブとパネルの配置に、名前を付けて保存したものです。いつもの組み合わせで開きたいときに便利です。

- **ファイル > ワークスペース > 保存** で、`.hexworkspace` のファイルに書き出します。
- **ファイル > ワークスペース > 開く** で、読み込みます。Explorer から `.hexworkspace` をダブルクリックしても開きます。

ワークスペースには、ファイルの中身や、ブックマークのようなドキュメントごとのデータは含まれません。タブとパネルの様子が保存されます。

## Explorer との連携とファイルの関連付け {#explorer}

**ツール > 設定 > Explorer 連携** で、Explorer の右クリックメニューとファイルの関連付けを設定します。

- **右クリックメニュー「HexEditor で開く」**: Explorer でファイルを右クリックして、HexEditor で開けます。複数のファイルを選ぶと、すべてが 1 つのウィンドウのタブで開きます。Windows 11 では、**その他のオプションを確認** の中に出ることがあります。
- **ファイルの関連付け**: `.hexproj` と `.hexworkspace` は HexEditor に関連付けられます。`.bin`、`.dat`、`.img`、`.rom`、`.dmp`、`.raw`、`.iso` は、**プログラムから開く** の候補に加わるだけで、既定のアプリは変わりません。既定にしたいときは、Windows の **既定のアプリ** の設定を開く **既定のアプリを設定** を使います。

配布形態による違いは、次のとおりです。

| 配布形態 | 右クリックメニューと関連付け |
| --- | --- |
| Microsoft Store 版 | インストールと同時に登録されます。設定画面では変えられません |
| インストーラ版 | インストール時に登録されます。画面の **登録を解除する** で外せます |
| ポータブル版 | 初めは登録されません。画面の **登録する** で登録します |

ポータブル版で登録したあとに、フォルダを移動したときは、登録の更新をすすめるバーが出ます。**更新する** を選んでください。

ポータブル版を削除する前に、**この PC から登録を解除** を選ぶと、登録した右クリックメニュー、関連付け、ジャンプリスト、一時ファイルがまとめて消えます。その後でフォルダを削除してください。

タスクバーの HexEditor のアイコンを右クリックすると、ジャンプリストに、ピン留めと最近使ったファイル、よく使う操作が出ます。

## プライバシーとネットワーク {#privacy}

HexEditor は、利用状況、クラッシュの情報、設定、開いたファイルの情報を、どこにも送りません。送る設定もありません。

HexEditor がインターネットを使うのは、次の場合だけです。

| 機能 | 接続先 |
| --- | --- |
| 更新の確認とダウンロード | GitHub Releases (インストーラ版・ポータブル版)、Microsoft Store (Store 版) |
| テンプレートやプラグインなどのダウンロード | 配布先。操作したときだけ |
| 追加コンポーネントのダウンロード | 更新と同じ配布元。操作したときだけ |
| ドキュメントや翻訳の報告のページを開く | GitHub。ブラウザで開く |

**ツール > 設定 > プライバシー** で、これらを個別に、またはまとめて止められます。**オフラインモード** をオンにすると、上の機能がすべて止まります。通信には、Windows のプロキシの設定を使います。

リモートのデータソースやスクリプトの通信は、あなたが指定した接続先に、許可したときだけ接続します。オフラインモードの対象外です。

初めて起動したとき、スタートページに、ネットワークを使う機能の一覧が出ます。ログは、このパソコンの中にだけ保存されます。ファイルの内容は書きません。

## 更新 {#updates}

更新の確認は、起動の 30 秒後と、その後 24 時間ごとに自動で行います。**ヘルプ > 更新の確認** で、いつでも確認できます。手動で確認したときは、結果が必ず出ます。

**ツール > 設定 > 更新** で、次を選べます。

- **更新を自動で確認する**
- **更新を自動でダウンロードする** (インストーラ版)
- **更新のチャネル**: **安定版** (既定) か **プレビュー版**
- **この版をスキップ**: 画面上部のバーで選ぶと、その版を知らせなくなります。

配布形態ごとの更新は、次のとおりです。

| 配布形態 | 更新のしかた |
| --- | --- |
| インストーラ版 | 裏でダウンロードします。準備ができると、バーに **再起動して更新** が出ます。**後で** を選ぶと、アプリを終了したときに更新します。保存などの処理が動いている間は、再起動できません |
| Microsoft Store 版 | Microsoft Store が自動で更新します。アプリ内のバーの **Microsoft Store で更新** で、Store のページを開けます |
| ポータブル版 | 自動では入れ替えません。バーの **ダウンロードページを開く** で、新しい版のページを開きます。新しい zip を展開して、古いフォルダの `Data` を移してください |

更新のあとの最初の起動で、「版 X に更新しました」とバーが出ます。**リリースノート** で、変更点を読めます。更新に失敗したときは、前の版のままです。
