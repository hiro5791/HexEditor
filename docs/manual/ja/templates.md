# 構造体テンプレート

このページでは、構造体テンプレートをファイルに適用して中身を読み解く方法と、自分でテンプレートを書いてデバッグする方法を説明します。言語の詳しい説明は、[テンプレートの標準ライブラリ](template-library.md)と[テンプレートのエラーコード](template-error-codes.md)のページにあります。

構造体テンプレートは、バイト列の「形」を書いた設計図です。たとえば PNG のテンプレートを PNG ファイルに適用すると、シグネチャ、ヘッダ、各チャンクが名前と値の付いたツリーで表示されます。Hex 列の中では、各部分が色分けされます。

## テンプレートを適用する {#apply-a-template}

1. 適用したいドキュメントを開きます。
2. **解析 > 構造体テンプレート > テンプレートを適用** を選びます。コマンドパレットの **テンプレート: 適用** でも開けます。
3. 一覧からテンプレートを選びます。**テンプレートを検索** の欄に、名前、説明、拡張子、MIME タイプの一部を入力して絞り込めます。最近使ったテンプレートは上に出ます。
4. 必要なら **開始オフセット**、**既定のエンディアン**、**種類** を変えます。
5. **適用** を選びます。

適用すると、**構造体** パネルに結果のツリーが出ます。パネルが閉じているときは、**表示 > パネルの表示切り替え > 構造体** で開きます。

カーソルの位置から適用するには、Hex 列を右クリックして **ここからテンプレートを適用** を選びます。**開始オフセット** にカーソルの位置が入ります。

### 固定と追従 {#fixed-and-follow}

**種類** には 2 つあります。

- **固定** (既定): 開始オフセットに構造体を固定します。カーソルを動かしても結果は変わりません。
- **追従**: カーソルのある位置を開始オフセットとして、選んだ 1 つの型を読みます。カーソルを動かすたびに、その位置の値に変わります。ディスクのセクタやレコードを順に見ていくときに便利です。

追従にするときは、**型 (追従)** にテンプレートの中の型の名前を入れます。コマンドパレットの **テンプレート: カーソル位置で型を表示** からも始められます。追従の結果は、Hex 列で色分けせずに枠線だけで示します。追従の適用ノードを右クリックして **固定に変換** を選ぶと、そのときの位置で固定の適用になります。

### 複数の適用と解除 {#multiple-applications}

1 つのドキュメントに、最大 32 個まで適用できます。たとえば先頭に PE、0x4000 に別の構造体、というように重ねられます。適用ごとに、ツリーの最上位に 1 つのノードが並びます。

適用をやめるには、そのノードを右クリックして **適用を解除** を選びます。ツリーと色分けが消えます。

適用の一覧は、ドキュメントと一緒に記憶されます。ドキュメントを開き直すと、同じ適用が自動で戻ります。

## 結果のツリー {#result-tree}

**構造体** パネルに、評価の結果が表になって出ます。

- 列は **名前**、**値**、**型**、**オフセット**、**サイズ**、**コメント** です。**表示する列** のボタンで、エンディアン、終わり、色の列も出せます。列の順序も変えられます。
- 構造体、配列、ポインタは開閉できます。子は開いたときに初めて読むので、巨大な構造体でも固まりません。要素が 1,000 を超える配列は、1,000 要素ずつのグループに分かれます。
- 上の絞り込み欄に入力すると、名前、値、型で絞り込めます。まだ読んでいない部分も含めて探すには **すべて評価して検索** を選びます。
- 下の **パス** の欄には、選んだノードのパス (例: `chunks[3].header.width`) が出ます。パスを入力して、そのノードへ移動することもできます。
- 下部には、評価したパターンの数と、エラー・警告の件数が出ます。件数を選ぶと、[テンプレートの出力パネル](#template-output)が開きます。

キーボードでは、<kbd>↑</kbd> と <kbd>↓</kbd> で移動し、<kbd>→</kbd> と <kbd>←</kbd> で開閉します。<kbd>Enter</kbd> を押すと、Hex 列でそのノードの範囲が選択されます。

### Hex 列との連動 {#hex-link}

- ノードを選ぶと、Hex 列でその範囲が選択され、必要ならスクロールします。
- Hex 列でカーソルを動かすと、カーソルを含む一番内側のノードがツリーで選ばれます。**カーソルに追従** のボタンで、この連動を切り替えられます。
- Hex 列のバイトにマウスを置くと、パス、型、値がツールチップで出ます。

### 色分け {#coloring}

各パターンの範囲は、Hex 列で色分けされます。隣り合う部分は違う色になります。**表示 > 構造体の色分け** で、色分けの表示を切り替えられます。コマンドパレットの **テンプレート: 色分けの表示切り替え** でも切り替えられます。濃さは、**設定 > テンプレート** の **色分けの不透明度 (%)** で変えます。

ハイコントラストのテーマでは、塗りつぶしの代わりに、パターンの境目に線を引きます。

### ノードの右クリックメニュー {#node-menu}

ノードを右クリックすると、次の操作ができます。

- **データへ移動**: Hex 列で範囲を選択します。
- **指す先へ移動**: ポインタのノードで、指している場所へ移動します。<kbd>Alt</kbd>+<kbd>←</kbd> で戻れます。
- **定義へ移動**: テンプレートエディタで、そのパターンを宣言した行を開きます。<kbd>F12</kbd> でも開けます。
- **値をコピー**、**名前と値をコピー**、**パスをコピー**、**バイト列をコピー**、**オフセットをコピー**
- **部分木を JSON でコピー**: ノードより下をまとめて JSON でコピーします。64 MB を超えるときは、ファイルへの保存をすすめます。
- **ブックマークに追加**: 範囲を、名前とパスをコメントにしたブックマークにします。[ブックマーク](bookmarks.md)を参照してください。
- **選択範囲をマルチ選択に追加**: 選んだ複数のノードの範囲を、まとめて選択します。
- **セクションを新しいタブで開く**: セクションのノードで、展開後のデータを読み取り専用のタブで開きます。[セクション](#sections)を参照してください。

複数のノードを選ぶと、コピーの項目は選んだノードすべてを改行でつないでコピーします。

## ツリーから値を書き換える {#edit-from-the-tree}

ツリーの値をダブルクリックするか、右クリックして **値を編集** を選ぶと、バイト列を書き換えられます。コマンドパレットの **テンプレート: 値を編集** でも始められます。

型に合わせた入力欄が出ます。

| 型 | 入力欄 |
| --- | --- |
| 整数 | 数値 (`0x1F` のような 16 進も使えます) |
| 浮動小数点 | 数値、`NaN`、`Inf`、`-Inf` |
| 列挙型 | 名前の一覧。**数値で入力** も選べます |
| フラグ | チェックボックスの一覧 |
| 真偽値 | チェックボックス |
| 文字列 | テキスト。短いときは **残りを 0 で埋める** かどうかを選べます |
| 日時 | 日付と時刻。**UTC** か **地域の時刻** を選びます |
| 色 | 色の選択、または `#RRGGBB` |

<kbd>Enter</kbd> で確定し、<kbd>Esc</kbd> で取り消します。値が不正なときは、入力欄が赤くなり、理由が出ます。

書き換えは、そのパターンの範囲だけを上書きします。挿入モードでも、サイズは変わりません。書き換えは 1 回の [元に戻す](editing.md#undo-redo)の単位になります。

次のノードは編集できません。理由はツールチップに出ます。

- 読み取り専用のドキュメントのノード
- `readonly` の付いたパターン
- セクションの中のパターン
- 計算した値とエラーのノード

## テンプレートの自動適用 {#auto-apply}

ファイルを開くと、HexEditor は先頭と末尾を調べて、合うテンプレートを探します。マジックナンバー、MIME タイプ、拡張子で判断します。拡張子だけが合う場合は、候補にはなりますが、自動では適用しません。

**設定 > テンプレート** の **自動適用** で、合うテンプレートが見つかったときの動作を選びます。

- **提案する** (既定): エディタの上に、「このファイルは PNG 画像のようです。テンプレート "PNG image" を適用しますか?」と出ます。**適用**、**ほかの候補...**、**この形式では今後表示しない** のボタンがあります。編集は続けられます。
- **常に適用する**: 一番合うテンプレートを自動で適用します。
- **何もしない**。

**この形式では今後表示しない** を選ぶと、その形式の提案が出なくなります。元に戻すには、**設定 > テンプレート** の **テンプレートごとの設定** で、**今後表示しない提案** の **元に戻す** を選びます。

ドキュメントに適用の記録がすでにあるときは、提案しません。

手動で探すには、**解析 > 構造体テンプレート > 合うテンプレートを探す** を選びます。**合うテンプレート** の一覧に、合った条件 (マジック、MIME、拡張子) と点数が出ます。選んで適用できます。

ドキュメントを編集したあとは、最後の編集から 0.5 秒待って、結果を自動で評価し直します。開閉の状態と選択は、パスで復元されます。**設定 > テンプレート** の **編集後に自動で再評価** を切ると、自動では評価し直さなくなります。そのときは、**解析 > 構造体テンプレート > 再実行** を使います。

## 標準テンプレート {#standard-templates}

よく使う形式のテンプレートが、アプリに含まれています。**テンプレートを適用** の一覧で、**標準** のものです。

| 分類 | 形式の例 |
| --- | --- |
| 実行形式 | PE、ELF、Mach-O、Java クラス、DEX、WebAssembly |
| 画像 | PNG、JPEG、GIF、BMP、ICO、TIFF、WebP、TGA |
| 音声・動画 | WAV、AVI、MP3、FLAC、Ogg、MIDI、MP4、MKV |
| アーカイブ | ZIP、GZIP、TAR、7z、RAR、XZ、CAB |
| 文書 | PDF、OLE 複合文書、RTF |
| ディスクとファイルシステム | MBR、GPT、FAT、exFAT、NTFS、ISO 9660、VHD、VHDX、ext |
| そのほか | SQLite、LNK、レジストリハイブ、PCAP、TrueType、DER |

標準テンプレートは読み取り専用です。直接は保存できません。変えたいときは、テンプレートエディタで **複製して編集** を選ぶと、自分のフォルダに複製ができます。

## Kaitai Struct のファイル {#kaitai}

HexEditor は、Kaitai Struct の定義ファイル (`.ksy`) をそのまま実行できます。外部のコンパイラは要りません。結果は、通常のテンプレートと同じツリーに出ます。

1. **解析 > 構造体テンプレート > Kaitai Struct を適用** を選びます。
2. `.ksy` のファイルを選んで、**適用** を選びます。

テンプレートの一覧で `.ksy` を選んでも、同じように適用できます。

`.ksy` を HexEditor のテンプレート (`.hxt`) に変換して、手で編集を続けることもできます。**解析 > 構造体テンプレート > .ksy を HXT に変換** を選びます。変換できない部分は、コメントで印が付きます。

対応していない機能 (例: `opaque-types`) を使う型は、その型だけがエラーになります。ほかの部分は読めます。

## テンプレートエディタでテンプレートを書く {#template-editor}

自分のテンプレートは、`.hxt` のテキストファイルです。テンプレートエディタで書きます。

### 作る・開く {#create-and-open}

- 新しく作る: **解析 > 構造体テンプレート > 新しいテンプレート**。ひな形が入った状態で開きます。
- 既存のものを開く: **解析 > 構造体テンプレート > テンプレートを開く**。
- 適用中のテンプレートを直す: **解析 > 構造体テンプレート > テンプレートを編集**。

エディタは、ドキュメントと同じ並びのタブとして開きます。`.hxt` のファイルを開いたときも、テンプレートエディタで開きます。

### 例 {#example}

次のテンプレートは、先頭の 4 バイトのマジックと、2 つの数値でできた簡単な形式を読みます。

```text
#pragma name "My format"
#pragma magic 0 "4D 59 46 4D"
#pragma extensions "myf"

struct Header {
    char magic[4];
    u16  version;
    u16  count;
};

struct Item {
    u32 id;
    u32 size;
};

Header header;
Item   items[header.count];
```

`#pragma magic` と `#pragma extensions` は、[自動適用](#auto-apply)の条件になります。ファイルの先頭から、上から順にパターンを読みます。

### エディタの機能 {#editor-features}

- 構文の色分け。テーマに合わせた色になります。
- 入力中の構文チェック。エラーの行には波線が引かれ、下の **問題** にも出ます。
- 補完。予約語、型、属性、標準ライブラリの関数、宣言済みのメンバー (`header.` と入力すると `header` の中身) が候補に出ます。<kbd>Ctrl</kbd>+<kbd>Space</kbd> で出すこともできます。
- 行へ移動 (<kbd>Ctrl</kbd>+<kbd>G</kbd>)。
- 折りたたみ、括弧の対応の表示、コメントの切り替え (<kbd>Ctrl</kbd>+<kbd>/</kbd>)、書式の整形 (<kbd>Shift</kbd>+<kbd>Alt</kbd>+<kbd>F</kbd>)。
- 定義へ移動 (<kbd>F12</kbd>)。型の名前の上で押すと、その型を定義した行を開きます。
- 保存 (<kbd>Ctrl</kbd>+<kbd>S</kbd>)。保存すると、そのテンプレートを使っている適用が自動で評価し直されます。外部のエディタで保存したときも同じです。

WebView2 ランタイムが入っていない PC では、色分けや補完のない基本のエディタで開き、上のバーで知らせます。テンプレートの編集と保存はできます。

### 保存せずに試す {#try-run}

ツールバーの **試しに実行** を選ぶと、保存せずにテンプレートを **対象のドキュメント** に適用します。ツリーには **(未保存)** と出ます。**対象のドキュメント** は、ツールバーで選べます。

### テンプレートの出力パネル {#template-output}

構文エラー、評価中のエラー、警告、`print` の出力は、**テンプレートの出力** パネルに時刻順に出ます。パネルは **表示 > パネルの表示切り替え > テンプレートの出力** で開きます。

- エラーには `HXT1004` のようなコードが付きます。エラーの行で **HXT1004 のヘルプ** のような項目を選ぶと、[テンプレートのエラーコード](template-error-codes.md)の説明を開けます。
- 行をダブルクリックすると、**ソースへ** (テンプレートの該当行) か **データへ** (ドキュメントの該当位置) を選んで移動できます。
- 途中でエラーが起きても、それまでに読めた部分は結果のツリーに残ります。エラーのノードには、アイコンと「エラー」の文字が付きます。

## テンプレートデバッガ {#template-debugger}

テンプレートが思ったとおりに読めないときは、評価を途中で止めて、1 文ずつ実行できます。

1. テンプレートエディタで、止めたい行の左の余白をクリックするか、<kbd>F9</kbd> を押して、ブレークポイントを置きます。
2. <kbd>F5</kbd> を押すか、ツールバーの **デバッグ開始 / 続行** を選びます。
3. ブレークポイントで止まります。

止まっている間は、現在の行が強調され、次のものが見られます。

- **変数**: ローカル変数と、読んでいる構造体のパターン
- **ウォッチ**: 自分で追加した式の値 (**ウォッチ式を追加**)
- **呼び出し履歴**
- **ブレークポイント**
- そこまでの結果のツリー
- Hex 列の `$` の印 (現在の読み込み位置)

| 操作 | キー |
| --- | --- |
| 開始 / 続行 | <kbd>F5</kbd> |
| 停止 | <kbd>Shift</kbd>+<kbd>F5</kbd> |
| ブレークポイントの設定 / 解除 | <kbd>F9</kbd> |
| ステップオーバー | <kbd>F10</kbd> |
| ステップイン | <kbd>F11</kbd> |
| ステップアウト | <kbd>Shift</kbd>+<kbd>F11</kbd> |

これらのキーは、テンプレートエディタにフォーカスがあるときに使えます。<kbd>F11</kbd> は、全画面表示ではなくステップインになります。ツールバーやコマンドパレットからも実行できます。

ブレークポイントには、条件 (例: `$ >= 0x1000`) やヒット回数を付けられます。結果のツリーか Hex 列を右クリックして **ここを読むときに止める** を選ぶと、そのオフセットを読む文で止まります。

デバッグ中は、評価の順序を分かりやすくするため、遅延評価をしません (**デバッグ中は遅延評価しない**)。巨大な配列があると、時間がかかることがあります。

デバッグ中は、対象のドキュメントが読み取り専用になります。デバッグを終えると、編集できるように戻ります。構文エラーがあるときは、先に直すよう求められます。

## セクション (仮想バッファ) {#sections}

ファイルの中に圧縮されたデータがあるとき、展開したあとのデータにもパターンを置けます。展開後のデータを置く場所が **セクション** です。

セクションは、結果のツリーでは **セクション: 名前** の見出しの下に出ます。セクションのノードを右クリックして **セクションを新しいタブで開く** を選ぶと、展開後のデータを読み取り専用のタブで見られます。

- セクションの中のパターンは、編集できません。
- 展開後のサイズには上限があります。上限に達すると、展開を打ち切って警告を出します。
- 展開は、中のパターンが必要になったときに行います。

テンプレートの中でセクションを作る方法は、[テンプレートの標準ライブラリ](template-library.md)の `std::section` と `std::compress` を参照してください。

## 結果のエクスポート {#export-results}

結果のツリーを JSON か CSV で保存できます。

1. 構造体パネルのツールバーで **エクスポート** を選びます。**解析 > 構造体テンプレート > 結果をエクスポート** でも開けます。
2. **形式**、**対象** (適用の全体、または選んだノードの部分木) を選びます。
3. 必要なら **配列の要素の最大数**、**階層の最大の深さ**、**hidden のパターンを含める**、**オフセットを 16 進の文字列で書く** を設定します。
4. **保存** を選びます。

CSV は UTF-8 (BOM 付き) で書くので、Excel で開いても文字化けしません。巨大な配列を含む結果でも、少しずつ書き出すので、メモリは増え続けません。書き出しは、処理センターからキャンセルできます。キャンセルすると、書きかけのファイルは消えます。

同じ内容をコマンドラインから出すには、[テンプレートと JSON の出力](command-line.md#templates-and-json)を参照してください。

## テンプレートの管理 {#manage-templates}

**解析 > 構造体テンプレート > テンプレートの管理** (コマンドパレットの **テンプレート: 管理**、または **設定 > テンプレート**) で、テンプレートを管理します。

- 一覧には、テンプレートの名前、出所 (標準 / 利用者)、自動適用の条件が出ます。**名前で絞り込む** の欄で探せます。
- **有効** と **自動適用** のスイッチで、テンプレートごとに、一覧と自動適用に出すかどうかを選べます。
- 同じ名前のテンプレートが複数あるときは、先に見つかったものが使われ、もう一方には「ほかのテンプレートに隠れています。」と出ます。
- **フォルダを追加** で、テンプレートを探すフォルダを足せます (例: チームで共有するフォルダ)。フォルダの中の変更は、再起動しなくても一覧に反映されます。
- **インポート** は、`.hxt`、`.ksy`、またはそれらを含む `.zip` を、自分のフォルダに取り込みます。
- **エクスポート** は、選んだテンプレートと、それが読み込むファイルを `.zip` にまとめます。標準テンプレートはエクスポートできません。複製してからエクスポートしてください。
- **新しいテンプレート** と **編集** で、テンプレートエディタが開きます。

### インスペクタで使う {#inspector-templates}

テンプレートの型に `[[inspector("表示名")]]` を付けると、その型をデータインスペクタに出せます。テンプレートの管理で **インスペクタ用テンプレートを追加** を選んで登録します。インスペクタの行は、カーソルの位置の値に合わせて変わります。使い方は、[データインスペクタ](inspector.md#user-types)を参照してください。4 KB 以下の固定長の型を使ってください。可変長の型を登録すると警告が出ます。

## ビジュアライザ {#visualizers}

ビジュアライザは、パターンのデータを Hex 以外の形 (画像、音声、逆アセンブル、表、グラフ、色、テキスト) で表示します。テンプレートのパターンに `visualize` 属性を付けます。

| 書き方 | 表示するもの |
| --- | --- |
| `visualize("bitmap", 幅, 高さ, "形式")` | 生の画素。形式は `gray8`、`rgb8`、`rgba8`、`bgra8`、`rgb565`、`indexed8`。`indexed8` は、次の引数にパレットのパターンを渡します (RGB。BMP のパレットなら続けて `"bgra8"`)。行は上から下の順に、詰め物なしで並べます。 |
| `visualize("image")` | 画像ファイル: PNG、JPEG、GIF、BMP、ICO、TIFF、WebP |
| `visualize("audio", サンプルレート, チャンネル数, "形式")` | 音声。形式は `pcm_u8`、`pcm_s16le`、`pcm_s16be`、`pcm_s24le`、`pcm_f32le` |
| `visualize("disasm", "アーキテクチャ", ベースアドレス)` | 逆アセンブル (逆アセンブルビューと同じエンジン。例: `"x86-64"`) |
| `visualize("table")` | 構造体の配列を、メンバーごとの列の表で |
| `visualize("chart", "line")` または `visualize("chart", "bar")` | 数値の配列をグラフで |
| `visualize("color")` | 色の値の大きな色見本 |
| `visualize("text", "文字コード")` | 文字コードで読んだテキストの全文 |

例:

```text
struct Rec { u8 tag[16]; le u32 no; u8 rest[44]; };
Rec recs[16] [[visualize("table")]];
```

ビジュアライザを見るには:

1. 結果のツリーで、ビジュアライザのあるノードを選びます。そのノードには絵のボタンが出ます。
2. ボタンを選ぶか、ノードの右クリックメニューの **ビジュアライザで表示** を選びます。
3. 右に **ビジュアライザ** パネルが開きます。パネルを開いている間は、ビジュアライザのあるほかのノードを選ぶと、すぐにそれを表示します。

パネルの上部に、種類と大きさが出ます。音声は **再生**・**停止** と再生位置のバーで操作し、その下に波形が出ます。**保存** で、画像は PNG、音声は WAV、表は CSV に保存します。

ビジュアライザで表示するデータは 64 MB まで、画像は 16,384 × 16,384 ピクセルまでです。超える場合は先頭だけを表示し、その旨を表示します。画像をデコードできないときは、パネルに「この画像を表示できません」と理由が出ます。HexEditor はそのまま使えます。

## レコードからテンプレートを推定する {#infer-a-template}

データに合うテンプレートがなくても、固定長のレコードが並んでいるなら、レコードの部分を選択して右クリックし、**選択範囲からテンプレートを推定...** を選びます。HexEditor がレコード長とフィールドの型を推定し、すぐに適用したりテンプレートエディタで開いたりできる下書きを作ります。[テンプレートの推定](template-inference.md) を見てください。

## オンラインのテンプレート {#online-templates}

インターネット上のリポジトリから、ほかの形式のテンプレートを探してインストールし、最新に保てます。

1. **解析 > 構造体テンプレート > オンラインのテンプレートを探す** (コマンドパレットの **テンプレート: オンラインで探す**) を選びます。テンプレートの管理の **オンラインのテンプレート** が開きます。
2. **オンラインのテンプレートを検索** に入力するか、**分類** を選びます。
3. 項目ごとに、名前、版、ライセンス、作者、説明が出ます。インストールする前に **ソースを表示** でテンプレートを読めます。
4. **インストール** を選びます。テンプレートはすぐに使えます。テンプレートの一覧に出所「オンライン」で出て、自動適用にも使われます。

インストールしたテンプレートは、設定フォルダの `templates-online` フォルダに、自分のテンプレートとは分けて置かれます。**更新** で新しい版をインストールし、**削除** で削除します。

- **追加したリポジトリ**: リポジトリの索引 (`index.json`) の HTTPS のアドレスを入力して **リポジトリを追加** を選びます。署名のないリポジトリのテンプレートには「署名なし」と出ます。
- 公式のリポジトリは署名されています。署名を確認できない場合、その一覧は使いません。ダウンロードしたファイルは、索引のチェックサムと一致したときだけインストールします。一致しないときは「ファイルが改ざんされている可能性があります」と出て、何もインストールしません。
- スクリプトの機能を使うテンプレートは、インストールの前に確認が出ます。ダウンロードしたテンプレートも、ほかのテンプレートと同じ安全な環境で動きます。
- **起動時にオンラインのテンプレートの更新を確認する** (**設定 > テンプレート**) は 1 日に 1 回確認します。新しい版があると InfoBar で知らせるので、**更新** を選んでインストールします。**オンラインのテンプレートを自動で更新する** をオンにすると、確認せずに新しい版をインストールします。
- HexEditor が送るのは、索引とテンプレートのファイルの要求だけです。開いているファイルの名前や内容は送りません。
- 接続には Windows のプロキシの設定を使います。ダウンロードを一切させないときは、**設定 > プライバシー** でダウンロードをオフにするか、オフラインモードにします。そのときオンラインのページには「オンラインのテンプレートは無効になっています」と **設定を開く** が出て、HexEditor は接続しません。インストール済みのテンプレートはそのまま使えます。
