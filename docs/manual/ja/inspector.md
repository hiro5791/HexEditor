# データインスペクタ

データインスペクタは、カーソル位置のバイトを整数、小数、文字、日時などとして読み取って一覧にするパネルです。値をその場で書き換えることもできます。ファイルの形式が分からないときや、数値を確かめたいときに使います。

## インスペクタを表示する {#show-the-inspector}

次のどれかでパネルを開き閉じします。

- <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>I</kbd> を押す。
- **表示 > パネルの表示切り替え > データインスペクタ** を選ぶ。
- コマンドパレットで **表示: データインスペクタの表示切り替え** を実行する。

インスペクタは、カーソル位置のバイトから読みます。選択範囲があるときは、選択範囲の先頭から読みます。選択範囲があってもカーソル位置から読みたいときは、設定の **インスペクタ: 選択範囲があってもカーソル位置を使う** をオンにします。

パネルの上に、読み始める位置が `0x00001F00 から` のように出ます。カーソルを動かすと、すぐに表示が変わります。

読む位置からファイルの末尾までのバイト数が型のサイズより少ないときは、値の欄に「—」と出ます。マウスを重ねると「データが足りません (4 バイト必要、残り 2 バイト)」のように理由が出ます。

行にマウスを重ねるか、行を選ぶと、その行が読んでいるバイトが Hex 列とテキスト列で強調されます。選択範囲は変わりません。強調したくないときは、設定の **インスペクタの対象を強調する** をオフにします。

行は種類ごとのグループ (**整数**、**浮動小数点**、**可変長整数**、**文字・文字列**、**日時**、**その他**、**ユーザー定義**) に分かれています。グループの見出しを選ぶと、折りたためます。パネルを閉じている間は、何も計算しません。

行を右クリックすると、次のメニューが出ます。

- **値をコピー**
- **すべての行をコピー** (タブ区切りのテキスト)
- **値を編集**
- **ポインタとして移動**
- **この型で配列として移動**
- **この行を非表示**

## 値の型 {#types}

初めて開いたときに出る行は、次のとおりです。

| グループ | 行 |
| --- | --- |
| 整数 | int8、uint8、int16、uint16、int32、uint32、int64、uint64 |
| 浮動小数点 | float、double |
| 文字・文字列 | ANSI、UTF-8、UTF-16 |
| 日時 | Unix 時刻 (32 bit)、FILETIME、DOS 日時 |
| その他 | 2 進 (8 bit)、GUID (Windows) |

そのほかの型は、最初は非表示です。[行の表示・非表示と並べ替え](#customize)で表示できます。

- 整数: int24 / uint24、int48 / uint48、int128 / uint128。
- 浮動小数点: half、bfloat16、long double (80 bit)、Real48、固定小数点 (ビット数を指定)。
- 可変長整数: ULEB128、SLEB128、SQLite varint。
- 文字列: NUL 終端 (ANSI / UTF-8 / UTF-16)、Pascal 形式 (長さが 1 / 2 / 4 バイトのもの)。
- 日時: DOS 日付、DOS 時刻、Unix 時刻 (32 bit 符号なし / 64 bit / ミリ秒)、OLE オートメーション日付、HFS+ 日時、APFS 日時、Mac 絶対時刻 (Cocoa)、SQL Server の datetime / smalldatetime、.NET DateTime、10 進の数字の日時。
- その他: 2 進 (16 / 32 / 64 bit)、UUID (RFC 9562)、色 (RGBA8、BGRA8、RGB8、RGB565)、機械語の 1 命令を逆アセンブルする **1 命令の逆アセンブル** (`mov rbp, rsp (3 バイト)` など)。

**1 命令の逆アセンブル** の行は、最初は x86 64 bit で解釈します。ほかのアーキテクチャにするには、行の設定でこの行を選び、**アーキテクチャ** で選びます。構文と数値の書式は [逆アセンブルの表示オプション](disassembly.md#display-options) に従います。強調するのは命令の長さのバイトで、命令として解釈できないときは **不正な命令** と表示します。この行からは書き換えられません。分岐命令では、行を右クリックして **分岐先へ移動** を選ぶと分岐先へ移動します。<kbd>Alt</kbd>+<kbd>←</kbd> で戻れます。

読み取れないバイトは、行に **不正** と理由 (例: 「継続バイト」「途中で終わる並び」) が出ます。UTF-8 や UTF-16 の文字列は、最初の 4 KB までを読みます。

日時は、ローカル時刻か UTC で表示します。パネルの **日時を UTC で表示** で切り替えます。書式は、設定の **インスペクタ: 日時の書式** で **地域設定に従う** か **ISO 8601** を選びます。

## エンディアン {#endianness}

2 バイト以上の型は、バイトの並び順 (エンディアン) で値が変わります。たとえば `01 02 03 04` は、リトルエンディアンでは uint32 の 67,305,985、ビッグエンディアンでは 16,909,060 になります。

パネルの **エンディアン** で選びます。

- **ドキュメントに従う** (既定): ドキュメントのエンディアンを使います。
- **リトルエンディアン**
- **ビッグエンディアン**

リトルエンディアンかビッグエンディアンを選ぶと、インスペクタの中だけで固定します。ステータスバーと Hex ビューのエンディアンは変わりません。この選択は、ドキュメントごとに覚えます。

コマンドパレットの **インスペクタ: エンディアンの切り替え** で、反対のエンディアンに切り替えることもできます。

エンディアンに従わない型があります。SQLite varint は常にビッグエンディアンです。GUID (Windows) の先頭の 3 つのフィールドは常にリトルエンディアンです。これらの行には「(固定)」と付きます。

表示の形式も選べます。

- **整数の表示形式**: **10 進** (既定)、**16 進** (`0x0000002A` のように桁を 0 で埋める)、**8 進**。10 進には、地域設定の桁区切りが付きます。設定の **インスペクタ: 桁区切り** でオフにできます。
- **浮動小数点の表示形式**: **最短で正確** (既定)、**指数表記**、**Hex 浮動小数点** (`0x1.8p+1`)。

## インスペクタから値を書き換える {#edit-values}

1. 書き換えたい位置にカーソルを置きます。
2. インスペクタの行を選び、<kbd>Enter</kbd> を押します。値の欄をダブルクリックしてもかまいません。右クリックして **値を編集** を選ぶこともできます。
3. 新しい値を入力します。入力欄の横に、書き込まれるバイト列が Hex で出ます。
4. <kbd>Enter</kbd> を押して確定します。やめるときは <kbd>Esc</kbd> を押します。

整数の欄には、数だけでなく `0x100*4` のような式も入力できます。浮動小数点は `1.5`、`1e-3`、`inf`、`nan`、`0x1.8p+1` の形で入力します。日時は `2026-10-07 12:34:56` の形です。GUID は 16 進数字 32 桁、色は `#FF8000` のような形です。

書き換えについて、覚えておくことがあります。

- 書き換えは、挿入モードでも必ず上書きです。型のサイズ分のバイトを置き換え、ファイルの長さは変わりません。
- 書き込みがドキュメントの末尾を超えるときは、確定できません。入力欄の下に理由が出ます。
- 範囲外の値や、正しくない書き方の入力も、確定できません。理由が入力欄の下に出ます。
- 可変長整数と文字列は、バイト数が変わる書き換えはできません。元の長さに収まる値だけを書けます。
- 1 回の書き換えは、<kbd>Ctrl</kbd>+<kbd>Z</kbd> 1 回で元に戻ります。
- 書き換えのあとも、カーソルは動きません。
- 読み取り専用のドキュメントでは、書き換えられません。

## 行の表示・非表示と並べ替え {#customize}

見たい行だけを出して、順番を変えられます。

1. パネルの **行の設定** を選びます。
2. 表示する行にチェックを付けます。
3. 順番を変えるには、行を選んで **上へ** か **下へ** を押します。**行の設定** の一覧では、行をドラッグしても動かせます。

行の右クリックメニューの **この行を非表示** でも、行を隠せます。

型ごとのオプションもあります。

- **反対のエンディアンでも表示**: オンにすると、`int32 (BE)` のように、反対のエンディアンの行が加わります。
- **固定小数点の行を加える**: 全体のビット数と小数部のビット数、符号の有無を指定して **加える** を押します。**行を外す** で消せます。
- 日時の書式の選択。

行の組み合わせは、プリセットとして選べます。

| プリセット | 内容 |
| --- | --- |
| **基本** | 初めに出る行 |
| **すべて** | すべての型 |
| **日時** | 日時の型 |
| **組み込み向け** | 整数、固定小数点、half、2 進 |

**既定に戻す** で **基本** に戻ります。自分の組み合わせは、プリセットの名前を入力して **プリセットとして保存** で残せます。行の構成は、アプリ全体で共通です。ドキュメントごとには変わりません。

## ユーザー定義型 {#user-types}

自分で定義した型を、インスペクタの **ユーザー定義** グループに加えられます。構造体のようなまとまりは、展開できる行で表示します。

定義の方法は 2 つあります。

- [テンプレート](templates.md)で型を定義し、インスペクタに表示する指定を付ける。定義のファイルは、設定フォルダの `inspector` フォルダに置きます。設定の **インスペクタ用テンプレート** に登録したテンプレートも使えます。
- [プラグイン](plugins.md)で型を加える。プラグインを有効にしたときだけ、行が出ます。

ユーザー定義型には、次の決まりがあります。

- 読むのは、位置から最大 4 KB です。
- 1 つの型の解釈に使える時間には上限があります (既定は 50 ミリ秒)。超えると、その行に **時間切れ** と出ます。位置が変わると、もう一度試します。
- ある型でエラーが出ても、ほかの行は影響を受けません。その行に「エラー: ...」と出ます。
- 定義のファイルを保存し直すと、アプリを再起動しなくても行が更新されます。
- 書き換えられるのは、文字列からバイト列への変換が定義された型だけです。

## ポインタと配列をたどる {#pointers}

### ポインタとして移動 {#follow-pointer}

ファイルの中には、別の位置を指す数値があります。整数の行の値を位置とみなして、その場所へ移動できます。

1. 位置を指す数値の上にカーソルを置きます。
2. インスペクタで、その整数の行を右クリックします。
3. **ポインタとして移動** を選び、数値の意味を選びます。

| 選ぶ項目 | 移動先 |
| --- | --- |
| **絶対 (オフセット)** | 値そのものがオフセット |
| **絶対 (アドレス)** | 値は表示上のアドレス。ベースアドレスを引いたオフセットに移動 |
| **カーソルからの相対** | 読み始めた位置 + 値 |
| **値の直後からの相対** | 読み始めた位置 + 型のサイズ + 値 |
| **基準を指定して相対...** | 入力した基準 + 値。基準は `0x400000` や `bm.header` のような式で入力し、**移動** を押す |

符号つきの整数で負の値のときは、後ろ向きの移動になります。移動先がドキュメントの外のときは、移動せずに知らせます。移動はジャンプ履歴に残るので、<kbd>Alt</kbd>+<kbd>←</kbd> で元の位置に戻れます。

コマンドパレットの **インスペクタ: ポインタとして移動** からも実行できます。

### 配列として移動 {#follow-array}

同じ大きさのデータが並んでいる場所では、要素ごとにカーソルを動かせます。

1. 要素の型の行を右クリックして、**この型で配列として移動** を選びます。
2. パネルに配列モードの操作が出ます。**前の要素** と **次の要素** で、1 要素ずつ動きます。
3. **要素番号** に番号を入力すると、その要素に移動します。負の番号も使えます。
4. 要素の大きさが型のサイズと違うときは、**要素のサイズ** に `0x28` のような式を入力します。
5. 終わるときは、**配列モードを終了** を選ぶか、パネルで <kbd>Esc</kbd> を押します。

配列モードに入った位置が要素 0 です。要素の境界にいないときは、「(要素の境界ではありません)」と出ます。配列モードの間の移動は、ジャンプ履歴に残りません。
