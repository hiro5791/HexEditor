## INSP-01 データインスペクタのパネル

### TC-INSP-01-01 Ctrl+Shift+I でのパネルの表示切り替え

| 項目 | 内容 |
| --- | --- |
| 確認する基準 | INSP-01 の受け入れ基準 1 |
| 種別 | 自動: UI |
| 優先度 | 高 |
| フェーズ | 1 |
| テストデータ | TD-INSP-VALUES |
| 環境 | 標準 |

**前提**: 新しい設定フォルダで HexEditor を起動し、TD-INSP-VALUES を開いている。データインスペクタは非表示。

**手順**:

1. Ctrl+Shift+I を押し、データインスペクタのパネルを AutomationId で探して有無を読む。
2. パネルの上部の起点の表示と、int32 の行の値を読む。
3. Ctrl+Shift+I をもう一度押し、パネルの有無を読む。
4. コマンドパレットで「データインスペクタの表示切り替え」を実行し、パネルの有無を読む。

**期待結果**:

- 手順 1: パネルが表示される (既定は右パネル)。
- 手順 2: 起点が「0x00000000 から」を示し、int32 の行が `12,345`。
- 手順 3: パネルが非表示になる。手順 4: 再び表示される。

### TC-INSP-01-02 カーソル移動から全行の更新までの時間

| 項目 | 内容 |
| --- | --- |
| 確認する基準 | INSP-01 の受け入れ基準 2 |
| 種別 | 自動: 性能 |
| 優先度 | 中 |
| フェーズ | 1 |
| テストデータ | TD-RANDOM-16M |
| 環境 | 性能テスト用の固定の環境 (6.6) |

**前提**: HexEditor を起動して TD-RANDOM-16M を開き、データインスペクタを表示し、行の設定をプリセット「すべて」にしている。

**手順**:

1. → を 100 回、200 ms 間隔で押す。
2. 各キー入力の時刻と、インスペクタのすべての行の値が新しい起点の値になった時刻 (UI オートメーションの値の変更イベント) の差を読む。
3. 各回の表示値を、同じバイト列を解釈部品で直接解釈した値と比べる。

**期待結果**:

- 100 回すべてで差が 50 ms 以内。
- 表示値がすべて一致する。

### TC-INSP-01-05 キーボードでの操作と行の読み上げ用の名前

| 項目 | 内容 |
| --- | --- |
| 確認する基準 | INSP-01 の受け入れ基準 5 |
| 種別 | 自動: アクセシビリティ |
| 優先度 | 中 |
| フェーズ | 1 |
| テストデータ | TD-INSP-VALUES |
| 環境 | 標準 |

**前提**: 新しい設定フォルダで HexEditor を起動し、TD-INSP-VALUES を開き、データインスペクタを表示している。Hex ビューにフォーカスがある。

**手順**:

1. F6 を、フォーカスがインスペクタの一覧に移るまで押す (押した回数を記録する)。
2. ↓ を押して、int32 の行を選ぶ。
3. UI オートメーションで、選ばれた行の `Name` と、フォーカスの変更イベントを読む。
4. ↑ を押し、選ばれた行の `Name` を読む。
5. Shift+F6 を、手順 1 と同じ回数押し、フォーカスのある要素を読む。

**期待結果**:

- 手順 3: 行の `Name` が「int32, 12,345」(型の名前と値の組) で、フォーカスの変更イベントが行に対して出ている。
- 手順 4: 1 つ上の行 (uint16 など) の `Name` が同じ形式。
- 手順 5: フォーカスが Hex ビューに戻る。

## INSP-02 エンディアンと表示形式

### TC-INSP-02-01 LE と BE での uint32 の解釈 (単体)

| 項目 | 内容 |
| --- | --- |
| 確認する基準 | INSP-02 の受け入れ基準 1、4 |
| 種別 | 自動: 単体 |
| 優先度 | 中 |
| フェーズ | 1 |
| テストデータ | なし |
| 環境 | 標準 (カルチャは en-US) |

**前提**: なし。

**手順**:

1. 解釈部品に `01 02 03 04` を渡し、uint32 を LE と BE で 10 進表示させる。
2. `FF FF` を渡し、int16 を 16 進表示させる。
3. `2A 00 00 00` を渡し、int32 を 16 進表示、8 進表示させる。
4. `00 00 00 80` を渡し、int32 を 16 進表示させる。

**期待結果**:

- 手順 1: LE で `67,305,985`、BE で `16,909,060`。
- 手順 2: `0xFFFF`。
- 手順 3: `0x0000002A` と 8 進の `52` (8 進の表記の形は実装で決めた形式)。
- 手順 4: `0x80000000`。

## INSP-05 浮動小数点 (float / double)

### TC-INSP-05-01 float と double の解釈 (単体)

| 項目 | 内容 |

| 環境 | 標準 (カルチャは en-US) |
