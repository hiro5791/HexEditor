## 自動テストが前提とする仕組み

このファイルの自動テストは、00-test-strategy 7.2 の仕組みに加えて、テスト用のビルドに次の仕組みがあることを前提にする (7.2 への追加が必要)。

| 仕組み | 内容 |
| --- | --- |
| 描画モデルの取得 | Hex ビュー (ミニマップ・画像表示パネルを含む) が、表示中の各セルの文字・文字色・背景色・枠・線・模様・下線・層 (VIEW-17 の順位)、各行の先頭オフセット、セルの外接矩形、カーソルの形とニブルを、UI オートメーション経由で返す。表示の正しさは画像ではなくこれで確認する |

| 地域設定・タイムゾーンの上書き | `--test-hooks` で、アプリの地域設定 (CurrentCulture) とタイムゾーンを指定の値にする。表示言語 (`--lang`) とは別に指定できる |

## VIEW-01 Hex ビューコントロール

### TC-VIEW-01-01 100 GB のファイルの先頭・中央・末尾の表示

| 項目 | 内容 |
| --- | --- |
| 確認する基準 | VIEW-01 の受け入れ基準 1 |
| 種別 | 自動: UI |
| 優先度 | 高 |
| フェーズ | 0 |
| テストデータ | TD-SPARSE-100G |
| 環境 | 標準 |

**前提**: 新しい設定フォルダで HexEditor を起動している。表示設定は既定 (1 行 16 バイト)。

**手順**:

1. TD-SPARSE-100G を開く。
2. 描画モデルから 1 行目の先頭オフセットと 16 バイトの値を読む。
3. Ctrl+G で移動バーを開き、`0xC80000000` (50 GiB、ファイルの中央) を入力して Enter を押す。
4. 描画モデルからカーソルのある行の先頭オフセットと値を読む。
5. Ctrl+End を押し、描画モデルから最終行の先頭オフセットと値を読む。

**期待結果**:

- 1 行目の先頭オフセットが 0 で、値が目印 `@0000000000000000` の先頭 16 バイトと一致する。
- 手順 4 の行の先頭オフセットが 0xC80000000 で、値が目印 `@0000000C80000000` の先頭 16 バイトと一致する。
- 最終行の先頭オフセットが (107,374,182,400 − 1) を 16 で切り捨てた倍数の位置で、値がテストデータ生成ツールの規則で求めた末尾の目印のバイトと一致する。
- オフセット列の表示が、各行の先頭オフセットの 16 進表記 (VIEW-19 の書式) と一致する。
