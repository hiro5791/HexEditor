# テストケース: 解析 (比較・統計・ハッシュ・逆アセンブル)

この文書は、機能仕様書 [06-analysis.md](../../spec/06-analysis.md) の受け入れ基準 (142 項目) を確認するテストケースを定める。書式と種別の決め方は [00-test-strategy.md](../00-test-strategy.md) に従う。

- テストケースの数: 146 件 (自動: 単体 36、自動: 結合 36、自動: UI 57、自動: 性能 9、自動: 国際化 1、自動: アクセシビリティ 1、自動: ファジング 1、半自動 2、手動 3)
- 手動・半自動のテストケースの所要時間の合計: 約 17 分 (うちスモーク (優先度「高」) は 3 分)
- ハッシュ・チェックサムは、公開されているテストベクタ (NIST の FIPS の例、RFC の付録、CRC カタログの check 値など) と照合する。出典はテストケースごとに名前で書く。
- 比較 (差分) は、無作為に作ったデータの組について、単純な基準の実装 (バイトごとのループ、完全な LCS) の結果と照合する。
- 逆アセンブルは、既知の命令のエンコード (この文書に書いたバイト列と、Capstone のテストスイート `suite/MC` の期待値) と照合する。
- 自動テストが自分で作る小さなデータ (数十バイトのバイト列など) は、テストデータ ID を付けずに手順の中に値を書く。

## ANA-01 比較の開始と比較対象の指定

### TC-ANA-01-01 開いている 2 つのタブから比較タブを開く

| 項目 | 内容 |
| --- | --- |
| 確認する基準 | ANA-01 の受け入れ基準 1 |
| 種別 | 自動: UI |
| 優先度 | 高 |
| フェーズ | 2 |
| テストデータ | TD-ANA-DIFF3-A、TD-ANA-DIFF3-B |
| 環境 | 標準 |

**前提**: TD-ANA-DIFF3-A と TD-ANA-DIFF3-B をこの順にタブで開いている。

**手順**:

1. 解析 > 比較 > ファイルを比較... を実行する。
2. 左の「対象」で TD-ANA-DIFF3-A のタブを、右の「対象」で TD-ANA-DIFF3-B のタブを選ぶ。
3. 比較方式は既定のまま「比較」を押す。

**期待結果**:

- 新しいタブが開き、タブ名が `TD-ANA-DIFF3-A.bin ↔ TD-ANA-DIFF3-B.bin` になる。
- タブの中に Hex ビューが 2 つ並び、左に A、右に B の内容が表示される。
- 差分の一覧パネルが表示され、差分が 1 件以上ある。

### TC-ANA-02-03 近い差分をまとめる

### TC-ANA-02-04 基準の実装との照合 (無作為なデータ)

| 項目 | 内容 |
| --- | --- |

| フェーズ | 2 |
| テストデータ | なし |
| 環境 | 標準 |

**前提**: なし。

**手順**:

1. FsCheck で、長さ 0〜70,000 バイトの左右のデータ (片方を元に、無作為な位置を無作為な値に変えたもの、長さも変えたもの) と、オプション (近い差分をまとめる 0〜16、比較の単位 1 / 2 / 4 / 8、左右の開始オフセット) を 1,000 組作る。

### TC-ANA-03-03 最小一致長に満たない一致は再同期点にしない

| 項目 | 内容 |
| --- | --- |
| 確認する基準 | ANA-03 の受け入れ基準 4 |
| 種別 | 自動: 単体 |
| 優先度 | 中 |
| フェーズ | 2 |
| テストデータ | なし |
| 環境 | 標準 |

**前提**: なし。

**手順**:

1. 固定の種の乱数で 4,096 バイトの共通部分 C1・C2 と、互いに一致しない 32 バイトの部分 X1・X2・Y1・Y2 を作る。7 バイトの列 S (`11 22 33 44 55 66 77`) を用意する。
2. 左を C1 + X1 + S + X2 + C2、右を C1 + Y1 + S + Y2 + C2 とする。
3. M = 8 で比較する。
4. S を 8 バイト (`11 22 33 44 55 66 77 88`) に変えたデータで、M = 8 で比較する。

**期待結果**:

- 手順 3 では、C1 の後ろから C2 の前まで (X1 + S + X2 と Y1 + S + Y2) が 1 件の「変更」になる。S は一致として切り出されない。
- 手順 4 では、S が「一致」の区間になり、その前後が別々の「変更」2 件になる。

### TC-ANA-03-04 基準の実装との照合 (無作為な編集)

| 項目 | 内容 |
| --- | --- |
| 確認する基準 | ANA-03 の受け入れ基準 1、2 |
| 種別 | 自動: 単体 |
| 優先度 | 中 |
| フェーズ | 2 |
| テストデータ | なし |
| 環境 | 標準 |

**前提**: なし。

**手順**:

1. FsCheck で、長さ 0〜8,192 バイトの左のデータと、それに無作為な挿入・削除・上書きを 0〜20 回加えた右のデータの組を 2,000 組作る。
2. 各組を製品の比較 (W = 64 KB、M = 1) で比べ、結果の区間の列を左に適用して右を作り直す。

**期待結果**:
