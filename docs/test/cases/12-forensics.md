# テストケース: フォレンジック機能

この文書は、機能仕様書 [12-forensics.md](../../spec/12-forensics.md) (FOR) の受け入れ基準を確認するテストケースを定める。書式と用語は [00-test-strategy.md](../00-test-strategy.md) に従う。この領域はすべてフェーズ 5。

- テストケースの数: 合計 123 件 (自動: 単体 21、自動: 結合 46、自動: UI 44、自動: 性能 2、半自動 3、手動 7)
- 手動・半自動の所要時間の合計 (目安): 39 分
- 共通のテストデータは [test-data.md](../test-data.md)、このファイルで新しく定義したテストデータは末尾の「このファイルで使うテストデータ」を参照する。

このファイルの「環境」欄では、標準環境 (00-test-strategy の 5.1) のほかに次の書き方を使う。

| 書き方 | 意味 |
| --- | --- |
| 管理者 (CI) | CI のランナーの管理者権限のまま、アプリを管理者として実行する |
| 一般ユーザー (CI) | CI のランナー上で、昇格していないトークンでアプリを起動する。ランナーの UAC は「確認なしで昇格する」設定にしておき、補助プロセス (ENG-28) の起動は確認なしで通る |
| 仮想ディスク | テストの開始時に VHDX を作成・接続し、終了時に必ず切断・削除する (00-test-strategy の 6.4)。ディスクイメージのテストデータを使う場合は、その内容を書き込んだ VHDX を作って接続する |
| ケースあり | テスト用の一時フォルダに新しいケース (ケース番号 `C-0001`、ケース名 `テストケース`、調査者名 `tester`) を作って開いた状態 |

イメージファイルだけを対象とするテストは、管理者権限なしの標準環境で行う。日時を確認するテストでは、異常を再現する仕組み (00-test-strategy の 7.2) の「時刻の固定」で、現在時刻を 2026-10-07T03:15:42.1234567Z に固定する。

### TC-FOR-01-04 編集中のファイルの保存の禁止と名前を付けて保存

### TC-FOR-01-05 補助プロセスへの直接の書き込み要求の拒否

| 項目 | 内容 |
| --- | --- |
| 確認する基準 | FOR-01 の受け入れ基準 4 |
| 種別 | 自動: 結合 |
| 優先度 | 高 |
| フェーズ | 5 |
| テストデータ | TD-VHDX-MBR |
| 環境 | 管理者 (CI)、仮想ディスク |

**前提**: TD-VHDX-MBR を接続し、ディスク全体の SHA-256 を記録する。テスト用のクライアント (UI のプロセスの代わりにパイプを作り、補助プロセスを起動して接続の手順を行うプログラム) で `HexEditor.Elevated.exe` を起動し、`Hello` の後に `SetWriteBlock` (ENG-28 の仕様 4) で書き込み保護モードが有効であることを補助プロセスに通知する。

**手順**:

1. 読み取りのみの `OpenDevice` で TD-VHDX-MBR の物理ディスクを開き、`ReadSectors` で LBA 0 を読む。
2. 読み書きを指定した `OpenDevice` を送る。
3. 手順 1 のハンドルに対して `WriteSectors` (LBA 100、1 セクタ、`FF` × 512) を送る。
4. `LockVolume`、`DismountVolume` をそのディスクの NTFS のボリュームに対して送る。
5. `GetUsbWriteProtect` を送る。
6. ディスク全体の SHA-256 を計算する。

**期待結果**:

- 手順 1 と 5 が成功する。
- 手順 2〜4 がすべて拒否の応答 (成功以外の状態) になる。
- 手順 6 の SHA-256 が記録した値と一致する。

## FOR-02 OS の USB ストレージ書き込み保護

### TC-FOR-02-01 有効にした後に挿した USB メモリにコピーできない

| 項目 | 内容 |

| 手動にする理由 | 実機・実環境が必要で、CI で再現できない (USB メモリの抜き差し) |
| 所要時間の目安 | 5 分 |

**前提**: USB メモリは PC から抜いておく。手動テスト支援ツールの「準備」で TD-BYTES-256 をデスクトップに置き、HexEditor を管理者として起動する。

- 手順 4 で、エクスプローラーに書き込みが禁止されている趣旨のエラーが出て、コピーできない。

- OS のツール (フォーマット、diskpart、mke2fs など) で作るファイルシステムのイメージは、ファイルの内容と作成の手順は固定するが、ファイルシステムのメタデータ (シリアル番号・日時・GUID の一部) は作るたびに変わりうる。テストの期待値は、イメージ自身または生成時に記録するマニフェスト (全ファイルのパス・サイズ・更新日時・SHA-256 と、断片のディスク上の位置) から求める。Linux のツールで作るものは、生成ツールが WSL 上で作る。
