# テストケース: 自動化 (スクリプト・マクロ・プラグイン・コマンドライン)

機能仕様書 [../../spec/08-automation.md](../../spec/08-automation.md) (AUTO-01〜AUTO-46、受け入れ基準 187 項目) のテストケース。共通の書式と方針は [../00-test-strategy.md](../00-test-strategy.md) に従う。

| 種別 | 件数 |
| --- | --- |
| 自動: 単体 | 1 |
| 自動: 結合 | 59 |
| 自動: UI | 103 |
| 自動: 性能 | 14 |
| 自動: 国際化 | 1 |
| 自動: 配布 | 3 |
| 半自動 | 1 |
| 手動 | 1 |
| 合計 | 183 |

- 手動・半自動の所要時間の合計の目安: 7 分 (優先度「高」の手動・半自動はなし)。
- AUTO-37 の受け入れ基準にないテスト用の起動オプション (`--test-profile`、`--ui-lang`、`--test-hooks`) は、TC-AUTO-37-07〜09 で確認する。GUI の表示言語の指定は AUTO-37 の `--ui-lang` を使う (`hexed` の `--lang` はコンソールのメッセージの言語)。

テストを書くうえでの共通の前提:

- GUI のテストは、テストごとに新しいテスト用の設定フォルダ (`--test-profile`) で起動する。「信頼済み」と書いたスクリプト・プラグインは、その設定フォルダに「常に許可する」の記録を置いて作る。
- ヘッドレスのテスト (`hexed`) は、テストごとに新しく展開したポータブル版で行う。設定と信頼の記録は、そのポータブル版のデータフォルダ (`<exe のフォルダ>\Data\`) に置くため、他のテストと混ざらない。
- 「ファイルが変わらない」は、実行前後の SHA-256 の比較で確認する。

## AUTO-01 スクリプトの実行

### TC-AUTO-01-01 F5 で JavaScript と C# スクリプトを実行する

| 項目 | 内容 |
| --- | --- |
| 確認する基準 | AUTO-01 の受け入れ基準 1 |
| 種別 | 自動: UI |
| 優先度 | 高 |
| フェーズ | 3 |
| テストデータ | TD-AUTO-JS-HELLO、TD-AUTO-CSX-HELLO、TD-SEQ-1M |
| 環境 | 標準。テスト用の設定フォルダに C# スクリプト コンポーネントを展開済み |

**前提**: テスト用の設定フォルダで TD-SEQ-1M を開いて起動している。TD-AUTO-JS-HELLO と TD-AUTO-CSX-HELLO は「常に許可する」の記録を設定フォルダに置いてある (信頼の確認を出さない)。

**手順**:

1. スクリプト一覧パネルを開き、TD-AUTO-JS-HELLO を選んでフォーカスを置く。
2. F5 を押す。
3. 出力パネルの内容を取得する。
4. TD-AUTO-CSX-HELLO を選んで F5 を押す。
5. 出力パネルの内容を取得する。

**期待結果**:

- 手順 3 で、出力パネルに `hello from js` と、実行結果の行 (成功・経過時間) が 1 行出る。
- 手順 5 で、出力パネルに `hello from csx` と、実行結果の行 (成功) が出る。

### TC-AUTO-01-02 実行中の UI の応答と、書き込み中のドキュメントの保護

| 項目 | 内容 |
| --- | --- |
| 確認する基準 | AUTO-01 の受け入れ基準 2、3 |
| 種別 | 自動: UI |
| 優先度 | 中 |
| フェーズ | 3 |
| テストデータ | TD-AUTO-JS-SLOWWRITE、TD-SEQ-1M (2 つのコピー a.bin・b.bin) |
| 環境 | 標準 |

**前提**: a.bin と b.bin を 2 つのタブで開き、a.bin をアクティブにしている。TD-AUTO-JS-SLOWWRITE は信頼済み。

**手順**:

1. TD-AUTO-JS-SLOWWRITE を実行する (a.bin に 1 バイト書いた後、20 秒間 `script.signal` を見ながら計算を続けるスクリプト)。
2. 実行開始から 2 秒後に、a.bin の Hex ビューのオフセット 0x10 で `FF` を入力する。
3. a.bin のエディタ上部の InfoBar を取得する。
4. b.bin のタブに切り替え、オフセット 0x10 で `AA` を入力する。
5. 各操作の応答時間 (キー入力から画面の反映まで) を記録する。
6. 処理センターの停止ボタンでスクリプトを止める。

**期待結果**:

- 手順 2 の入力は受け付けられず、a.bin のオフセット 0x10 の値は変わらない。
- 手順 3 で、InfoBar に「スクリプト「slowwrite」を実行中です」の意味の文言と停止ボタンがある。
- 手順 4 で、b.bin のオフセット 0x10 が `AA` になる。
- 手順 4 のタブの切り替えと入力が、それぞれ 50 ms 以内に画面に反映される (UI が固まらない)。

### TC-AUTO-01-03 1 回の実行による変更を 1 回の Ctrl+Z で戻す

| 項目 | 内容 |
| --- | --- |
| 確認する基準 | AUTO-01 の受け入れ基準 4 |
| 種別 | 自動: UI |
| 優先度 | 中 |
| フェーズ | 3 |
| テストデータ | TD-AUTO-JS-WRITE3、TD-SEQ-1M |
| 環境 | 標準 |

**前提**: TD-SEQ-1M のコピーを開いている。TD-AUTO-JS-WRITE3 は信頼済み。

**手順**:

1. TD-AUTO-JS-WRITE3 を実行し、終了を待つ (オフセット 0x0・0x100・0x1000 に別々の `writeBytes` で `00` を書く)。

**期待結果**:

- 手順 3 の後、Undo の履歴の先頭の名前が「スクリプト: write3」だった単位が取り消され、手順 4 の SHA-256 が TD-SEQ-1M と一致する。

### TC-AUTO-02-03 実行時間の上限での一時停止と「続ける」
