# テストケース: ツール (印刷・インポート / エクスポート・ファイルツール・電卓など)

機能仕様書 [../../spec/11-tools.md](../../spec/11-tools.md) (TOOL-01〜TOOL-28、受け入れ基準 110 項目) のテストケース。共通の書式と方針は [../00-test-strategy.md](../00-test-strategy.md) に従う。

| 種別 | 件数 |
| --- | --- |
| 自動: 単体 | 16 |
| 自動: 結合 | 15 |
| 自動: UI | 60 |
| 自動: 性能 | 7 |
| 自動: 国際化 | 1 |
| 半自動 | 1 |
| 手動 | 5 |
| 合計 | 105 |

- 手動・半自動の所要時間の合計の目安: 24 分 (うち優先度「高」は TC-TOOL-01-07 の 5 分)。
- 印刷の内容は、プリンタ「Microsoft Print to PDF」と PDF への出力 (TOOL-03) の結果の PDF を解析して自動で確認する。物理的なプリンタへの印刷だけを手動 (TC-TOOL-01-07) にする。
- インポート・エクスポートの形式は、往復の変換 (エクスポートしてインポートすると元に戻ること) と、他のツール (objcopy、srec_cat、xxd など) で作った参照ファイルとの比較で確認する。

テストを書くうえでの共通の前提:

- GUI のテストは、テストごとに新しいテスト用の設定フォルダ (`--test-profile`) で起動する。
- 「自動: 単体」「自動: 結合」で「〜の処理」と書いたものは、ダイアログと同じ `HexEditor.Core` の処理を直接呼ぶ (ダイアログの操作は別の UI のテストケースで確認する)。
- 「ファイルが変わらない」「元と一致する」は、SHA-256 の比較で確認する。

## TOOL-01 印刷とページ設定

### TC-TOOL-01-01 Ctrl+P で印刷ダイアログが開き、選択があれば印刷範囲の既定が選択範囲になる

| 項目 | 内容 |
| --- | --- |
| 確認する基準 | TOOL-01 の受け入れ基準 1 |
| 種別 | 自動: UI |
| 優先度 | 高 |
| フェーズ | 4 |
| テストデータ | TD-SEQ-1M |
| 環境 | 標準。「Microsoft Print to PDF」が既定のプリンタ |

**前提**: TD-SEQ-1M を開いている。選択はない。

**手順**:

1. Ctrl+P を押し、印刷ダイアログの印刷範囲の選択状態と、「選択範囲」の項目の有効 / 無効を取得する。
2. Esc でダイアログを閉じる。
3. Ctrl+E で 0x100 から長さ 0x200 を選択する。
4. Ctrl+P を押し、印刷範囲の選択状態を取得する。
5. ダイアログの右側のプレビューの要素の有無を取得する。

**期待結果**:

- 手順 1 で、印刷範囲が「すべて」で、「選択範囲」の項目は無効。
- 手順 4 で、印刷範囲が「選択範囲」。
- 手順 5 で、ダイアログの右側にプレビューがある。

### TC-TOOL-01-02 ヘッダ・フッタの置換記号が正しく置き換わる

| 項目 | 内容 |
| --- | --- |
| 確認する基準 | TOOL-01 の受け入れ基準 2 |
| 種別 | 自動: UI |
| 優先度 | 中 |
| フェーズ | 4 |
| テストデータ | TD-SEQ-1M |
| 環境 | 標準 (地域設定 en-US)。テスト用のビルドで時刻を 2026-10-07 14:03:00 に固定する (`--test-hooks`)。プリンタ「Microsoft Print to PDF」 |

**前提**: TD-SEQ-1M のコピー `print.bin` を開き、オフセット 0 に `FF` を入力している (未保存)。

**手順**:

1. Ctrl+P を押す。
2. ヘッダの左・中央・右を `{name}`、`{path}`、`{range}`、フッタの左・中央・右を `{size} {modified}`、`{page} / {pages}`、`{date} {time}` にする。
3. 印刷範囲を「オフセットの範囲」`0:0x1000` にする。
4. プリンタ「Microsoft Print to PDF」で印刷し、出力先に `out.pdf` を指定する。
5. `out.pdf` の各ページのテキストを抽出し、ヘッダとフッタの行を取り出す。

**期待結果**:

- 各ページのヘッダが `print.bin`、`print.bin` のフルパス、印刷範囲のオフセット (0x0〜0xFFF を表す表記)。
- フッタの左が TD-SEQ-1M のサイズ (1,048,576 バイトを表す表記) と「(変更あり)」、中央が `1 / N`〜`N / N` (N は PDF のページ数)、右が地域設定の書式の `10/7/2026` と `2:03 PM`。
- 置換されずに残った `{` を含む文字列がない。

### TC-TOOL-01-03 白黒の印刷で変更バイトが下線で区別できる

### TC-TOOL-01-04 100 GB のファイルで印刷ダイアログを開いても 1 秒以内にページ数が表示される

| 項目 | 内容 |
| --- | --- |

### TC-TOOL-01-06 印刷中に編集しても印刷開始時点の内容で印刷される

### TC-TOOL-01-07 実機のプリンタで印刷する
