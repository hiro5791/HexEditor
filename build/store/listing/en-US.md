# HexEditor

## Short description

A hex editor for Windows that opens, edits, searches and saves files and disks of any size.

## Description

HexEditor opens files of hundreds of GB instantly and keeps memory use small, whatever the size of the file.
Edit in the hex column or the text column, in overwrite or insert mode, with unlimited undo. Saving never breaks
the original file: changes are written to a temporary file first.

- Search for bytes, text (ASCII, UTF-8, UTF-16) and numbers; find all; replace.
- Data inspector: integers, floating point numbers, dates, GUIDs, with either endianness.
- Bookmarks, jump history, go to an offset with expressions such as end-0x10.
- Light, dark and high contrast themes; full keyboard operation; screen reader support.
- 23 display languages.
- No telemetry. HexEditor never sends the contents of your files anywhere.

## Notes

Features that need administrator rights (physical disks, internal disk volumes, memory of elevated processes)
work in the Microsoft Store version only when you start the whole app with **Run as administrator**
(Start menu > right-click HexEditor > More > Run as administrator). Memory of your own processes and USB storage
volumes work without administrator rights.
