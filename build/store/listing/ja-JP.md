# HexEditor

## 短い説明

どんな大きさのファイルやディスクでも開いて編集・検索・保存できる、Windows 向けのバイナリエディタ。

## 説明

HexEditor は数百 GB のファイルも一瞬で開き、ファイルの大きさに関係なく少ないメモリで動きます。
Hex 列とテキスト列のどちらからでも、上書きモードと挿入モードで編集でき、元に戻す回数に制限はありません。
保存では先に一時ファイルに書くため、元のファイルを壊しません。

- バイト列・テキスト (ASCII、UTF-8、UTF-16)・数値の検索、すべて検索、置換
- データインスペクタ: 整数、浮動小数点数、日時、GUID。エンディアンの切り替え
- ブックマーク、ジャンプ履歴、end-0x10 のような式でのオフセットへの移動
- ライト・ダーク・ハイコントラスト、キーボードだけでの操作、スクリーンリーダー
- 23 の表示言語
- テレメトリは送りません。ファイルの内容をどこにも送信しません。

## 注意

管理者権限が必要な機能 (物理ディスク、内蔵ディスクのボリューム、昇格したプロセスのメモリ) は、Microsoft Store 版では
アプリ全体を **管理者として実行** で起動したときだけ使えます (スタートメニューで HexEditor を右クリック > その他 > 管理者として実行)。
自分のプロセスのメモリと USB ストレージのボリュームは、管理者権限なしで使えます。
